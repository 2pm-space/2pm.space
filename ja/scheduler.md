## エージェントを時計に合わせる

エージェントを選び、時間を設定し、結果を読む。

1. **エージェントと仕事を選ぶ** — エージェントを選び、尋ねる内容を1行に1メッセージずつ書きます — 各行は個別の項目として送信・回答されます。
2. **実行タイミングを設定** — 1回限り、毎日、チェックした曜日の毎週、日付指定の毎月、または cron 式 — 選んだタイムゾーンで。
3. **結果を読む** — すべての実行は、各回答・トークン・コストとともにタスクの履歴に記録されます。一覧から今すぐ実行、一時停止、キャンセルもできます。

## エージェントを動かしていると分かっているスケジュール

Webhook を叩くだけの cron ジョブではなく、会話・ツール・ログを備えた実行です。

### 5種類のスケジュール

日付指定の1回限り、時刻指定の毎日、選んだ曜日の毎週、日付指定の毎月、またはあらゆる cron 式。すべてのスケジュールは、サーバーのではなく、自分で設定したタイムゾーンを守ります。

### 結果は必要な場所に届く

エージェントは自分のツールとともに実行されるため、レポートは書かれたそばから送り出せます — 営業グループへの Telegram メッセージ、メール、担当者へのプッシュ通知、ドライブのテーブルの1行として。

### 待てるなら、半額で

シンプルなエージェントを Batch API に切り替えると、実行はプロバイダーのバッチキューを通ります — およそ50%安く、24時間以内に完了します。Anthropic と OpenAI のモデルが対象です。

### 望むなら、実行をまたぐメモリも

毎回新しい会話を始めても、最新の会話に追加し続けてエージェントに前回を覚えさせても、あるいは特定の会話に投稿してもかまいません。

### 止めたいときに止まる

有効期限や実行回数の上限を設定でき、同時に処理するメッセージ数も1〜10件から選べます。

### すべての実行が記録に残る

各実行は、そのステータス、開始と終了、そしてすべてのメッセージの回答またはエラーを、トークンとコストとともに保持します — 設定 › ログにもまとめて表示されます。

## スケジュール設定のすべてのオプション

Create Task ダイアログが提供する、項目ごとの内容。

### スケジュール

- 1回限り、日付と時刻を指定
- 毎日、時刻を指定
- 毎週、チェックした曜日に
- 毎月、日にちを指定
- カスタムの cron 式
- あらゆるタイムゾーン

### 実行

- 即時実行、1〜10件のメッセージを同時に
- Batch API、およそ50%安く、24時間以内
- Anthropic または OpenAI のモデルを使うシンプルなエージェント向けの Batch
- Human Review ステップを含むエージェントはスケジュールできない

### 入力と会話

- 1行に1メッセージ、それぞれが個別の項目
- 毎回新しい会話
- または最新の会話を継続
- または ID を指定した特定の会話

### 制限

- 有効期限の日付と時刻
- 実行回数の上限
- 一覧に表示される実行回数、例：6/12

### 操作

- 今すぐ実行
- 一時停止と再開
- キャンセル
- 編集または削除
- 検索、ステータスまたはモードでの絞り込み

### 履歴とログ

- すべての実行とすべてのメッセージのステータス
- 各回答またはエラーの全文
- メッセージごと、実行ごとのトークンとコスト
- ワークスペースのログにある Scheduler Runs タブ

## cron とスクリプト vs. スケジューラー

同じ朝のレポートを、2通りのやり方で。

| 2pm.space がない場合 | 2pm.space を使うと |
| --- | --- |
| 1つの質問をするためだけに、cron ジョブ、スクリプト、動かし続けるサーバーが要る。 | エージェントを選び、質問を書き、時間を設定するだけ。 |
| 実行が午前3時に失敗しても、気づくのは1週間後。 | 各実行のステータスとエラーは、タスクの履歴に残る。 |

| 明日まで誰も必要としない作業に、正規料金を払っている。 | Batch API での実行なら、およそ半額。 |

## スケジューラーについてのよくある質問

最初のレポートを自動化する前に、みんなが聞くこと。

### 何をスケジュールできますか？

ワークスペース内の、有効なエージェントであれば何でも。受け取らせたいメッセージを1行ずつ書けば、各実行がそれらを送信し、回答を記録します。

### 結果はどうやって自分に届きますか？

エージェント自身のツールを通じてです。Telegram Send Message、Gmail、Notify Operators を与え、メッセージの中で結果の送り先を指示します。すべての回答は、タスクの実行履歴にも保存されます。

### Batch API モードとは何ですか？

実行のメッセージを、即座に回答する代わりにモデルプロバイダーのバッチキューに通します。コストはおよそ半分で、24時間以内に完了します。Anthropic または OpenAI のモデルを使うシンプルなエージェントで動作します — エージェンティックなワークフローは複数ターンの実行が必要なため、常に即時実行になります。

### どのタイムゾーンが使われますか？

タスクで選んだタイムゾーンです — デフォルトはブラウザのタイムゾーンです。毎日・毎週・毎月の時刻は、そのタイムゾーンで解釈されます。

### Human Review ステップを含むエージェントをスケジュールできますか？

いいえ。スケジュール実行には承認する人がいないため、ワークフローに Human Review ノードを含むエージェントはダイアログでスケジュールできません。

### 一定の実行回数のあとにタスクを止められますか？

はい。実行回数の上限、有効期限、またはその両方を設定できます。タスクはいつでも一時停止、再開、キャンセルできます。
