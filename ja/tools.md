## エージェントにツールを与える3ステップ

選んで、つないで、与える。

1. **種類を選ぶ** — 組み込みカタログから選ぶか、Webhook、Python 関数、MCP 接続、またはツールとしてのエージェントを作成します。
2. **つなぐ** — ベンダーから渡された API キー、または自社サービスの URL と認証情報を貼り付けます。認証情報は暗号化して保存されます。
3. **与える** — 使うべきエージェントに対してオンにするか、グローバルにしてすべてのエージェントが使えるようにします。いつ呼び出すかは、ツールの説明文からエージェントが判断します。

## 5種類のツールを、1つのリストに

エージェントが届く必要のあるものは何でも、渡す方法があります。

### 60種類のツールが、すぐ使える

ウェブ検索、Wikipedia、ArXiv、ヘッドレスブラウザ、Gmail、Google Calendar、GitHub、Telegram、テキスト読み上げ、BI ボード、自社の Drive — それぞれがカタログの1枚のカードで、多くは追加した瞬間から動きます。

### あらゆる HTTP API

エンドポイントを記述するだけ — メソッド、URL、ヘッダー、認証、エージェントが送るべき JSON — それがそのままツールになります。GET、POST、PUT、PATCH、DELETE に対応し、ベアラートークンまたは API キー認証を使えます。

### 自社の Python

関数を書いて入力スキーマを与えれば、タイムアウト付きのサンドボックスで実行されます — インターネットアクセスを許可しない限りオフラインです。

### あらゆる MCP サーバー

サーバーの URL を指定するだけで、公開されているツールが検出されます。1つずつオン・オフを切り替え、書き込みを行うものには承認を必須にできます。

### ツールとしてのエージェント

あるエージェントを別のエージェントに公開します — ライター役はリサーチャー役に尋ね、営業エージェントは在庫チェック役に尋ねられます。それぞれが自分自身のプロンプト、モデル、ツールを保ったままです。

### 誰が何を持つかは、自分で決める

ツールをエージェントごとに付与するか、グローバルにするか。削除せずにオフにでき、結果をキャッシュでき、実行前に人の承認を必須にできます。

## ツールについてのよくある質問

最初のシステムをつなぐ前に、みんなが聞くこと。

### 組み込みツールはいくつありますか？

現時点で60種類、検索、ナレッジ、コンピュート、データ、AI・メディア、金融、ユーティリティ、生産性、MCP サーバー、Drive、連携にグループ分けされています — 全リストはこのページにあります。それ以外にも、あらゆる HTTP API、Python 関数、MCP サーバーがツールになれます。

### API キーは必要ですか？

一部のツールにはベンダーのキーが必要です — Tavily、Serper、Gmail、GitHub など、鍵アイコンが付いているものです。DuckDuckGo、Wikipedia、ArXiv、Web Fetch、Playwright ブラウザ、ドライブのツールなど、多くはキーなしで動きます。

### ツールは実行前に承認を待てますか？

はい。人が確認すべきツール — 送信、書き込み、削除を行うものが典型的です — には「人の承認を必須にする」をオンにします。すると、誰かが呼び出しを承認するまでエージェントの実行は一時停止します。MCP サーバーや連携の場合、承認は検出したツールごとに設定します。

### 自社の MCP サーバーを接続できますか？

はい。サーバーの URL、トランスポート、認証を指定して MCP ツールを追加すると、公開されているツールが検出・一覧表示され、1つずつオン・オフを切り替えられます。N8N、Slack、Notion、GitHub、Google Drive、WordPress のプリセットもカタログにあります。

### あるエージェントが、別のエージェントをツールとして使えますか？

はい。Agent as tool を作成し、対象のエージェントを選びます。付与されたどのエージェントも、タスクを渡して回答を利用できます。渡された側は、自分自身のプロンプト、モデル、ツールを保ったままです。

### Viettel Post と KiotViet はどう位置づけられますか？

組み込みの連携です。アカウントを一度接続すれば、エージェントはそれらの操作をツールとして得られます — 送料の見積もり、配送の作成、在庫確認、注文の照会など。
