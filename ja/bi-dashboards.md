## 始まりは、 1つの質問から

データベースに普段の言葉で質問し、グラフをピン留めすれば、チームが開きっぱなしにしているボードに加わります — タブ、すべてのタイルに届くフィルター、そしてワンクリックで前期間との比較まで。

## 質問からボードまで3ステップ

質問して、ピン留めして、共有する。

1. **質問する、あるいは SQL を書く** — Ask Data は普段の言葉での質問に、グラフ付きで答えます。SQL Lab では自分でクエリを書くことも、説明文から AI に下書きさせることもできます。
2. **ボードにピン留め** — グラフを、新規または既存のボードとタブにピン留めします。タイルが保持するのは絵ではなく、クエリそのものです。
3. **共有する** — 必要な人にボードを共有します。フィルターは URL に保持されるため、リンクを開けば今見ている表示のまま開きます。

## ごまかさないボード

すべてのタイルは、データモデルに対するクエリであり、その結果のスクリーンショットではありません。

### 「売上」の定義は1つ

タイルは Ask Data と同じセマンティックモデルにクエリするため、一度定義したメジャーは、すべてのグラフとすべてのボードで同じ意味を持ちます。

### すべてのタイルに届くフィルター

モデルがフィルター可能とマークしたディメンションであれば何にでもボードフィルターを追加でき、それを使うすべてのタイルが再実行されます。従えないタイルは、そう表示します。

### 今期と前期を比べる

前期間、前年同期、または自分で選んだ範囲と比較でき、時間は日・週・月・四半期・年単位で再集計できます。

### 9通りの描き方

棒グラフ、横棒グラフ、積み上げ、100% 積み上げ、折れ線、面、円、散布図、単一数値カード — タイルごとに軸、凡例、データラベル、系列の色を設定できます。

### 正確さを求めるなら SQL Lab

モデルに対して CubeQL を書き、コンパイル後のネイティブ SQL を確認し、クエリを保存し、良いものは再利用できる派生キューブにできます。

### エージェントもボードを作れる

BI Board ツールを使えば、エージェントもボードの作成、グラフの追加、タイルのデータ読み取りができます — 同じ操作は、Claude Code や Cursor 向けの自社 MCP サーバーでも可能です。

- 折れ線と面

### 書式

- 軸タイトル、最小値、最大値、対数スケール
- 凡例、データラベル、系列の色
- フィールドごとの、モデル書式の上書き

### フィルター

- モデルのフィルター可能なディメンションであれば何にでも
- テキスト、単一選択、複数選択、日付、日付範囲
- 一致する、一致しない、含む、で始まる、で終わる
- 共有できる表示として URL に保持
- タイルのカテゴリ内を検索

### 時間

- 前期間と比較
- または前年同期と比較
- またはカスタム範囲と比較
- 日・週・月・四半期・年単位でグループ化
- 相対的なままの日付範囲

- セマンティックモデルに対する CubeQL
- コンパイル後のネイティブ SQL
- 説明文から AI がクエリを下書き
- 保存したクエリ
- 派生キューブとして保存したクエリ

- ドラッグ&リサイズできるレイアウト

## スプレッドシートのレポート vs. ライブなボード

同じ月曜の数字を、2通りのやり方で。

| 2pm.space がない場合 | 2pm.space を使うと |
| --- | --- |
| 誰かが毎週月曜、数字をエクスポートして貼り付け、グラフを描き直す。 | タイルはクエリを保持している — 更新すれば最新になる。 |
| レポートが2つあれば、「売上」の定義も2つ。 | すべてのタイルが、モデルの同じメジャーを読む。 |
| 「先月分もお願い」と言われるたびに、別のレポートが必要になる。 | ボードのフィルターを変えるか、比較をオンにするだけ。 |
| グラフの依頼は、SQL を知っている人の順番待ち。 | 普段の言葉で質問して、答えをピン留めするだけ。 |

## BI ダッシュボードについてのよくある質問

最初のボードを作る前に、みんなが聞くこと。

### ボードはどのデータベースを使えますか？

Ask Data が対応するあらゆる接続です — PostgreSQL、MySQL、Redshift、ClickHouse、Snowflake、BigQuery。ボードは、自社のセマンティックモデルを通してクエリします。

### グラフはどうやってボードに載りますか？

Ask Data または SQL Lab からです。グラフが正しく仕上がったら「Pin to board」を選び、ボードとタブを指定します。タイルが保持するのはクエリであり、絵だけではありません。

### フィルターはすべてのタイルに効きますか？

ボードフィルターは、そのディメンションをクエリで使うすべてのタイルに適用され、再実行されます。フィルターできないタイルは、フィルターされていない数字を黙って表示するのではなく、ヘッダーにその旨を表示します。

### 先月や前年と比較できますか？

はい。比較をオンにして、前期間、前年同期、またはカスタム範囲を選びます。日付範囲を持つタイルは、両方の期間を表示します。

### エージェントはボードを使えますか？

はい。BI Board ツールを使えば、エージェントはボードの作成、グラフの追加、タイルのデータ読み取りができます。同じ操作は、MCP サーバー経由で Claude Code や Cursor からも利用できます。
