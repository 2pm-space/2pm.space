## 最初のメッセージからお礼まで

お客様がどのチャネルからでもメッセージを送ると、2pm AI がナレッジ、スキル、ツール、メモリを使って相談に乗り、注文を受け、代引き（COD）配送を手配し、お礼を伝えます — 会話の流れが変わっても、どちらに進むべきかを判断します。

**お客様がチャット**

- **Messenger:** *青いの、まだ在庫ありますか？*
- **Telegram:** *ダナンまで配送できますか？*
- **ウェブサイトウィジェット:** *これ2つだといくらになりますか？*
- **個人 Zalo:** *代引きで払えますか？*

### 2pm AI が接客

すべてのチャネルの裏側に、1つのエージェント。ワークスペースが知っていることをすべて活用します。

- **ナレッジ** — ドキュメントやカタログから回答。商品写真も含めて
- **スキル** — 自社の営業プレイブック — 何を聞き、何を提案し、どんな口調で話すか
- **ツール** — 会話の途中で、商品、過去の注文、送料を調べます
- **メモリ** — お客様が前回話したことを覚えています
- **Customer 360** — お客様が使ったすべてのチャネルを、1つの履歴に
- **ガードレール** — すべての返信を、言ってよいこと・してよいことの範囲内に保ちます

1. **内容を確認** — 商品、電話番号、配送先住所をお客様と確認し合います。 `住所を保存`
2. **注文を作成** — カタログの価格で受注を作成 — チームが確定する下書きにするか、そのまま確定します。 `SO-2026-48213`
3. **COD 配送を手配** — 代引き金額を付けて Viettel Post に手配するか、自社の配送業者向けに納品書として残します。 `COD · 追跡番号`
4. **お礼を伝える** — 配達完了が報告されると、イベントルールがお礼を送信 — スレッドの内容から書くか、テンプレートを使います。 `配達済み → お礼済み`

**その途中で**

- **電話番号を教えてくれたら → Zalo で友だち追加.** 番号は連絡先に紐づけられ、個人 Zalo から友だち申請を送信 — 間隔を空けて、午前8時から午後8時の間に。承認されると、Zalo のチャットも同じ顧客にまとまります。 `+84 ••• 412 → Zalo`
- **返信が途絶えたら → ケアがフォローアップ.** ケアエージェントがスレッドを読み、設定した無応答時間の後にフォローアップ — 送信しない時間帯を避け、1人あたりの上限を守り、チャネルのメッセージ送信期間内に送ります。 `無応答2時間 → フォローアップ`
- **担当者を求められたら → チームが入る.** エージェントがスレッドを開くプッシュ通知をチームに送ります。誰でもそこで返信でき、AI を停止してスレッドを引き取ることもできます。 `通知 → AI 停止`
- **スパムや迷惑行為があれば → エージェントが返信を停止.** そのスレッドの AI とケアをオフにし、チームに1行の理由を残します。受信箱から誰でもオンに戻せます。 `AI オフ · 理由を記録`

## 仕組み

アイデアから本番運用まで3ステップ。複雑なセットアップも、インフラの悩みもありません。

1. **エージェントを構築** — エージェントのペルソナ、指示、振る舞いを定義します。マーケットプレイスのテンプレートから始めても、ビジュアルビルダーの白紙のキャンバスから始めても構いません。
2. **スキル、ツール、ナレッジを与える** — スキルを追加し、ツールを接続し、必要なドキュメントやデータベースを指定して、守るべきガードレールを設定します。
3. **仕事を任せる** — チャネル、スケジュール、API に送り出します。すべての実行をツール呼び出しやコストとともに見守り、実際に起きたことから改善します。

## 強力なエンジンの上に

2pm.space の中身は、ただのチャット画面ではありません。すべての機能が、エージェントをより賢く、速く、安全にするために設計された本番品質のエンジンです。

### エージェントの考え方

**考え、行動し、繰り返すエージェント**

2pm.space のすべてのエージェントは ReAct ループの上に構築されています — 推論し、行動し、観察し、繰り返す。エージェントはただ応答するのではなく、計画を立て、ツールを呼び出し、結果を評価し、タスクが終わるまで調整します。

- シンプルモード：1回の LLM 呼び出しで、速く直接的な回答
- エージェンティックモード：条件分岐と並列実行を備えた複数ノードのワークフローグラフ
- 各ノードはデフォルトで最大10回のツール呼び出しの反復に対応
- バックエッジ（循環）で、無限ループに陥らずにステップを再訪可能

### メモリとコンテキスト

**会話を重ねるほど賢くなるメモリ**

2pm.space のエージェントは覚えています。3層のメモリシステム — テナント全体のグローバルメモリ、エージェントごとの共有コンテキスト、ユーザーごとのメモ — により、すべてのやり取りが過去の経緯を踏まえたものになります。

- すべての会話からバックグラウンドでメモリを自動抽出
- 減衰スコアリング付きのセマンティック検索 — 新しく関連性の高い記憶が先に浮かぶ
- 6種類のメモリ：事実、好み、指示、フィードバック、エピソード、手順
- 3段階の重複排除：LLM プロンプト、ベクトル類似度、定期的な統合

### ツール

**エージェントを、あらゆるものに接続**

エージェントは与えられたツールを呼び出します — プラットフォームの組み込みツール、外部の Webhook、サンドボックスの Python 関数、MCP サーバーのツール。ReAct ループはエラーを適切に処理し、手動の介入なしに賢く再試行します。

- 組み込みツール：Web 検索、画像生成、コード実行など
- Webhook ツール：Bearer または API キー認証で、あらゆる API に POST/GET/PUT/PATCH
- コード：サンドボックスの Python 関数をツールとして、ワークフローのコードノードでは Python や Bash を
- MCP 対応：あらゆる MCP サーバーに接続し、ツールを検出してひとつずつオン・オフ

### ドキュメントと RAG

**ナレッジベースを、いつでも手の届くところに**

ドキュメント、マインドマップ、スプレッドシート、テーブルを Collaborative Drive にアップロード。エージェントは必要なときに、密ベクトル検索と BM25 キーワード検索を組み合わせたハイブリッド検索で、最も関連性の高いチャンクを取り出します。

- デフォルトでハイブリッド検索：RRF による融合で、ベクトル70%＋キーワード30%
- 文脈を考慮した埋め込みによるセマンティックチャンキングで、検索精度を向上
- 2つの RAG モード：「tool」（エージェントが呼び出す）または「auto」（常に注入）
- 段階的な検索：まずチャンクの要約、必要に応じて全文 — トークンを節約

### スキル

**エージェントが使いこなす、再利用可能な指示**

スキルは、エージェントのシステムプロンプトに注入されるプロンプトテンプレートです — 常に、またはユーザーの質問が一致したときに自動で。一度定義すれば、ワークスペース内のすべてのエージェントで再利用できます。

- 「常に」モード：すべてのシステムプロンプトに注入し、振る舞いを確実に
- 「自動」モード：全文検索で質問が一致したときだけ注入 — トークンを節約
- グローバルスキルはすべてのエージェントに適用、エージェント固有のスキルはその範囲内に
- システムスキルはプラットフォーム全体に適用され、テナントの制限を受けない

### 可観測性

**すべてのエージェント実行を完全に可視化**

すべての実行をエンドツーエンドで追跡 — ノードごとのトークン使用量、コスト、レイテンシ、ツール呼び出し、ガードの結果。あらゆる失敗をデバッグし、コストを最適化し、エージェントが何をしているのかを正確に把握できます。

- ノードごとの追跡：ステップごとの入力トークン、出力トークン、コスト
- メッセージ履歴とツール呼び出しの結果をすべて含む実行ログ
- ガードレールの監査：どのガードが作動し、どんな措置が取られ、なぜそうなったか
- メモリ抽出ログ：各会話から何を学んだかを追跡

## 2pm.space が選ばれる理由

バラバラのツールから1つのプラットフォームへ。2pm.space が AI ワークフローをどう変えるかをご覧ください。

| 2pm.space がない場合 | 2pm.space を使うと |
| --- | --- |
| 受信箱に1つ、ダッシュボードに1つ、コンテンツにもう1つのツール — そしてどれも、知っていることを共有しない。 | 同じエージェント、メモリ、ナレッジベースが3つすべてを支える、1つのワークスペース。 |
| ページに置いたチャットボットは、シナリオどおりにしか答えられず、本当の質問をされるとお手上げ。 | ドキュメント、カタログ、ツールを備えたエージェント — そしてワンクリックでチームメンバーにつながる。 |

## よくある質問

2pm.space で AI エージェントを構築・デプロイするために知っておきたいことのすべて。

### 2pm.space をひと言で言うと？

AI エージェントを構築し、実際に仕事を任せるためのワークスペースです — Messenger、Zalo、Telegram、ウェブサイトチャットでお客様に回答し、データベースに関する質問に普段の言葉で答え、コンテンツカレンダーを回します。そのすべてが、ライブなドキュメント、マインドマップ、テーブルを共有するドライブの上で動きます。

### どんな AI エージェントを作れますか？

1回の呼び出しで完結するアシスタントから、条件分岐、並列ブランチ、評価ループを備えた複数ノードのワークフローまで、何でも作れます。サポートエージェント、リサーチアシスタント、コンテンツライター、データアナリスト、社内の自動化がよくある形で、どれも同じスキル、ツール、ナレッジ、ガードレールから組み立てられます。

### エージェントを作るのにプログラミングの経験は必要ですか？

いいえ。エージェントはビジュアルに構築します — ペルソナ、指示、スキル、ツール、ガードレールはすべて設定で、出発点となるテンプレートのマーケットプレイスもあります。コードを書く場合は、サンドボックス化された Python のツール、API、MCP エンドポイントも用意されています。

### エージェントはどのように学習し、コンテキストを覚えるのですか？

3つの方法を組み合わせています。メモリは会話からバックグラウンドで抽出され、意味で検索されるので、エージェントは言われたことを覚えています。ドライブのドキュメントは、ベクトルとキーワードのハイブリッド検索で必要なときに取り出されます。そしてスキル — 一度書けば再利用できる指示 — は、常に、または質問が一致したときだけプロンプトに注入されます。

### すでに使っているシステムと接続できますか？

はい。メッセージングチャネルはファーストクラスのチャネルとして、HTTP API は Webhook ツールとして、6種類のデータベースとデータウェアハウスはデータ接続として、あらゆる MCP サーバーは検出して有効にするツールのソースとして接続できます。それ以外は、シンプルな Webhook を通じてつながります。

### 料金はいくらですか？

すべての機能が無料で、有料プランも席数による課金もありません。お支払いいただくのは AI の利用分だけです — モデルのトークンは提供元の料金そのままで上乗せなしに請求され、プラットフォームはクレジットを追加するときに一律の手数料を一度だけいただきます。月額で請求されるのは、含まれる基本容量を超えたストレージだけです。

### チームでの共同作業はどのように行いますか？

ワークスペースにはメンバー、ロール、チームがあり、権限はリソースごと、アクションごとに付与されます。さらに、個々のエージェント、ドキュメント、チャネル、ボードがそれぞれ独自のアクセスリストを持つため、外部スタッフにワークスペース全体ではなく、1つのページだけを渡せます。

### エージェントが実際に何をしたか確認できますか？

すべての実行がエンドツーエンドで記録されます。メッセージ、各ツール呼び出しとその戻り値、ステップごとのトークンとコスト、どのガードレールが作動して何をしたか。スケジュール実行、Webhook の配信、フォローアップの送信も、それぞれのログがその隣に保存されます。
