## 从第一条消息到一句感谢

客户在任意渠道发来消息。2pm AI 调用你的知识、技能、工具和记忆进行咨询，接单、预约 COD 配送并致谢——对话方向一变，它也知道该怎么走。

**客户发来消息**

- **Messenger:** *蓝色那款还有货吗？*
- **Telegram:** *能发货到岘港吗？*
- **网站挂件:** *这个买两个多少钱？*
- **个人 Zalo:** *可以货到付款吗？*

### 2pm AI 负责咨询

每个渠道背后都是同一个智能体，调用你工作区掌握的全部信息。

- **知识** — 依据你的文档和商品目录作答，包括商品图片
- **技能** — 你的销售话术——该问什么、推荐什么、用什么语气
- **工具** — 对话中随时查询商品、历史订单和运费
- **记忆** — 记得客户上次说过的话
- **Customer 360** — 客户用过的所有渠道，合并为一份历史记录
- **护栏** — 让每条回复都不越出它可说、可做的范围

1. **确认信息** — 与客户逐一核对商品、手机号和收货地址。 `地址已保存`
2. **创建订单** — 按你的商品目录定价生成销售订单——可作为草稿由团队确认，也可直接提交。 `SO-2026-48213`
3. **预约 COD 发货** — 通过 Viettel Post 下单并填写货到付款金额，或记在送货单上交给你自己的承运商。 `COD · 运单号`
4. **发送感谢** — 收到签收回报后，事件规则会自动发送感谢消息——根据会话内容撰写，或使用你的模板。 `已签收 → 已致谢`

**过程中**

- **如果客户留下手机号 → 在 Zalo 上加好友.** 号码会固定到联系人上，你的个人 Zalo 随即发送好友请求——控制节奏，只在早 8 点到晚 8 点之间发送。对方通过后，Zalo 聊天会归入同一位客户。 `+84 ••• 412 → Zalo`
- **如果客户不再回复 → 关怀智能体跟进.** 关怀智能体会阅读会话，在你设定的沉默时长后跟进——遵守你的免打扰时段、每人次数上限，以及渠道的消息发送窗口。 `沉默 2 小时 → 跟进`
- **如果客户要求人工 → 团队介入.** 智能体向团队发送直接打开会话的推送提醒。任何人都可以在那里回复——或暂停 AI，把会话留给自己。 `提醒 → AI 已暂停`
- **如果客户刷屏或辱骂 → 智能体停止回复.** 它会关闭该会话的 AI 和关怀，并给团队留下一句原因说明。任何人都可以在收件箱中重新开启。 `AI 已关闭 · 已记录原因`

## 由强大的引擎驱动

在底层，2pm.space 远不止一个聊天界面。每项能力都是生产级引擎，让你的智能体更聪明、更快、更安全。

### 智能体原理

**会思考、会行动、会迭代的智能体**

2pm.space 上的每个智能体都基于 ReAct 循环——推理、行动、观察，循环往复。智能体不只是回应；它会规划、调用工具、评估结果并不断调整，直到完成任务。

- 简单模式：单次 LLM 调用，快速直接作答
- 智能体模式：多节点工作流图，支持条件路由和并行执行
- 每个节点默认支持最多 10 次工具调用迭代
- 回边（循环）让智能体可以回到之前的步骤，而不会陷入无限循环

### 记忆与上下文

**每次对话都让记忆更聪明**

2pm.space 上的智能体有记忆。三层记忆系统——租户全局记忆、智能体共享上下文、每位用户的笔记——让每次交互都能参考之前发生的一切。

- 在后台自动从每次对话中提取记忆
- 带衰减评分的语义检索——最新、最相关的记忆优先浮现
- 六种记忆类型：事实、偏好、指令、反馈、经历、流程
- 三个层面去重：LLM 提示词、向量相似度和定期整合

### 工具

**把智能体连接到一切**

智能体调用你授予它的工具——平台内置工具、外部 Webhook、沙箱中的 Python 函数，或某个 MCP 服务器的工具。ReAct 循环会优雅地处理错误，无需人工干预即可智能重试。

- 内置工具：网页搜索、图片生成、代码执行等
- Webhook 工具：以 POST/GET/PUT/PATCH 调用任意 API，支持 Bearer 或 API 密钥认证
- 代码：沙箱中的 Python 函数作为工具，工作流的代码节点中可运行 Python 或 Bash
- MCP 支持：连接任意 MCP 服务器，发现其工具并逐个开启或关闭

### 文档与 RAG

**你的知识库，随取随用**

把文档、思维导图、电子表格和表格上传到 Collaborative Drive。智能体按需用混合检索找出最相关的片段——结合稠密向量检索与 BM25 关键词检索。

- 默认混合检索：通过 RRF 融合，70% 向量 + 30% 关键词
- 语义分块配合上下文嵌入，检索更准确
- 两种 RAG 模式：“tool”（由智能体触发）或“auto”（始终注入）
- 分层检索：先看片段摘要，需要时再取全文——节省 Token

### 技能

**智能体可以掌握的可复用指令**

技能是注入智能体系统提示词的提示词模板——可以始终注入，也可以在用户问题匹配时自动注入。定义一次，就能在工作区的所有智能体中复用。

- “Always”模式：注入每条系统提示词，确保行为稳定
- “Auto”模式：仅在全文检索匹配到问题时注入——节省 Token
- 全局技能适用于所有智能体；专属技能只作用于指定智能体
- 系统技能在整个平台生效，不受租户限制

### 可观测性

**每次智能体运行都清清楚楚**

每次执行都被端到端追踪——逐节点的 Token 用量、成本、延迟、工具调用和护栏结果。排查任何故障，优化成本，准确了解智能体在做什么。

- 逐节点追踪：每一步的输入 Token、输出 Token 和成本
- 执行日志包含完整消息历史和工具调用结果
- 护栏审计：查看哪些护栏被触发、采取了什么措施、原因是什么
- 记忆提取日志：追踪每次对话学到了什么

## 常见问题

关于用 2pm.space 构建和部署 AI 智能体，你需要知道的一切。

### 一句话介绍 2pm.space？

一个工作区：你在这里构建 AI 智能体，并真正让它们投入工作——在 Messenger、Zalo、Telegram 和网站聊天上回复客户，用日常语言回答关于数据库的问题，运营你的内容日历——一切都建立在存放实时文档、思维导图和表格的共享云盘之上。

### 我可以构建哪些类型的 AI 智能体？

从单次调用的助手，到带条件路由、并行分支和评估循环的多节点工作流都可以。常见的有客服智能体、研究助理、内容写手、数据分析师和内部自动化，每一个都由同一套技能、工具、知识和护栏组装而成。

### 创建智能体需要编程经验吗？

不需要。智能体以可视化方式构建——角色设定、指令、技能、工具和护栏都是配置项，还有应用市场的模板可以直接起步。如果你会写代码，沙箱化的 Python 工具、API 和 MCP 端点也随时可用。

### 智能体如何学习和记住上下文？

三种方式协同工作。记忆在后台从对话中提取并按语义检索，所以智能体记得别人告诉过它什么。云盘中的文档通过向量与关键词混合检索按需取用。而技能——写一次即可复用的指令——会始终注入提示词，或只在问题匹配时注入。

### 能连接我们现有的系统吗？

可以。消息应用作为一等渠道接入，HTTP API 作为 Webhook 工具接入，六种数据库和数据仓库作为数据连接接入，任意 MCP 服务器作为可发现并启用的工具来源接入。其他任何系统都可以通过普通 Webhook 接入。

### 费用是多少？

所有功能免费，没有付费档位，也不按席位收费。你只为 AI 用量付费——模型 Token 按提供商的原价计费、不加价，平台只在你充值时收取一笔固定费用。超出基础额度的存储空间是唯一按月计费的项目。

### 团队协作如何进行？

工作区包含成员、角色和团队，权限按资源、按操作授予。在此之上，单个智能体、文档、渠道或看板还有各自的访问列表——所以可以只给外包人员一个主页的权限，而不开放整个工作区。

### 能看到智能体实际做了什么吗？

每次运行都有端到端日志：消息内容、每次工具调用及其返回结果、每一步的 Token 和成本，以及哪些护栏被触发、做了什么。定时运行、Webhook 投递和跟进发送也各有独立日志，放在一旁可查。
