## Donnez un outil à un agent en trois étapes

Choisissez-le, connectez-le, accordez-le.

1. **Choisissez un type** — Choisissez dans le catalogue intégré, ou créez un webhook, une fonction Python, une connexion MCP ou un agent en tant qu'outil.
2. **Connectez-le** — Collez la clé API fournie par le prestataire, ou l'URL et l'authentification de votre propre service. Les identifiants sont stockés chiffrés.
3. **Accordez-le** — Activez-le pour les agents qui doivent l'utiliser, ou rendez-le global pour que chaque agent le puisse. L'agent décide quand l'appeler à partir de la description de l'outil.

## Cinq types d'outils, une seule liste

Quoi que doive atteindre un agent, il existe un moyen de le lui confier.

### Soixante outils, prêts à l'emploi

Recherche web, Wikipedia et ArXiv, un navigateur headless, Gmail et Google Calendar, GitHub, Telegram, la synthèse vocale, les tableaux BI et votre propre Drive — chacun une carte du catalogue, beaucoup fonctionnant dès que vous les ajoutez.

### N'importe quelle API HTTP

Décrivez le endpoint — méthode, URL, en-têtes, authentification et le JSON que l'agent doit envoyer — et il devient un outil. GET, POST, PUT, PATCH et DELETE, avec authentification par jeton porteur ou clé API.

### Votre propre Python

Écrivez une fonction, donnez-lui un schéma d'entrée, et elle s'exécute dans un bac à sable avec un délai d'expiration — hors ligne à moins que vous n'autorisiez l'accès internet.

### N'importe quel serveur MCP

Indiquez l'URL d'un serveur et les outils qu'il expose sont découverts pour vous. Activez ou désactivez chacun, et exigez une approbation pour ceux qui écrivent.

### Des agents en tant qu'outils

Exposez un agent à un autre : un rédacteur peut interroger un chercheur, un agent commercial peut interroger le vérificateur de stock — chacun gardant son propre prompt, modèle et outils.

### Vous décidez qui détient quoi

Accordez un outil par agent ou rendez-le global, désactivez-le sans le supprimer, mettez ses résultats en cache, et exigez l'approbation d'une personne avant son exécution.

## Ce que prend chaque type

Les champs, les options et les limites — avant de vous lancer.

### Types d'outils

- Built-in — choisi dans le catalogue
- Webhook — n'importe quel endpoint HTTP
- Code — une fonction Python en bac à sable
- MCP — n'importe quel serveur MCP
- Agent as tool — un autre agent de l'espace de travail

### Outils webhook

- GET, POST, PUT, PATCH et DELETE
- Aucune authentification, jeton porteur ou clé API
- En-têtes personnalisés
- Un schéma d'entrée JSON que l'agent remplit

### Outils Code

- Python, édité dans le navigateur
- S'exécute dans un bac à sable avec un délai d'expiration
- Accès internet désactivé sauf autorisation
- Un schéma d'entrée, comme tout autre outil

### Serveurs MCP

- Connexion par URL, en SSE ou Streamable HTTP
- Authentification par jeton porteur et en-têtes personnalisés
- Les outils découverts listés un par un
- Chacun activable ou désactivable
- Approbation par outil, ou pour tous

### Intégrations

- Viettel Post — frais, expéditions, statut et étiquettes
- KiotViet — produits, stock, clients, commandes et factures
- WordPress — articles, pages, médias, et produits WooCommerce
- ERPNext / Frappe — les documents de votre site
- Les kits d'outils Composio, avec votre clé Composio

### Accès et sécurité

- Accordé par agent, ou global à tous
- Désactivé sans être supprimé
- Approbation humaine avant l'exécution des outils choisis
- Mise en cache des résultats, contournée quand l'approbation est activée
- Chaque appel dans le journal d'exécution

## Câbler les outils à la main contre le catalogue

La même intégration, de deux façons.

| Sans 2pm.space | Avec 2pm.space |
| --- | --- |
| Chaque nouvelle API veut dire du code, un déploiement, et un prompt pour l'expliquer. | Décrivez le endpoint une seule fois ; tout agent auquel vous l'accordez peut l'appeler. |
| Un outil capable de supprimer s'exécute aussi librement qu'un outil qui ne fait que lire. | Exigez une approbation sur les outils qui écrivent, et l'exécution attend une personne. |
| Chaque serveur MCP apporte tous les outils qu'il possède, voulus ou non. | Activez ou désactivez chaque outil découvert, un par un. |
| Personne n'est certain de savoir quel agent peut atteindre quel système. | La page de chaque outil liste les agents auxquels il est accordé. |

## Questions sur les outils

Ce que les gens demandent avant de connecter leur premier système.

### Combien d'outils sont intégrés ?

Soixante aujourd'hui, regroupés en recherche, connaissances, calcul, données, IA et médias, finance, utilitaire, productivité, serveurs MCP, Drive et intégrations — la liste complète est sur cette page. Au-delà, toute API HTTP, fonction Python ou serveur MCP peut devenir un outil.

### Ai-je besoin de clés API ?

Certains outils nécessitent la clé du prestataire — Tavily, Serper, Gmail, GitHub et les autres marqués d'une icône de clé. Beaucoup fonctionnent sans, notamment DuckDuckGo, Wikipedia, ArXiv, Web Fetch, le navigateur Playwright et les outils Drive.

### Un outil peut-il attendre une approbation avant de s'exécuter ?

Oui. Activez Exiger une approbation humaine pour les outils qu'une personne doit confirmer — typiquement ceux qui envoient, écrivent ou suppriment — et l'exécution de l'agent se met en pause jusqu'à ce que quelqu'un approuve l'appel. Pour un serveur MCP ou une intégration, l'approbation se règle par outil découvert.

### Puis-je connecter mon propre serveur MCP ?

Oui. Ajoutez un outil MCP avec l'URL, le transport et l'authentification du serveur ; les outils qu'il expose sont découverts et listés, et vous activez ou désactivez chacun. Des préréglages pour N8N, Slack, Notion, GitHub, Google Drive et WordPress sont dans le catalogue.

### Un agent peut-il en utiliser un autre comme outil ?

Oui. Créez un Agent as tool et choisissez l'agent. Tout agent auquel vous l'accordez peut lui confier une tâche et utiliser la réponse, tandis qu'il garde son propre prompt, modèle et outils.

### Où se situent Viettel Post et KiotViet ?

Ce sont des intégrations intégrées. Connectez votre compte une seule fois et l'agent reçoit leurs opérations comme outils — chiffrer des frais de livraison, créer une expédition, vérifier le stock, retrouver une commande.
