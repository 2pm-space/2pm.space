# AI 에이전트 스케줄러 — 일정에 따라 에이전트 실행

> AI 에이전트가 스스로 실행되도록 일정을 잡으세요: 일회성, 매일, 매주, 매월 또는 cron, 원하는 시간대로. Batch API로 실행하면 비용이 약 절반이고, 실행 횟수와 만료 제한, 모든 답변의 토큰과 비용까지 기록으로 남습니다.

## 정확한 시간에, 매번 나타나는 에이전트

에이전트에게 무엇을 언제 할지 알려 주세요 — 8시의 매출 요약, 매주 월요일의 콘텐츠 다이제스트, 매일 밤의 팔로업 점검까지. 원하는 시간대에 맞춰 스스로 실행되고, 모든 답변을 확인할 수 있는 곳에 남깁니다.

## 에이전트에게 시간을 맡기세요

에이전트를 고르고, 시간을 정하고, 결과를 확인하세요.

1. **에이전트와 작업을 고르세요** — 에이전트를 고르고 물어볼 내용을 한 줄에 하나씩 적으세요 — 각 줄은 개별 항목으로 전송되고 답변됩니다.
2. **실행 시점을 정하세요** — 일회성, 매일, 체크한 요일마다 매주, 지정한 날짜에 매월, 또는 cron 표현식으로 — 원하는 시간대에 맞춰서요.
3. **무엇을 했는지 확인하세요** — 모든 실행은 각 답변, 토큰, 비용과 함께 작업 기록에 남습니다. 목록에서 지금 실행하거나, 일시중지하거나, 취소할 수 있습니다.

## 에이전트를 실행 중임을 아는 일정

웹훅을 쏘는 cron 작업이 아니라, 대화·도구·로그가 있는 실행입니다.

### 다섯 가지 일정 방식

지정한 날짜에 한 번, 매일 정해진 시각, 고른 요일마다 매주, 매월 지정한 날짜, 또는 임의의 cron 표현식. 모든 일정은 서버가 아닌 직접 설정한 시간대를 따릅니다.

### 결과는 필요한 곳으로

에이전트는 자신의 도구와 함께 실행되므로, 보고서를 작성한 그대로 내보낼 수 있습니다: Telegram으로 판매 그룹에 보내는 메시지, 이메일, 운영자에게 보내는 알림, Drive 표의 한 행까지.

### 기다릴 수 있다면, 절반 비용으로

심플 에이전트를 Batch API로 전환하면 실행이 제공사의 배치 큐를 거칩니다 — 약 50% 저렴하고 24시간 안에 완료됩니다. Anthropic과 OpenAI 모델에 적용됩니다.

### 원한다면, 실행 사이의 메모리

매번 새 대화로 시작하거나, 최근 대화에 계속 이어서 에이전트가 지난번을 기억하게 하거나, 지정한 대화에 게시할 수 있습니다.

### 멈추는 시점은 직접 정합니다

만료일이나 최대 실행 횟수를 정하고, 나란히 실행할 메시지 수를 1개부터 10개까지 고르세요.

### 모든 실행이 기록에 남습니다

각 실행은 상태, 시작과 종료 시각, 그리고 모든 메시지의 답변이나 오류를 토큰·비용과 함께 보관합니다 — 설정 › 로그에도 함께 모입니다.

## 모든 일정 옵션

Create Task 대화상자가 제공하는 것을 필드별로.

### 일정

- 일회성, 지정한 날짜와 시각
- 매일, 지정한 시각
- 매주, 체크한 요일마다
- 매월, 지정한 날짜
- 사용자 지정 cron 표현식
- 모든 시간대

### 실행

- 즉시 실행, 한 번에 1~10개 메시지
- Batch API, 약 50% 저렴, 24시간 이내
- Anthropic 또는 OpenAI 모델을 쓰는 심플 에이전트용 Batch
- Human Review 단계가 있는 에이전트는 예약할 수 없음

### 입력과 대화

- 한 줄에 메시지 하나, 각각 개별 항목
- 실행마다 새 대화
- 또는 최근 대화에 이어서
- 또는 ID로 지정한 대화

### 제한

- 만료 날짜와 시각
- 최대 실행 횟수
- 목록에 표시되는 실행 횟수, 예: 6/12

### 제어

- 지금 실행
- 일시중지와 재개
- 취소
- 편집 또는 삭제
- 검색, 상태나 모드별 필터

### 기록과 로그

- 모든 실행과 모든 메시지의 상태
- 각 답변이나 오류의 전체 내용
- 메시지별, 실행별 토큰과 비용
- 워크스페이스 로그의 Scheduler Runs 탭

## Cron과 스크립트 대 스케줄러

같은 아침 보고서를 두 가지 방식으로.

| 2pm.space 없이 | 2pm.space와 함께 |
| --- | --- |
| 질문 하나를 하기 위해 cron 작업, 스크립트, 계속 살려 둬야 할 서버까지. | 에이전트를 고르고, 질문을 쓰고, 시간을 정하면 끝. |
| 새벽 3시에 실행이 실패했는데 일주일 뒤에야 알게 됩니다. | 각 실행의 상태와 오류가 작업 기록에 남습니다. |
| 모든 보고서가 처음부터 다시 시작됩니다. | 최근 대화에 이어서, 에이전트가 지난번을 기억합니다. |
| 내일까지 아무도 필요 없는 작업에 정가를 다 냅니다. | Batch API 실행은 비용이 약 절반입니다. |

## 스케줄러 관련 질문

첫 보고서를 자동화하기 전에 사람들이 묻는 것들.

### 무엇을 예약할 수 있나요?

워크스페이스의 활성 에이전트라면 무엇이든 가능합니다. 받아야 할 메시지를 한 줄에 하나씩 쓰면, 실행마다 이를 전송하고 답변을 기록합니다.

### 결과는 어떻게 전달받나요?

에이전트 자신의 도구를 통해서입니다. Telegram Send Message, Gmail, Notify Operators를 부여하고 메시지에서 결과를 어디로 보낼지 지정하세요. 모든 답변은 작업의 실행 기록에도 남습니다.

### Batch API 모드란 무엇인가요?

실행의 메시지를 곧바로 답변하는 대신 모델 제공사의 배치 큐로 보냅니다. 비용은 약 절반이며 24시간 이내에 완료됩니다. Anthropic이나 OpenAI 모델을 쓰는 심플 에이전트에서 작동합니다 — 에이전틱 워크플로는 다중 턴 실행이 필요하므로 항상 즉시 실행됩니다.

### 어느 시간대를 사용하나요?

작업에서 직접 고른 시간대이며, 기본값은 브라우저의 시간대입니다. 매일·매주·매월 시각은 그 시간대 기준으로 해석됩니다.

### Human Review 단계가 있는 에이전트를 예약할 수 있나요?

아니요. 예약된 실행은 승인해 줄 사람이 없으므로, 워크플로에 Human Review 노드가 있는 에이전트는 대화상자에서 예약할 수 없습니다.

### 작업이 일정 횟수 실행 후 멈추게 할 수 있나요?

네. 최대 실행 횟수, 만료일, 또는 둘 다 설정할 수 있습니다. 언제든 작업을 일시중지, 재개, 취소할 수도 있습니다.
