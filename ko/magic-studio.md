## Magic Studio: 브랜드에 맞는 AI 이미지

## 상품 사진에서 캠페인 비주얼까지

세 단계, 그리고 각 단계를 따로 다시 실행할 수 있습니다.

1. **가진 것을 올리기** — 컴퓨터, 드라이브 또는 브랜드에 등록된 이미지 중 상품 사진 하나, 그리고 프롬프트 — 대충 써도 괜찮습니다. 각각 별도의 노드가 될 수도 있고, 이미지 단계의 참조 이미지가 될 수도 있습니다.
2. **단계 연결하기** — 프롬프트는 생성에, 사진은 이미지 편집에 연결하고, 단계마다 모델을 고른 뒤 비율, 해상도, 품질, 생성 개수를 설정하세요.
3. **마음에 들 때까지 다시 실행** — 다시 생성하면 이전 결과를 덮어쓰지 않고 옆에 새 결과가 생겨, 모든 시도가 캔버스에 남습니다. 배경을 제거하거나, 결과를 더 편집하거나, 다운로드하세요.

## 다시 필요해질 이미지를 위해

프롬프트 입력창이 아니라, 모든 이미지가 어떻게 만들어졌는지 기억하는 캔버스입니다.

### 하나의 캔버스에 25개 모델

GPT Image, Seedream, FLUX.2, Nano Banana, Qwen Image, Ideogram, Recraft 등 — 단계마다 모델을 따로 고르므로, 두 모델을 비교하려면 브라우저 탭 두 개와 스프레드시트 대신 노드 두 개를 나란히 두면 됩니다.

### 실물 그대로의 우리 상품

모든 생성 단계에는 Brand가 연결됩니다. 프롬프트에 그 브랜드의 상품 이름을 쓰면 업로드한 제품 사진이 레퍼런스로 함께 들어가므로, 포스터 속 병이 바로 우리 병입니다.

### 브랜드를 아는 프롬프트 작성기

대충 메모만 쓰면 아트 디렉터 에이전트가 브랜드 프로필과 카탈로그를 바탕으로 제대로 된 영어 프롬프트로 바꾸고, 어떤 상품에 관한 것인지도 표시합니다. 결과는 생성 전에 프롬프트 칸에 바로 들어가므로 수정해서 쓸 수 있습니다.

### 최대 16개 레퍼런스로 편집

문장 하나와 몇 개의 레퍼런스 — 상품, 배경, 모델, 색상 팔레트 — 로 이미지 속 내용을 바꾸고, 필요할 때는 원본 크기를 유지하세요.

### 모든 시도를 보관, 누끼까지

다시 생성은 같은 설정으로 이전 노드 옆에 새 노드를 추가하므로, 이전 결과를 그대로 두고 비교할 수 있습니다. 결과의 배경을 제거하면 누끼 이미지가 원본 옆에 추가되어 제품 사진과 마켓플레이스 등록에 바로 쓸 수 있습니다.

### 함께 만들고, 나중에 추적

팀이 같은 캔버스를 실시간으로 편집하고, 모든 이미지는 어떤 단계와 소스에서 나왔는지 기록을 남깁니다 — 잘 나온 이미지를 다시 만들 수 있습니다.

## 모델, 단계, 출력

만드는 작업을 모두 커버하는지 판단하기 전에 보는 전체 목록.

### 모델

- OpenAI — GPT Image 2, 2.5
- ByteDance — Seedream 5 Pro, 4
- Black Forest Labs — FLUX.2, Flux
- Google — Nano Banana, 2, Pro
- Alibaba, Ideogram, Recraft, HiDream, Krea, Bria, ImagineArt

### 단계

- 생성 — 실행당 1~4장
- 이미지 편집 — 프롬프트와 최대 16개 레퍼런스
- 다시 생성 — 같은 설정으로 이전 노드 옆에 새 노드
- 모든 결과에 배경 제거
- 업로드 또는 드라이브에서 이미지 입력

### 출력

- 1:1, 3:2, 2:3, 16:9, 9:16, 4:3, 3:4, 21:9
- 또는 256~4096px 사용자 지정 크기
- 1K 또는 2K 해상도
- 초안부터 최고 수준까지의 품질
- 반복 가능한 결과가 필요할 때 고정 시드

### Brand

- 생성 단계마다 Brand 하나
- 프롬프트에 상품이 언급되면 제품 사진 첨부
- 브랜드 프로필과 카탈로그를 바탕으로 프롬프트 재작성
- 재작성은 프롬프트 칸에 들어가며, 생성 전에 수정 가능

### 모든 결과물에서

- 배경 제거
- 추가 편집
- 다운로드
- 이미지 라이브러리에 보관되어 게시물에 바로 선택 가능

### 팀

- 하나의 캔버스에서 실시간 공동 편집
- 모든 이미지의 소스와 단계 기록
- 다른 작업물과 함께 드라이브에 보관되는 캔버스
- 워크스페이스별 사용량 집계 — 제공사 키 불필요

## Magic Studio에 관한 질문

상품 사진 작업을 옮기기 전에 팀들이 묻는 것들입니다.

### 어떤 이미지 모델을 쓸 수 있나요?

11개 제작사의 25개 모델입니다. OpenAI의 GPT Image 2와 2.5, ByteDance의 Seedream, Black Forest Labs의 FLUX.2와 Flux, Google의 Nano Banana, Alibaba의 Qwen Image, Ideogram, Recraft, HiDream, Krea, 라이선스 데이터로 학습한 Bria FIBO, 그리고 ImagineArt까지. 캔버스의 생성 단계마다 모델을 따로 고르므로, 캔버스 하나에서 여러 모델을 비교할 수 있습니다.

### 모델 제공사마다 계정이 필요한가요?

아니요. 모든 모델이 플랫폼을 통해 실행되므로, 모아야 할 제공사 키도 별도 청구서도 없습니다. 생성은 여기서 쓰는 다른 AI처럼 워크스페이스 사용량으로 집계됩니다.

### 우리 상품이 원래 모습 그대로 나오나요?

각 생성 단계에는 Brand가 연결됩니다. 프롬프트에 그 브랜드의 상품 이름이 나오면 레퍼런스 사진, 즉 업로드한 제품 사진이 요청에 자동으로 첨부되므로, 모델이 추측하지 않고 실제 상품을 바탕으로 작업합니다. 그 밖의 모든 것은 이미지 편집 단계가 자체적으로 최대 16개의 레퍼런스 이미지를 받습니다.

### 프롬프트를 잘 못 쓰는데, 문제가 되나요?

생각보다 문제가 되지 않습니다. 대충 메모만 쓰면 아트 디렉터 에이전트가 브랜드 프로필과 상품 카탈로그를 바탕으로 완성된 프롬프트로 재작성하고 — 이미지 모델이 가장 잘 이해하는 영어로 — 어떤 상품에 관한 것인지도 표시합니다. 재작성 결과는 생성 전에 프롬프트 칸에 바로 들어가므로 수정하거나 덮어쓸 수 있습니다.

### 영상도 만들 수 있나요?

영상은 Storyboard에서 만듭니다. Storyboard의 샷에는 잘 렌더링하는 데 필요한 카메라, 액션, 인물 정보가 담깁니다. 거기서 그리는 패널은 Magic Studio와 같은 이미지 모델을 씁니다.

### 팀이 같은 캔버스에서 작업할 수 있나요?

네. 캔버스는 실시간으로 함께 편집하며, 모든 이미지는 어떤 단계와 소스에서 나왔는지 기록을 남깁니다. 완성된 이미지는 다운로드하거나, 이미지 라이브러리에서 골라 콘텐츠 캘린더의 게시물에 쓸 수 있습니다.
