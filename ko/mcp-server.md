## 여러분의 워크스페이스가, AI 클라이언트 안으로

API 키 하나로 Claude Code, Cursor, 또는 모든 MCP 클라이언트를 2pm.space에 연결하세요. 에이전트를 만들고, 워크플로를 고치고, Drive 표를 채우고, 보드에 차트를 넣어 달라고 요청하세요 — 앱이 쓰는 것과 같은 작업으로 처리되며, 키가 허용하는 범위 안에서만 이루어집니다.

[무료로 시작하기](https://2pm.space/signup)

## 세 단계로 연결하기

키, 스니펫, 요청.

1. **API 키 만들기** — Settings › API Keys & MCP에서 키를 만들고 무엇을 할 수 있는지 정하세요. 키는 만든 사람보다 더 많은 권한을 가질 수 없습니다.
2. **스니펫 붙여넣기** — Claude Code나 Cursor용 서버 블록 — 엔드포인트와 X-API-Key 헤더에 담긴 키 — 을 복사해 클라이언트의 설정 파일에 붙여넣으세요.
3. **작업을 요청하기** — 원하는 것을 클라이언트에게 말하세요. 워크스페이스의 도구를 나열하고, 해당 작업의 플레이북을 읽은 뒤, 단계별로 도구를 호출합니다.

## 워크스페이스 전체를, 도구로

읽기 전용 창이 아니라, 앱이 수행하는 것과 같은 작업입니다.

### 모든 MCP 클라이언트

Streamable HTTP를 통한 원격 서버이므로 Claude Code, Cursor, MCP를 지원하는 다른 모든 클라이언트와 작동합니다. 앱 안의 설정 페이지에서 각 클라이언트용 스니펫을 제공합니다.

### 300개가 넘는 도구

에이전트와 그 캔버스, 도구, 스킬, 지식, 가드레일, 메모리, Drive 문서, 표, 마인드맵, 스토리보드, 데이터 소스와 보드, 브랜드, 콘텐츠 캘린더, 채널까지.

### 키로 제한됩니다

서버는 키의 권한이 허용하는 도구만 나열하며, 키는 만든 멤버의 권한으로 동작합니다. 읽기 권한만 준 키는 아무것도 바꿀 수 없습니다.

### 긴 작업을 위한 플레이북

에이전트 만들기, RAG 설정, 데이터 소스 정리, 콘텐츠 캘린더 기획 등 19개의 기본 제공 가이드로, 클라이언트가 시작하기 전에 읽습니다.

### 에디터에서 다루는 나의 Drive

문서를 만들고 편집하고, Drive 표를 채우고, 마인드맵에 노드를 추가하거나 스토리보드에 샷을 추가하세요 — 변경 사항은 팀을 위해 앱에 그대로 남습니다.

### 데이터와 보드

연결된 데이터베이스를 시맨틱 모델을 통해 조회하고, 보드를 만들어 차트를 추가하거나, 모델의 측정값과 관계를 다듬으세요.

## 서버가 노출하는 것

연결, 키, 그리고 클라이언트가 작업할 수 있는 워크스페이스의 영역.

### 연결

- Streamable HTTP를 통한 원격 MCP 서버
- 설정 페이지에 표시되는 엔드포인트 하나
- Claude Code와 Cursor를 위한 스니펫
- /.well-known/ai-catalog.json에서 확인 가능

### 키와 권한

- X-API-Key 헤더의 워크스페이스 API 키
- 키는 만든 멤버의 권한으로 동작
- 만든 사람보다 넓지 않은 권한
- 선택적 만료일
- 허용된 도구만 나열

### 에이전트

- 에이전트 생성, 설정, 삭제
- 워크플로 캔버스를 노드별로 편집
- 도구, 스킬, 지식 할당
- 캔버스 버전 저장과 복원
- 테스트 실행과 추적 확인

### Drive와 콘텐츠

- 문서, 폴더, Drive 표
- 마인드맵 — 노드, 도형, 표
- 스토리보드 — 씬, 샷, 프레임
- 브랜드와 그 상품, 이미지
- 콘텐츠 캘린더 슬롯

### 데이터

- 데이터 소스, 표, 범위
- 시맨틱 모델: 큐브, 측정값, 조인
- CubeQL 또는 SQL 쿼리
- BI 보드, 탭, 차트, 필터

### 채널과 받은편지함

- 채널과 그 설정
- 대화와 그 메시지

## MCP 관련 질문

클라이언트를 연결하기 전에 사람들이 묻는 것들.

### 어떤 클라이언트가 작동하나요?

Streamable HTTP를 통한 원격 MCP 서버를 지원하는 모든 클라이언트입니다. 설정 페이지에서 Claude Code와 Cursor용 스니펫을 바로 제공합니다.

### 클라이언트가 내 워크스페이스에서 무엇을 할 수 있나요?

키가 허용하는 것이라면 무엇이든요: 에이전트를 만들고 테스트하기, Drive 문서·표·마인드맵·스토리보드 편집하기, 연결된 데이터베이스 조회하기, 보드·브랜드·콘텐츠 캘린더·채널 설정 관리하기. 클라이언트가 보는 도구 목록은 이미 그 권한에 맞게 필터링되어 있습니다.

### AI 클라이언트에게 키를 주어도 안전한가요?

키는 만든 멤버의 권한으로 동작하며, 그 사람에게 없는 권한은 가질 수 없습니다. MCP에는 승인 프롬프트가 없으므로 키의 권한이 곧 관문입니다: 읽기만 해야 할 클라이언트에는 읽기 권한만 부여하고, 언젠가 멈춰야 할 키에는 만료일을 설정하세요.

### 내 크레딧을 사용하나요?

대부분의 도구는 단순한 읽기와 쓰기입니다. 캘린더 개요, 이미지, 에이전트 테스트 실행처럼 무언가를 생성하는 도구는 앱에서와 똑같이 워크스페이스 크레딧을 사용합니다.
