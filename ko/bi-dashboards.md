## 질문에서 보드까지, 세 단계

묻고, 고정하고, 공유하세요.

1. **묻거나, SQL을 직접 쓰세요** — Ask Data는 일상 언어로 물으면 차트와 함께 답합니다. SQL Lab에서는 직접 쿼리를 쓰거나, 설명만으로 AI가 초안을 작성하게 할 수 있습니다.
2. **보드에 고정하세요** — 차트를 보드와 탭에 고정하세요 — 새로 만들거나 기존 것을 골라도 됩니다. 타일은 그림이 아니라 쿼리 자체를 유지합니다.
3. **공유하세요** — 필요한 사람과 보드를 공유하세요. 필터는 URL에 담기므로, 링크를 열면 보고 있던 화면 그대로 열립니다.

## 정직함을 잃지 않는 보드

모든 타일은 데이터 모델에 대한 쿼리이지, 쿼리의 스크린샷이 아닙니다.

### 매출의 정의는 하나

타일은 Ask Data와 같은 시맨틱 모델에 쿼리하므로, 한 번 정의한 측정값은 모든 차트와 모든 보드에서 같은 의미를 가집니다.

### 모든 타일에 닿는 필터

모델이 필터 가능으로 표시한 차원이라면 어떤 것에든 보드 필터를 추가하세요 — 텍스트, 선택, 다중 선택, 날짜, 날짜 범위 — 이를 사용하는 모든 타일이 다시 실행됩니다. 반영할 수 없는 타일은 그렇다고 표시합니다.

### 이번 기간과 지난 기간

이전 기간, 작년 같은 기간, 또는 직접 고른 범위와 비교하고, 일·주·월·분기·연 단위로 시간을 다시 묶으세요.

### 그리는 아홉 가지 방법

막대, 가로 막대, 누적, 100% 누적, 선, 영역, 원형, 산점도, 단일 숫자 카드 — 타일마다 축, 범례, 데이터 레이블, 시리즈 색상을 설정할 수 있습니다.

### 정확함을 원한다면 SQL Lab

모델에 대해 CubeQL을 작성하고, 컴파일된 네이티브 SQL을 확인하고, 쿼리를 저장하고, 마음에 드는 쿼리를 재사용 가능한 파생 큐브로 만드세요.

### 에이전트도 보드를 만들 수 있습니다

BI Board 도구를 쓰면 에이전트가 보드를 만들고, 차트를 추가하고, 타일의 데이터를 읽을 수 있습니다 — 같은 작업을 Claude Code나 Cursor용 MCP 서버에서도 할 수 있습니다.

## 보드가 지원하는 것

차트, 형식, 필터, 시간 — 전체 목록.

### 차트 유형

- 막대와 가로 막대
- 누적과 100% 누적
- 선과 영역
- 원형
- 산점도
- 숫자 카드

### 형식

- 숫자, 통화, 퍼센트 또는 바이트
- 소수 자릿수, 축약형 K / M / B, 구분 기호
- 접두사와 접미사
- 축 제목, 최솟값, 최댓값, 로그 스케일
- 범례, 데이터 레이블, 시리즈 색상
- 필드별로 모델 형식을 재정의

### 필터

- 모델의 필터 가능한 모든 차원에
- 텍스트, 선택, 다중 선택, 날짜, 날짜 범위
- 같음, 같지 않음, 포함, ~로 시작, ~로 끝남
- 공유 가능한 화면을 위해 URL에 유지
- 타일의 카테고리 내 검색

### 시간

- 이전 기간과 비교
- 또는 작년 같은 기간
- 또는 사용자 지정 범위
- 일, 주, 월, 분기, 연 단위로 그룹화
- 계속 상대적으로 유지되는 상대 날짜 구간

### SQL Lab

- 시맨틱 모델에 대한 CubeQL
- 컴파일되는 네이티브 SQL
- 설명만으로 AI가 작성하는 쿼리 초안
- 저장된 쿼리
- 파생 큐브로 저장한 쿼리

### 보드와 공유

- 보드마다 여러 탭, 이름 변경과 순서 변경
- 드래그로 크기를 조절하는 레이아웃
- 필요할 때 타일 새로고침
- 팀원과 공유
- 에이전트와 MCP 클라이언트도 보드를 만들 수 있음

## BI 대시보드 관련 질문

첫 보드를 만들기 전에 사람들이 묻는 것들.

### 보드는 어떤 데이터베이스를 쓸 수 있나요?

Ask Data가 지원하는 모든 연결입니다: PostgreSQL, MySQL, Redshift, ClickHouse, Snowflake, BigQuery. 보드는 시맨틱 모델을 통해 이를 조회합니다.

### 차트는 어떻게 보드에 들어가나요?

Ask Data나 SQL Lab에서요: 차트가 원하는 대로 나오면 Pin to board를 선택하고 보드와 탭을 고르세요. 타일은 그림이 아니라 쿼리를 그대로 유지합니다.

### 필터는 모든 타일에 적용되나요?

보드 필터는 해당 차원을 쓰는 모든 타일에 적용되어 다시 실행합니다. 필터를 반영할 수 없는 타일은 필터링되지 않은 수치를 조용히 보여주는 대신 헤더에 그 사실을 표시합니다.

### 지난달이나 작년과 비교할 수 있나요?

네. 비교 기능을 켜고 이전 기간, 작년 같은 기간, 또는 사용자 지정 범위를 고르세요. 날짜 구간이 있는 타일은 두 기간을 모두 보여줍니다.

### 에이전트가 보드를 쓸 수 있나요?

네. BI Board 도구를 쓰면 에이전트가 보드를 만들고, 차트를 추가하고, 타일의 데이터를 읽을 수 있습니다. 같은 작업을 MCP 서버를 통해 Claude Code나 Cursor에서도 할 수 있습니다.
