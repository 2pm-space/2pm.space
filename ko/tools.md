## 다섯 가지 도구, 하나의 목록

에이전트가 닿아야 할 것이 무엇이든, 건네줄 방법이 있습니다.

### 바로 쓸 수 있는 도구 60개

웹 검색, Wikipedia와 ArXiv, 헤드리스 브라우저, Gmail과 Google Calendar, GitHub, Telegram, 텍스트 음성 변환, BI 보드, 그리고 내 Drive까지 — 카탈로그의 카드 하나하나이며, 대부분 추가하는 즉시 작동합니다.

### 모든 HTTP API

엔드포인트를 설명하면 — 메서드, URL, 헤더, 인증, 에이전트가 보낼 JSON — 도구가 됩니다. GET, POST, PUT, PATCH, DELETE를 지원하며 베어러 토큰 또는 API 키 인증을 씁니다.

### 직접 만든 Python

함수를 작성하고 입력 스키마를 지정하면 타임아웃이 있는 샌드박스에서 실행됩니다 — 인터넷 접근을 허용하지 않으면 오프라인 상태입니다.

### 모든 MCP 서버

서버 URL만 지정하면 그 서버가 제공하는 도구가 자동으로 검색됩니다. 하나씩 켜고 끄고, 쓰기 작업을 하는 도구는 승인을 요구하세요.

### 도구가 되는 에이전트

한 에이전트를 다른 에이전트에 노출하세요: 작성자는 리서처에게 물을 수 있고, 판매 에이전트는 재고 확인 에이전트에게 물을 수 있습니다 — 각자 자신만의 프롬프트, 모델, 도구를 그대로 유지한 채로요.

### 누가 무엇을 쥘지는 직접 정합니다

도구를 에이전트별로 부여하거나 전역으로 설정하고, 삭제하지 않고 끄고, 결과를 캐시하고, 실행 전 사람의 승인을 요구하세요.

## 도구 관련 질문

첫 시스템을 연결하기 전에 사람들이 묻는 것들.

### 기본 제공 도구는 몇 개인가요?

현재 60개이며, 검색, 지식, 컴퓨트, 데이터, AI 및 미디어, 금융, 유틸리티, 생산성, MCP 서버, Drive, 연동으로 분류됩니다 — 전체 목록은 이 페이지에 있습니다. 이 외에도 모든 HTTP API, Python 함수, MCP 서버가 도구가 될 수 있습니다.

### API 키가 필요한가요?

일부 도구는 제공사의 키가 필요합니다 — Tavily, Serper, Gmail, GitHub 등 키 아이콘이 표시된 도구들입니다. DuckDuckGo, Wikipedia, ArXiv, Web Fetch, Playwright 브라우저, Drive 도구를 비롯해 많은 도구는 키 없이도 작동합니다.

### 도구가 실행되기 전에 승인을 기다리게 할 수 있나요?

네. 사람이 확인해야 하는 도구 — 보통 전송, 쓰기, 삭제를 하는 도구 — 에 사람의 승인 필요를 켜면, 누군가 승인할 때까지 에이전트의 실행이 멈춥니다. MCP 서버나 연동의 경우 승인은 검색된 도구별로 설정합니다.

### 직접 만든 MCP 서버를 연결할 수 있나요?

네. 서버의 URL, 전송 방식, 인증 정보로 MCP 도구를 추가하세요. 그 서버가 제공하는 도구가 검색되어 목록에 나타나고, 하나씩 켜거나 끌 수 있습니다. N8N, Slack, Notion, GitHub, Google Drive, WordPress를 위한 프리셋도 카탈로그에 있습니다.

### 한 에이전트가 다른 에이전트를 도구로 쓸 수 있나요?

네. Agent as tool을 만들고 에이전트를 고르세요. 부여받은 어떤 에이전트든 작업을 맡기고 답변을 활용할 수 있으며, 원래 에이전트는 자신만의 프롬프트, 모델, 도구를 그대로 유지합니다.

### Viettel Post와 KiotViet은 어디에 쓰이나요?

기본 제공 연동입니다. 계정을 한 번만 연결하면 에이전트가 배송비 견적, 배송 생성, 재고 확인, 주문 조회 같은 작업을 도구로 사용할 수 있습니다.
