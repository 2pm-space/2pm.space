# BI Dashboard ที่สร้างจากคำถามภาษาธรรมดา

## แดชบอร์ดที่เริ่มจาก คำถามหนึ่งข้อ

ถามฐานข้อมูลด้วยภาษาธรรมดา ปักหมุดกราฟ แล้วมันจะเข้าไปอยู่ในบอร์ดที่ทีมเปิดไว้ตลอด — มีแท็บ ตัวกรองที่ถึงทุกไทล์ และการเทียบกับช่วงก่อนหน้าในคลิกเดียว

## จากคำถามสู่บอร์ดในสามขั้นตอน

ถาม ปักหมุด แชร์

1. **ถาม หรือเขียน SQL เอง** — Ask Data ตอบเป็นภาษาธรรมดาพร้อมกราฟ SQL Lab ให้คุณเขียนคิวรีเอง หรือให้ AI ร่างจากคำอธิบาย
2. **ปักหมุดลงบอร์ด** — ปักหมุดกราฟลงบอร์ดและแท็บ — ใหม่หรือที่มีอยู่ ไทล์เก็บคิวรีไว้ ไม่ใช่แค่ภาพ
3. **แชร์** — แชร์บอร์ดให้คนที่ต้องใช้ ตัวกรองอยู่ใน URL ลิงก์จึงเปิดมาที่มุมมองเดียวกับที่คุณดูอยู่

## บอร์ดที่ซื่อตรงเสมอ

ทุกไทล์คือคิวรีบนโมเดลข้อมูลของคุณ ไม่ใช่ภาพหน้าจอของมัน

### นิยามรายได้เดียว

ไทล์คิวรีโมเดลเชิงความหมายเดียวกับที่ Ask Data ใช้ ตัวชี้วัดที่นิยามครั้งเดียวจึงมีความหมายเดียวกันบนทุกกราฟและทุกบอร์ด

### ตัวกรองที่ถึงทุกไทล์

เพิ่มตัวกรองบอร์ดบนมิติใดก็ได้ที่โมเดลกำหนดว่ากรองได้ — ข้อความ ตัวเลือก หลายตัวเลือก วันที่ หรือช่วงวันที่ — แล้วทุกไทล์ที่ใช้มิตินั้นจะรันใหม่ ไทล์ไหนใช้ไม่ได้ก็จะบอกไว้

### ช่วงนี้เทียบกับช่วงก่อน

เทียบกับช่วงก่อนหน้า ช่วงเดียวกันปีที่แล้ว หรือช่วงที่คุณเลือก และจัดกลุ่มเวลาใหม่เป็นวัน สัปดาห์ เดือน ไตรมาส หรือปี

### เก้าวิธีในการวาด

แท่ง แท่งแนวนอน ซ้อน ซ้อน 100% เส้น พื้นที่ วงกลม กระจาย และการ์ดตัวเลขเดียว — ตั้งค่าแกน คำอธิบาย ป้ายข้อมูล และสีชุดข้อมูลได้รายไทล์

### SQL Lab สำหรับคนที่ต้องการความแม่นยำ

เขียน CubeQL บนโมเดล ดู SQL ต้นฉบับที่มันคอมไพล์ออกมา บันทึกคิวรี และเปลี่ยนคิวรีที่ดีเป็น derived cube ที่ใช้ซ้ำได้

### เอเจนต์ก็สร้างบอร์ดได้

เครื่องมือ BI Board ให้เอเจนต์สร้างบอร์ด เพิ่มกราฟ และอ่านข้อมูลของไทล์ — และการทำงานเดียวกันนี้มีบน MCP server ของเราสำหรับ Claude Code หรือ Cursor

## บอร์ดรองรับอะไรบ้าง

กราฟ รูปแบบ ตัวกรอง และเวลา — รายการเต็ม

### ประเภทกราฟ

- แท่งและแท่งแนวนอน
- ซ้อนและซ้อน 100%
- เส้นและพื้นที่
- วงกลม
- กระจาย
- การ์ดตัวเลข

### การจัดรูปแบบ

- ตัวเลข สกุลเงิน เปอร์เซ็นต์ หรือไบต์
- ทศนิยม แบบย่อ K / M / B และตัวคั่น
- คำนำหน้าและคำต่อท้าย
- ชื่อแกน ค่าต่ำสุด ค่าสูงสุด และสเกลลอการิทึม
- คำอธิบาย ป้ายข้อมูล และสีชุดข้อมูล
- เขียนทับรูปแบบของโมเดลรายฟิลด์

### ตัวกรอง

- บนมิติที่กรองได้ของโมเดล
- ข้อความ ตัวเลือก หลายตัวเลือก วันที่ และช่วงวันที่
- เท่ากับ ไม่เท่ากับ มีคำว่า ขึ้นต้นด้วย ลงท้ายด้วย
- เก็บไว้ใน URL เพื่อแชร์มุมมอง
- ค้นหาในหมวดหมู่ของไทล์

### เวลา

- เทียบกับช่วงก่อนหน้า
- หรือช่วงเดียวกันปีที่แล้ว
- หรือช่วงที่กำหนดเอง
- จัดกลุ่มตามวัน สัปดาห์ เดือน ไตรมาส หรือปี
- ช่วงวันที่แบบสัมพัทธ์ที่ยังคงสัมพัทธ์

### SQL Lab

- CubeQL บนโมเดลเชิงความหมาย
- SQL ต้นฉบับที่คอมไพล์ออกมา
- AI ร่างคิวรีจากคำอธิบาย
- คิวรีที่บันทึกไว้
- บันทึกคิวรีเป็น derived cube

### บอร์ดและการแชร์

- หลายแท็บต่อบอร์ด เปลี่ยนชื่อและจัดลำดับใหม่ได้
- เลย์เอาต์ลากวางปรับขนาดได้
- รีเฟรชไทล์เมื่อต้องการ
- แชร์กับเพื่อนร่วมทีม
- เอเจนต์และ MCP client สร้างบอร์ดได้

## คำถามเกี่ยวกับ BI Dashboard

สิ่งที่คนถามก่อนสร้างบอร์ดแรก

### บอร์ดใช้ฐานข้อมูลอะไรได้บ้าง?

ทุกการเชื่อมต่อที่ Ask Data รองรับ: PostgreSQL, MySQL, Redshift, ClickHouse, Snowflake และ BigQuery บอร์ดคิวรีผ่านโมเดลเชิงความหมายของคุณ

### กราฟขึ้นบอร์ดได้อย่างไร?

จาก Ask Data หรือ SQL Lab: เมื่อกราฟดูใช้ได้ เลือก Pin to board แล้วเลือกบอร์ดและแท็บ ไทล์เก็บคิวรีไว้ ไม่ใช่แค่ภาพ

### ตัวกรองใช้ได้กับทุกไทล์ไหม?

ตัวกรองบอร์ดใช้กับทุกไทล์ที่คิวรีใช้มิตินั้น และรันไทล์ใหม่ ไทล์ที่กรองด้วยมิตินั้นไม่ได้จะบอกไว้ที่หัวไทล์ แทนการแสดงตัวเลขที่ไม่ได้กรองแบบเงียบๆ

### เทียบกับเดือนที่แล้วหรือปีที่แล้วได้ไหม?

ได้ เปิดการเทียบแล้วเลือกช่วงก่อนหน้า ช่วงเดียวกันปีที่แล้ว หรือช่วงที่กำหนดเอง ไทล์ที่มีช่วงวันที่จะแสดงทั้งสองช่วง

### เอเจนต์ใช้บอร์ดได้ไหม?

ได้ เครื่องมือ BI Board ให้เอเจนต์สร้างบอร์ด เพิ่มกราฟ และอ่านข้อมูลของไทล์ และการทำงานเดียวกันนี้ใช้ได้กับ Claude Code หรือ Cursor ผ่าน MCP server
