## เชื่อมเข้ากับ ทุกระบบที่คุณใช้อยู่แล้ว

ช่องทางแชท HTTP API ฐานข้อมูล MCP server และโค้ดในแซนด์บ็อกซ์ — ด้วยการอธิบาย ไม่ใช่การเขียนโค้ด เอเจนต์จึงเข้าถึงระบบที่มีคำตอบได้ แทนที่จะขอโทษว่าไม่รู้

## หกวิธีเข้าถึงระบบส่วนที่เหลือของคุณ

ไม่ว่าระบบจะเป็นอะไร หนึ่งในวิธีเหล่านี้รองรับอยู่แล้ว

### API ใดก็ได้ แค่อธิบาย ไม่ต้องเขียนโค้ด

ให้เครื่องมือมี URL เมธอด auth header และ JSON Schema สำหรับพารามิเตอร์ แล้วให้สิทธิ์แก่เอเจนต์ที่ต้องเรียกใช้ ไม่ต้อง deploy อะไรนอกจาก endpoint ที่คุณมีอยู่แล้ว

### เขียนโค้ด เมื่ออธิบายยากกว่า

Python ในแซนด์บ็อกซ์ที่เรียกใช้เป็นเครื่องมือได้ อาร์กิวเมนต์เข้ามาทาง ARGS และผลลัพธ์คือสิ่งที่มัน print ออกมา สำหรับการจัดรูปแบบ การแยกวิเคราะห์ และการคำนวณที่เขียนเร็วกว่าอธิบายให้โมเดลฟัง

### MCP ทั้งสองทิศทาง

ชี้เครื่องมือไปที่ MCP server ใดก็ได้ ค้นหาเครื่องมือของมันในคลิกเดียว แล้วเปิด ปิด หรือบังคับให้อนุมัติทีละตัว — และควบคุมเวิร์กสเปซนี้จาก MCP client ภายนอก รวมถึง coding agent ที่สร้างเอเจนต์ให้คุณ

### เอเจนต์เป็นเครื่องมือ

เปิดเอเจนต์ตัวหนึ่งให้อีกตัวใช้ เอเจนต์หัวหน้ามอบงานให้เอเจนต์ผู้เชี่ยวชาญแล้วได้คำตอบแบบมีโครงสร้างกลับมา แทนที่จะต้องมีสำเนาของผู้เชี่ยวชาญอยู่ในพรอมต์ของตัวเอง

### ช่องทางก็คือการเชื่อมต่อ

Messenger, Zalo ส่วนตัว, Telegram, Pancake และวิดเจ็ตเว็บไซต์เชื่อมต่อเป็นช่องทางหลักโดยตรง ส่วนอย่างอื่นเข้ามาผ่านช่องทาง API กำหนดเอง — เว็บฮุกเข้า เว็บฮุกออก

### เหตุการณ์ส่งถึงคุณ

เหตุการณ์ในกล่องข้อความส่งไปยัง endpoint ของคุณ ข้อความใหม่จึงกระตุ้นการทำงานในระบบของคุณได้ การส่งถูกบันทึกไว้ ปลายทางที่ล่มอยู่จึงมองเห็นได้ ไม่ใช่หายไปเฉยๆ

## รายการทั้งหมด

สิ่งที่เชื่อมต่อได้วันนี้ แยกตามประเภท

### ช่องทางแชท

- Facebook Messenger และคอมเมนต์พร้อมตอบกลับแบบส่วนตัว
- Zalo ส่วนตัว และ Zalo Official Account เร็วๆ นี้
- บอต Telegram
- บัญชี Pancake
- วิดเจ็ตแชทบนเว็บไซต์
- Custom API — รับ webhook เข้า ส่ง webhook ออก

### ประเภทเครื่องมือ

- เครื่องมือในตัว รวมถึง Viettel Post, KiotViet และ WordPress
- เครื่องมือเว็บฮุก — HTTP API ใดก็ได้ ยืนยันตัวตนด้วย bearer หรือคีย์
- ฟังก์ชัน Python ในแซนด์บ็อกซ์ ออฟไลน์เว้นแต่คุณอนุญาตอินเทอร์เน็ต
- การอนุมัติโดยคนและการแคชผลลัพธ์ ต่อเครื่องมือ
- MCP server — ค้นหาเครื่องมือ เปิดหรือปิดทีละตัว
- มอบหมายงานด้วยเอเจนต์เป็นเครื่องมือ

### การเชื่อมต่อข้อมูล

- PostgreSQL และ MySQL
- Redshift และ ClickHouse
- Snowflake และ BigQuery
- เลือกตารางตอนเชื่อมต่อ — โมเดลอ่านเฉพาะตารางเหล่านั้น

### การเผยแพร่และบริการ

- เผยแพร่ไปยังเพจ Facebook และ WordPress
- ปลายทางเว็บฮุกแบบกำหนดเอง
- บัญชีแอปที่เชื่อมไว้สำหรับบริการภายนอก
- จัดส่งผ่าน Viettel Post พร้อมเก็บเงินปลายทาง

### การเข้าถึงผ่านโปรแกรม

- API key ของเวิร์กสเปซ มีสิทธิ์ตามสิทธิ์ของผู้สร้าง
- MCP endpoint ยืนยันตัวตนด้วยคีย์เดียวกัน
- เว็บฮุกขาออกตามเหตุการณ์ในกล่องข้อความ
- บันทึกทุกการเรียก พร้อมต้นทุน

### พร้อมติดตั้ง

- มาร์เก็ตเพลสเทมเพลตเอเจนต์
- เทมเพลตคัดลอกเข้าเวิร์กสเปซของคุณ แล้วแก้ไขต่อ
- ทักษะและเครื่องมือใช้ร่วมกันได้ทุกเอเจนต์
- แอปที่สร้างบนแพลตฟอร์ม ติดตั้งลงเวิร์กสเปซได้

## คำถามเรื่องการเชื่อมต่อ

สิ่งที่วิศวกรถามก่อนต่อเข้ากับระบบภายใน

### เชื่อมบริการที่ไม่อยู่ในรายการได้อย่างไร?

ด้วยเครื่องมือเว็บฮุก คุณใส่ URL เมธอด auth header และ JSON Schema สำหรับพารามิเตอร์ แล้วให้สิทธิ์แก่เอเจนต์ที่จะใช้ — หรือตั้งเป็นทั่วไปให้ทุกเอเจนต์ ไม่ต้อง deploy โค้ดฝั่งเรา และฝั่งคุณก็ไม่ต้องมีอะไรนอกจาก endpoint ที่มีอยู่แล้ว

### เอเจนต์รันโค้ดได้ไหม?

ได้ — Python ในแซนด์บ็อกซ์ เป็นเครื่องมือที่เอเจนต์เรียกใช้ได้ เหมาะกับการแปลงข้อมูลที่เขียนง่ายกว่าอธิบาย เช่น จัดรูป payload ใหม่ คำนวณสิ่งที่ไม่ควรฝากไว้กับโมเดล หรือแยกวิเคราะห์ข้อมูลที่ยุ่งยาก การเข้าถึงอินเทอร์เน็ตปิดอยู่จนกว่าคุณจะเปิด

### รองรับ MCP ไหม?

ได้ทั้งสองทาง เครื่องมือ MCP ชี้ไปที่เซิร์ฟเวอร์ใดก็ได้ ค้นหาเครื่องมือของมันในคลิกเดียว แล้วเลือกว่าตัวไหนเอเจนต์ใช้ได้และตัวไหนต้องอนุมัติ และแพลตฟอร์มยังเปิด MCP server ของตัวเอง ให้ client ภายนอก — รวมถึง coding agent — ควบคุมเวิร์กสเปซของคุณได้ ทั้งสร้างเอเจนต์ แก้เอกสาร คิวรีบอร์ด และจัดการทักษะกับเครื่องมือ

### เอเจนต์ตัวหนึ่งเรียกอีกตัวได้ไหม?

ได้ เอเจนต์เปิดเป็นเครื่องมือได้ เอเจนต์หัวหน้าจึงมอบงานให้เอเจนต์ผู้เชี่ยวชาญแล้วได้คำตอบแบบมีโครงสร้างกลับมา แทนที่จะต้องทำซ้ำสิ่งที่ผู้เชี่ยวชาญทำอยู่แล้ว

### เว็บฮุกในทิศทางกลับทำงานอย่างไร?

เหตุการณ์ในกล่องข้อความส่งไปยัง endpoint ของคุณได้ ข้อความใหม่หรือบทสนทนาที่ปิดแล้วจึงกระตุ้นการทำงานในระบบของคุณเองได้ การส่งถูกบันทึกไว้ ปลายทางที่ล่มอยู่จึงมองเห็นได้ ไม่ใช่ข้อความที่คุณไม่เคยรู้ว่ามี

### มี API ไหม?

มี API key ออกให้รายเวิร์กสเปซ และมีสิทธิ์ตามสมาชิกที่สร้าง คีย์จึงทำได้ไม่เกินคนที่อยู่เบื้องหลัง คีย์เดียวกันใช้ยืนยันตัวตนกับ MCP endpoint ด้วย
