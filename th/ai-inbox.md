## สี่ช่องทาง คิวเดียว

ช่องทางที่ลูกค้าทักคุณอยู่แล้ว — แต่ละช่องทางมีสิ่งที่ช่องทางอื่นทำไม่ได้

### Messenger

*ข้อความส่วนตัวและคอมเมนต์บนเพจ*

- ทุกเพจที่คุณเชื่อมต่อ รวมอยู่ในคิวเดียว
- ตอบคอมเมนต์ใต้โพสต์แบบสาธารณะ หรือตอบกลับทางข้อความส่วนตัว
- แสดงการ์ดโฆษณาที่พาลูกค้าเข้ามาและการ์ดสินค้าในบทสนทนา
- ดึงประวัติเดิมย้อนหลังมาให้เมื่อเพิ่มเพจ

### Telegram

*บอตของคุณ แชทส่วนตัวและแชทกลุ่ม*

- บอตของคุณเอง ตอบโดยเอเจนต์ที่คุณเลือก
- แชทกลุ่มที่แยกสมาชิกแต่ละคนเป็นผู้พูดของตัวเอง
- รูปภาพ ไฟล์ และข้อความเสียง — แปลงเสียงเป็นข้อความให้

### วิดเจ็ตเว็บไซต์

*วิดเจ็ตบนเว็บไซต์ของคุณเอง*

- สคริปต์แท็กเดียว ล็อกไว้เฉพาะโดเมนที่คุณอนุญาต
- สี คำทักทาย ปุ่มเปิดแชท และข้อความตอบด่วนในแบบของคุณ
- ฟอร์มก่อนแชท แปดภาษา กำหนดตำแหน่งแยกตามอุปกรณ์

### Zalo ส่วนตัว

*บัญชีของคุณเอง เชื่อมด้วย QR โค้ด*

- ล็อกอินด้วย QR โค้ด — ไม่ต้องมี Official Account
- แชทตัวต่อตัวและแชทกลุ่มอยู่ในคิวเดียวกัน
- ส่งคำขอเป็นเพื่อนด้วยเบอร์โทรได้จากในบทสนทนา

เชื่อมต่อได้อีก: Pancake · API แบบกำหนดเอง — รับ webhook เข้า ส่ง webhook ออก · Zalo Official Account (เร็วๆ นี้)

## ตั้งแต่ข้อความแรก จนถึงคำขอบคุณ

ลูกค้าทักมาทางช่องทางไหนก็ได้ เอเจนต์ให้คำปรึกษา รับออร์เดอร์ จองการจัดส่ง และกล่าวขอบคุณ — และเมื่อบทสนทนาเปลี่ยนทิศ มันก็รู้ว่าต้องไปทางไหน

**ลูกค้าแชทเข้ามา**

- **Messenger:** *สีฟ้ายังมีของอยู่ไหมคะ*
- **Telegram:** *ส่งไปดานังได้ไหมครับ*
- **วิดเจ็ตเว็บไซต์:** *ถ้าเอาสองชิ้นราคาเท่าไหร่คะ*
- **Zalo ส่วนตัว:** *เก็บเงินปลายทางได้ไหมคะ*

### 2pm AI ให้คำปรึกษา

เอเจนต์ตัวเดียวอยู่เบื้องหลังทุกช่องทาง ใช้ทุกอย่างที่เวิร์กสเปซของคุณรู้

- **ความรู้** — ตอบจากเอกสารและแคตตาล็อกของคุณ รวมถึงรูปสินค้า
- **ทักษะ** — คู่มือการขายของคุณ — ถามอะไร เสนออะไร และพูดด้วยน้ำเสียงแบบไหน
- **เครื่องมือ** — ค้นหาสินค้า ออร์เดอร์เก่า และค่าส่งได้ระหว่างการสนทนา
- **หน่วยความจำ** — จำสิ่งที่ลูกค้าเคยบอกไว้เมื่อครั้งก่อน
- **Customer 360** — ทุกช่องทางที่ลูกค้าเคยใช้ รวมเป็นประวัติเดียว
- **การ์ดเรล** — คุมทุกคำตอบให้อยู่ในขอบเขตที่พูดและทำได้

1. **ดำเนินการ** — ทวนรายการสินค้า เบอร์โทร และที่อยู่จัดส่งกับลูกค้าอีกครั้ง `บันทึกที่อยู่แล้ว`
2. **สร้างคำสั่งซื้อ** — ใบสั่งขายที่คิดราคาจากแคตตาล็อกของคุณ — เป็นฉบับร่างให้ทีมยืนยัน หรือส่งเข้าระบบทันที `SO-2026-48213`
3. **จองขนส่งแบบ COD** — จองกับ Viettel Post พร้อมยอดที่ต้องเก็บเงินปลายทาง หรือเก็บไว้ในใบส่งสินค้าสำหรับขนส่งของคุณเอง `COD · เลขพัสดุ`
4. **กล่าวขอบคุณ** — เมื่อมีแจ้งว่าส่งถึงแล้ว กฎตามเหตุการณ์จะส่งคำขอบคุณ — เขียนจากบทสนทนา หรือจากเทมเพลตของคุณ `ส่งถึงแล้ว → ขอบคุณแล้ว`

**ระหว่างทาง**

- **หากลูกค้าให้เบอร์โทร → เพิ่มเพื่อนบน Zalo.** เบอร์จะถูกปักไว้กับผู้ติดต่อ แล้ว Zalo ส่วนตัวของคุณจะส่งคำขอเป็นเพื่อน — ทยอยส่ง ระหว่าง 08:00–20:00 น. เมื่อลูกค้ากดรับ แชท Zalo จะรวมเข้ากับลูกค้าคนเดิม `+84 ••• 412 → Zalo`
- **หากลูกค้าเงียบไป → Care ติดตามต่อ.** Care agent อ่านบทสนทนาแล้วติดตามผลหลังลูกค้าเงียบไปตามเวลาที่คุณตั้ง — เคารพช่วงงดส่งของคุณ จำกัดจำนวนต่อคน และอยู่ในกรอบเวลาส่งข้อความของช่องทาง `เงียบ 2 ชม. → ติดตามผล`
- **หากลูกค้าขอคุยกับคน → ทีมของคุณเข้าช่วย.** Agent ส่งการแจ้งเตือนแบบพุชที่เปิดบทสนทนาให้ทีมของคุณ ใครก็ตอบตรงนั้นได้ — หรือหยุด AI เพื่อรับบทสนทนาไว้เอง `แจ้งเตือน → หยุด AI`
- **หากลูกค้าสแปมหรือพูดจาหยาบคาย → เอเจนต์หยุดตอบ.** ปิด AI และ Care สำหรับบทสนทนานั้น แล้วทิ้งเหตุผลสั้นๆ หนึ่งบรรทัดไว้ให้ทีม ใครก็เปิดกลับได้จากกล่องข้อความ `ปิด AI · บันทึกเหตุผลแล้ว`

## จากเพจที่เชื่อมไว้ สู่เอเจนต์ที่ทำงานได้จริง

สามขั้นตอน และบทสนทนาแรกได้รับคำตอบภายในวันเดียวกัน

1. **เชื่อมช่องทาง** — เชื่อมเพจ Facebook บัญชี Zalo บอต Telegram หรือวิดเจ็ตเว็บไซต์ ระบบดึงประวัติเดิมย้อนหลังมาให้ กล่องข้อความจึงเปิดมาพร้อมบทสนทนาที่คุณมีอยู่แล้ว ไม่ใช่รายการว่างเปล่า
2. **วางเอเจนต์ไว้เบื้องหลัง** — เลือกว่า agent ตัวไหนตอบในช่องทางไหน แล้วให้เอกสารและเครื่องมือที่ต้องใช้ Agent จะตอบเองเมื่อลูกค้าส่งข้อความชุดหนึ่งจบ — คุณกำหนดได้ว่าจะรอนานเท่าไร บทสนทนาที่ติดแท็กไหนให้ทีมจัดการเอง และโหมดแซนด์บ็อกซ์ที่เก็บคำตอบไว้ในแอประหว่างทดสอบ
3. **เฝ้าดู เข้าช่วย ปรับปรุง** — ทุกคำตอบเก็บรอบการทำงานของมัน — การเรียกเครื่องมือและค่าใช้จ่าย — ไว้ในบันทึกการทำงาน หยุด AI ในบทสนทนาที่ต้องการคน แล้วให้คะแนนหรือปรับปรุงคำตอบ: การแก้ไขช่วยให้ agent ดีขึ้นทันทีและใช้ฝึกในภายหลัง

## สร้างมาสำหรับทีมที่ทำงานกับกล่องข้อความจริงๆ

ไม่ใช่แชทบอตที่แปะไว้บนเพจ — แต่เป็นคิวที่ทีมและเอเจนต์ของคุณทำงานร่วมกัน

### เอเจนต์ประจำแนวหน้า

ชี้เอเจนต์ตัวหนึ่งไปที่ช่องทาง แล้วมันจะตอบด้วยน้ำเสียงของคุณ ใช้แคตตาล็อกสินค้า เอกสาร และทุกอย่างที่มันจำได้เกี่ยวกับลูกค้าคนนั้น มันมีเครื่องมือของคุณด้วย จึงค้นออร์เดอร์ได้เลย แทนที่จะขอโทษว่าไม่รู้

### ส่งต่องานโดยไม่ต้องแย่งกัน

เพื่อนร่วมทีมคนไหนก็ตอบกลางบทสนทนาได้ — บทสนทนาเดิม ประวัติเดิม — และคำตอบของเขาจะยกเลิกคำตอบที่ agent กำลังเขียน โดยไม่ปิด agent การหยุด AI จะมอบบทสนทนาให้ทีมของคุณจนกว่าจะมีคนเปิดกลับ เรื่องที่ต้องให้คนตัดสินใจ agent ก็ปล่อยให้คน: ออเดอร์ที่มันรับไว้จะเป็นฉบับร่างรอทีมยืนยัน เว้นแต่คุณอนุญาตให้ยืนยันเอง และมันส่งการแจ้งเตือนแบบพุชที่เปิดบทสนทนาให้ทีมได้

### ลูกค้าหนึ่งคน ไม่ใช่ห้าบทสนทนา

ผู้ติดต่อถูกจับคู่ข้ามช่องทาง คอมเมนต์ใน Facebook ข้อความตอบใน Messenger และข้อความใน Zalo จึงเป็นคนเดียวกันที่มีประวัติเดียว — พร้อมเบอร์โทร แท็ก และแอตทริบิวต์ของเขา

### เบอร์โทร จับได้และเก็บไว้

เบอร์ที่ลูกค้าพิมพ์ระหว่างสนทนาถูกตรวจจับ ตัดซ้ำกับเบอร์ที่คุณมีอยู่ แล้วปักไว้กับผู้ติดต่อ — โดยคัดสิ่งรบกวน (เบอร์พนักงาน เบอร์ในข้อความที่ส่งต่อมา) ออก ไม่นับรวม

### Care ติดตามผลโดยอ่านบทสนทนาก่อน

บทสนทนาที่เงียบไปจะถูกติดตามผลโดยเอเจนต์ที่อ่านประวัติแล้ว — เคารพช่วงงดส่งที่คุณตั้ง จำกัดความถี่ที่ติดต่อคนหนึ่งได้ และไม่ส่งข้อความเหมือนกันเป็นชุด

### ตัวเลขที่นำไปใช้ได้จริง

ปริมาณ เวลาตอบกลับ และรายละเอียดแยกตามช่องทาง คำนวณล่วงหน้าเป็นรายชั่วโมง แดชบอร์ดจึงเปิดได้ทันที ไม่ต้องสแกนข้อความทั้งปีทุกครั้งที่มีคนเปลี่ยนช่วงวันที่

## เชื่อมกับอะไรได้บ้าง และรองรับอะไร

รายการที่ผู้อ่านตั้งใจมาหา ก่อนตัดสินใจว่าเหมาะกับตัวเองไหม

### ช่องทางแชท

- Facebook Messenger — ข้อความส่วนตัว
- คอมเมนต์ Facebook พร้อมตอบกลับแบบส่วนตัว
- Zalo ส่วนตัว ล็อกอินด้วย QR โค้ด
- Zalo Official Account — เร็วๆ นี้
- บอต Telegram
- บัญชี Pancake

### ช่องทางของคุณเอง

- วิดเจ็ตเว็บไซต์ ฝังได้ทุกหน้า
- ช่องทาง Custom API — รับ webhook เข้า ส่ง webhook ออก
- เว็บฮุกขาออกตามเหตุการณ์ในกล่องข้อความ
- แอปมือถือสำหรับ iOS และ Android
- Deep link ตรงไปยังบทสนทนา

### ข้อความส่งอะไรได้บ้าง

- รูปภาพและอัลบั้ม ไฟล์ สติกเกอร์
- ข้อความเสียง ถอดเป็นข้อความที่ค้นหาได้
- ตำแหน่งที่ตั้ง โพล การ์ดสินค้าและการ์ดโฆษณาที่พาลูกค้าเข้ามา
- การตอบกลับแบบอ้างอิง แสดงคู่กับข้อความที่ตอบ
- แชทกลุ่มที่แยกตัวตนผู้พูดแต่ละคน

### ทำงานกับคิว

- ค้นหาแบบ full-text พร้อมข้อความส่วนที่ตรงกัน
- กรองตามช่องทาง แท็ก ประเภท และที่รอตอบกลับ
- ข้อความตอบด่วนที่ทั้งทีมใช้ร่วมกัน
- แท็ก ป้ายกำกับ และแอตทริบิวต์กำหนดเอง
- สรุปบทสนทนาบนแผงผู้ติดต่อ

### การควบคุม

- สิทธิ์ช่องทางรายสมาชิก บทบาท หรือทีม
- ออเดอร์ที่ agent รับไว้เก็บเป็นฉบับร่างจนกว่าพนักงานจะยืนยัน
- การ์ดเรลกำหนดสิ่งที่เอเจนต์พูดได้
- บล็อกผู้ติดต่อได้จากในบทสนทนา
- บันทึกการทำงานเต็มรูปแบบของทุกคำตอบ พร้อมต้นทุน

### ตามทันทุกอย่าง

- ดึงประวัติย้อนหลังเมื่อเพิ่มช่องทาง
- สรุปสถิติรายชั่วโมงแยกตามช่องทาง
- Care ติดตามผล พร้อมช่วงงดส่งและการจำกัดจำนวน
- รวมช่องทาง ย้ายประวัติของบัญชีหนึ่งเข้าอีกบัญชี
- บันทึกการส่งเว็บฮุกขาออก

## คำถามเกี่ยวกับ AI Inbox

สิ่งที่ทีมต่างๆ ถามก่อนจะให้เอเจนต์ดูแลเพจแรก

### เชื่อมช่องทางแชทไหนได้บ้าง?

Facebook Messenger (รวมคอมเมนต์ใต้โพสต์บนเพจ), Telegram, Zalo ส่วนตัวที่ล็อกอินด้วย QR โค้ด, Pancake และวิดเจ็ตแชทที่คุณฝังบนเว็บไซต์ของคุณเอง ส่วน Zalo Official Account จะมาเร็วๆ นี้ ช่องทางอื่นเชื่อมผ่านช่องทาง Custom API ซึ่งเป็นแค่ webhook ขาเข้าและ webhook ขาออก — ฝั่งเราไม่ต้องเขียนโค้ดใหม่

### AI ตอบเอง หรือพนักงานยังต้องตอบอยู่?

ทั้งสองอย่าง Agent ตอบข้อความใหม่เองเมื่อลูกค้าส่งข้อความชุดหนึ่งจบ และทีมของคุณตอบในบทสนทนาเดียวกันได้ทุกเมื่อ — คำตอบของเพื่อนร่วมทีมจะยกเลิกคำตอบที่ agent กำลังเขียน และ AI ยังเปิดอยู่ การหยุด AI จะมอบบทสนทนาให้ทีม (และหยุดการติดตามแบบ care ในบทสนทนานั้นด้วย) จนกว่าจะมีคนเปิดกลับ และบทสนทนาที่มีแท็กที่คุณเลือกสามารถปล่อยให้ทีมจัดการทั้งหมด ไม่มีขั้นตอนอนุมัติกลางบทสนทนา สำหรับออเดอร์ จุดตรวจคือตัวออเดอร์เอง — agent สร้างฉบับร่างให้ทีมยืนยัน เว้นแต่คุณอนุญาตให้ยืนยันเอง

### บทสนทนาจากลูกค้าคนเดียวกันอยู่รวมกันไหม?

ใช่ บทสนทนาถูกเชื่อมด้วยเบอร์โทรหรืออีเมลที่ตรงกัน คนที่คอมเมนต์โพสต์ Facebook แล้วทักคุณใน Zalo ทีหลัง จึงแสดงเป็นลูกค้าคนเดียวที่มีประวัติเดียว — รวมถึงเบอร์โทรที่ตรวจพบในบทสนทนา แอตทริบิวต์ที่ทีมกรอก และข้อมูลโปรไฟล์ที่ดึงมาจากระบบของคุณเอง

### รูปภาพ ข้อความเสียง และไฟล์ จะเป็นอย่างไร?

จัดเก็บไว้กับบทสนทนาและแสดงในบทสนทนาเลย — รูป อัลบั้ม สติกเกอร์ ไฟล์ ตำแหน่งที่ตั้ง โพล และการ์ดสินค้า แสดงเป็นตัวมันเอง ไม่ใช่ลิงก์เสีย ข้อความเสียงถูกถอดอัตโนมัติ จึงกลายเป็นตัวอักษรที่ค้นหาได้ และเอเจนต์อ่านแล้วตอบได้จริง

### กำหนดได้ไหมว่าพนักงานคนไหนเห็นช่องทางไหน?

ได้ สิทธิ์ช่องทางกำหนดรายสมาชิก รายบทบาท หรือรายทีม เอเจนซีจึงให้ทีมที่ดูแลลูกค้ารายหนึ่งเข้าถึงเพจเดียวได้ โดยไม่เปิดส่วนอื่นของเวิร์กสเปซ ทุกอย่างในเวิร์กสเปซใช้ระบบสิทธิ์เดียวกัน

### กล่องข้อความติดตามลูกค้าที่เงียบไปได้ไหม?

ได้ — นั่นคือหน้าที่ของ Care คุณตั้งตัวกระตุ้น (บทสนทนาที่เงียบไป N ชั่วโมง แท็ก ตัวกรอง) ช่วงงดส่งที่ห้ามส่งเด็ดขาด และจำนวนครั้งสูงสุดที่ติดต่อคนหนึ่งได้ ข้อความติดตามผลเขียนโดยเอเจนต์จากประวัติบทสนทนา ไม่ใช่เทมเพลตตายตัวที่ส่งเหมือนกันทั้งหมด
