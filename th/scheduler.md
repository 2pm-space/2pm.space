## ใส่เอเจนต์ลงในตารางเวลา

เลือกเอเจนต์ ตั้งเวลา อ่านผล

1. **เลือกเอเจนต์และงาน** — เลือกเอเจนต์และเขียนสิ่งที่จะถาม บรรทัดละหนึ่งข้อความ — แต่ละบรรทัดถูกส่งและตอบเป็นรายการของตัวเอง
2. **ตั้งเวลาที่จะรัน** — ครั้งเดียว รายวัน รายสัปดาห์ในวันที่คุณติ๊ก รายเดือนในวันที่กำหนด หรือ cron expression — ตามเขตเวลาที่คุณเลือก
3. **อ่านว่ามันทำอะไร** — ทุกรอบเข้าไปอยู่ในประวัติของงาน พร้อมคำตอบ โทเคน และต้นทุนแต่ละข้อ รันเลย หยุดชั่วคราว หรือยกเลิกได้จากรายการ

## ตารางเวลาที่รู้ว่ากำลังรันเอเจนต์

ไม่ใช่ cron job ที่ยิงเว็บฮุก — แต่เป็นการรันที่มีบทสนทนา เครื่องมือ และบันทึก

### ตารางห้าแบบ

ครั้งเดียวในวันที่กำหนด รายวันตามเวลา รายสัปดาห์ในวันที่เลือก รายเดือนในวันของเดือน หรือ cron expression ใดก็ได้ ทุกตารางยึดเขตเวลาที่คุณตั้ง ไม่ใช่ของเซิร์ฟเวอร์

### ผลลัพธ์ไปถึงที่ที่ต้องการ

เอเจนต์รันพร้อมเครื่องมือของมัน รายงานจึงส่งออกไปได้ทันทีที่เขียนเสร็จ: ข้อความ Telegram ถึงกลุ่มฝ่ายขาย อีเมล การแจ้งเตือนถึงทีมปฏิบัติการ หรือแถวในตาราง Drive

### ถูกลงครึ่งหนึ่ง เมื่องานรอได้

เปลี่ยนเอเจนต์แบบง่ายเป็น Batch API แล้วการรันจะผ่านคิว batch ของผู้ให้บริการ — ถูกลงราว 50% เสร็จภายใน 24 ชั่วโมง สำหรับโมเดล Anthropic และ OpenAI

### จำข้ามรอบได้ ถ้าคุณต้องการ

เริ่มบทสนทนาใหม่ทุกรอบ ต่อบทสนทนาล่าสุดเพื่อให้เอเจนต์จำครั้งก่อนได้ หรือส่งเข้าบทสนทนาที่ระบุ

### หยุดเมื่อคุณสั่ง

ตั้งวันหมดอายุหรือจำนวนรันสูงสุด และเลือกจำนวนข้อความที่รันพร้อมกัน — ตั้งแต่หนึ่งถึงสิบ

### ทุกรอบมีบันทึก

แต่ละรอบเก็บสถานะ เวลาเริ่มและจบ และคำตอบหรือข้อผิดพลาดของทุกข้อความพร้อมโทเคนและต้นทุน — รวมไว้ใน การตั้งค่า › บันทึก ด้วย

## ทุกตัวเลือกการตั้งเวลา

สิ่งที่หน้าต่างสร้างงานมีให้ ทีละฟิลด์

### ตารางเวลา

- ครั้งเดียว ในวันและเวลาที่กำหนด
- รายวัน ตามเวลา
- รายสัปดาห์ ในวันที่คุณติ๊ก
- รายเดือน ในวันของเดือน
- cron expression กำหนดเอง
- เขตเวลาใดก็ได้

### การรัน

- รันทันที ครั้งละ 1–10 ข้อความ
- Batch API ถูกลงราว 50% ภายใน 24 ชม.
- Batch สำหรับเอเจนต์แบบง่ายบนโมเดล Anthropic หรือ OpenAI
- เอเจนต์ที่มีขั้น Human Review ตั้งเวลาไม่ได้

### อินพุตและบทสนทนา

- บรรทัดละหนึ่งข้อความ แต่ละข้อความเป็นหนึ่งรายการ
- บทสนทนาใหม่ทุกรอบ
- หรือต่อบทสนทนาล่าสุด
- หรือบทสนทนาที่ระบุด้วย ID

### ข้อจำกัด

- วันและเวลาหมดอายุ
- จำนวนรันสูงสุด
- นับรอบในรายการ เช่น 6/12

### การควบคุม

- รันเลย
- หยุดชั่วคราวและทำต่อ
- ยกเลิก
- แก้ไขหรือลบ
- ค้นหา และกรองตามสถานะหรือโหมด

### ประวัติและบันทึก

- สถานะของทุกรอบและทุกข้อความ
- คำตอบหรือข้อผิดพลาดแต่ละข้อ แบบเต็ม
- โทเคนและต้นทุนต่อข้อความและต่อรอบ
- แท็บ Scheduler Runs ในบันทึกของเวิร์กสเปซ

## คำถามเกี่ยวกับตัวจัดตารางเวลา

สิ่งที่คนถามก่อนทำรายงานแรกให้เป็นอัตโนมัติ

### ตั้งเวลาอะไรได้บ้าง?

เอเจนต์ใดก็ได้ที่เปิดใช้งานในเวิร์กสเปซ คุณเขียนข้อความที่มันจะได้รับ บรรทัดละข้อความ และแต่ละรอบจะส่งข้อความเหล่านั้นแล้วบันทึกคำตอบ

### ผลลัพธ์มาถึงฉันได้อย่างไร?

ผ่านเครื่องมือของเอเจนต์เอง ให้มันมี Telegram Send Message, Gmail หรือ Notify Operators แล้วบอกในข้อความว่าผลลัพธ์ควรไปที่ไหน ทุกคำตอบยังถูกเก็บไว้ในประวัติการรันของงานด้วย

### โหมด Batch API คืออะไร?

เป็นการส่งข้อความของรอบนั้นผ่านคิว batch ของผู้ให้บริการโมเดลแทนการตอบทันที ต้นทุนราวครึ่งหนึ่งและเสร็จภายใน 24 ชั่วโมง ใช้ได้กับเอเจนต์แบบง่ายบนโมเดล Anthropic หรือ OpenAI ส่วนเวิร์กโฟลว์แบบ agentic ต้องรันหลายเทิร์น จึงรันทันทีเสมอ

### ใช้เขตเวลาอะไร?

เขตเวลาที่คุณเลือกในงาน — ค่าเริ่มต้นคือของเบราว์เซอร์ เวลารายวัน รายสัปดาห์ และรายเดือนจะอ่านตามเขตเวลานั้น

### ตั้งเวลาให้เอเจนต์ที่มีขั้น Human Review ได้ไหม?

ไม่ได้ การรันตามตารางเวลาไม่มีใครอนุมัติ หน้าต่างจึงไม่ตั้งเวลาให้เอเจนต์ที่มีโหนด Human Review ในเวิร์กโฟลว์

### งานหยุดเองหลังรันครบจำนวนได้ไหม?

ได้ ตั้งจำนวนรันสูงสุด วันหมดอายุ หรือทั้งสองอย่าง และคุณหยุดชั่วคราว ทำต่อ หรือยกเลิกงานได้ทุกเมื่อ
