## ให้เครื่องมือกับเอเจนต์ในสามขั้นตอน

เลือก เชื่อม มอบสิทธิ์

1. **เลือกประเภท** — เลือกจากแคตตาล็อกในตัว หรือสร้างเว็บฮุก ฟังก์ชัน Python การเชื่อมต่อ MCP หรือเอเจนต์ในฐานะเครื่องมือ
2. **เชื่อมต่อ** — วาง API key ที่ผู้ให้บริการให้มา หรือ URL และข้อมูลยืนยันตัวตนของบริการของคุณเอง ข้อมูลรับรองถูกเก็บแบบเข้ารหัส
3. **มอบสิทธิ์** — เปิดให้เอเจนต์ที่ควรใช้ หรือตั้งเป็นแบบทั่วไปให้ทุกเอเจนต์ใช้ได้ เอเจนต์ตัดสินใจเองว่าจะเรียกเมื่อไรจากคำอธิบายของเครื่องมือ

## เครื่องมือห้าประเภท รายการเดียว

เอเจนต์ต้องเข้าถึงอะไร ก็มีวิธีส่งให้ได้

### หกสิบเครื่องมือ พร้อมใช้

ค้นเว็บ Wikipedia และ ArXiv เบราว์เซอร์ headless, Gmail และ Google Calendar, GitHub, Telegram แปลงข้อความเป็นเสียง BI board และ Drive ของคุณเอง — แต่ละตัวเป็นการ์ดในแคตตาล็อก หลายตัวใช้ได้ทันทีที่เพิ่ม

### HTTP API ใดก็ได้

อธิบาย endpoint — method, URL, header, การยืนยันตัวตน และ JSON ที่เอเจนต์ควรส่ง — แล้วมันจะกลายเป็นเครื่องมือ รองรับ GET, POST, PUT, PATCH และ DELETE พร้อม bearer token หรือ API key

### Python ของคุณเอง

เขียนฟังก์ชัน กำหนด input schema แล้วมันจะรันในแซนด์บ็อกซ์ที่มีเวลาจำกัด — ออฟไลน์ เว้นแต่คุณอนุญาตให้ใช้อินเทอร์เน็ต

### MCP server ใดก็ได้

ชี้ไปที่ URL ของเซิร์ฟเวอร์ แล้วเครื่องมือที่มันเปิดให้จะถูกค้นพบให้ เปิดหรือปิดทีละตัว และกำหนดให้ต้องอนุมัติกับตัวที่เขียนข้อมูล

### เอเจนต์ในฐานะเครื่องมือ

เปิดเอเจนต์ตัวหนึ่งให้อีกตัวใช้: นักเขียนถามนักวิจัย เอเจนต์ขายถามตัวเช็กสต็อก — แต่ละตัวยังมีพรอมต์ โมเดล และเครื่องมือของตัวเอง

### คุณกำหนดว่าใครถืออะไร

มอบเครื่องมือรายเอเจนต์หรือตั้งเป็นแบบทั่วไป ปิดโดยไม่ต้องลบ แคชผลลัพธ์ และบังคับให้คนอนุมัติก่อนรัน

## แต่ละประเภทต้องใช้อะไร

ฟิลด์ ตัวเลือก และข้อจำกัด — ก่อนที่คุณจะสมัคร

### ประเภทเครื่องมือ

- ในตัว — เลือกจากแคตตาล็อก
- เว็บฮุก — HTTP endpoint ใดก็ได้
- โค้ด — ฟังก์ชัน Python ในแซนด์บ็อกซ์
- MCP — MCP server ใดก็ได้
- เอเจนต์ในฐานะเครื่องมือ — เอเจนต์อีกตัวในเวิร์กสเปซ

### เครื่องมือเว็บฮุก

- GET, POST, PUT, PATCH และ DELETE
- ไม่ยืนยันตัวตน, bearer token หรือ API key
- header กำหนดเอง
- JSON input schema ให้เอเจนต์กรอก

### เครื่องมือโค้ด

- Python แก้ไขในเบราว์เซอร์
- รันในแซนด์บ็อกซ์ที่มีเวลาจำกัด
- ปิดอินเทอร์เน็ต เว้นแต่คุณอนุญาต
- มี input schema เหมือนเครื่องมืออื่น

### MCP server

- เชื่อมด้วย URL ผ่าน SSE หรือ Streamable HTTP
- ยืนยันตัวตนด้วย bearer token และ header กำหนดเอง
- แสดงเครื่องมือที่ค้นพบทีละตัว
- เปิดหรือปิดได้ทีละตัว
- อนุมัติรายเครื่องมือ หรือทั้งหมด

### การเชื่อมต่อ

- Viettel Post — ค่าส่ง พัสดุ สถานะ และฉลาก
- KiotViet — สินค้า สต็อก ลูกค้า คำสั่งซื้อ และใบแจ้งหนี้
- WordPress — โพสต์ หน้า สื่อ และสินค้า WooCommerce
- ERPNext / Frappe — เอกสารบนไซต์ของคุณ
- ชุดเครื่องมือ Composio ด้วยคีย์ Composio ของคุณ

### สิทธิ์และความปลอดภัย

- มอบรายเอเจนต์ หรือทั่วไปให้ทุกตัว
- ปิดได้โดยไม่ต้องลบ
- ให้คนอนุมัติก่อนเครื่องมือที่เลือกจะรัน
- แคชผลลัพธ์ และข้ามแคชเมื่อเปิดการอนุมัติ
- ทุกการเรียกอยู่ในบันทึกการรัน

## ต่อเครื่องมือเองด้วยมือ กับ ใช้แคตตาล็อก

การเชื่อมต่อเดียวกัน สองวิธี

| ถ้าไม่มี 2pm.space | เมื่อใช้ 2pm.space |
| --- | --- |
| ทุก API ใหม่หมายถึงโค้ด การ deploy และพรอมต์ที่ต้องอธิบายมัน | อธิบาย endpoint ครั้งเดียว เอเจนต์ที่ได้รับสิทธิ์ก็เรียกได้ |
| เครื่องมือที่ลบข้อมูลได้รันอิสระพอๆ กับเครื่องมือที่แค่อ่าน | บังคับอนุมัติกับเครื่องมือที่เขียนข้อมูล แล้วการรันจะรอคน |
| MCP server แต่ละตัวพาเครื่องมือทั้งหมดมาด้วย จะต้องการหรือไม่ก็ตาม | เปิดหรือปิดเครื่องมือที่ค้นพบทีละตัว |
| ไม่มีใครแน่ใจว่าเอเจนต์ไหนเข้าถึงระบบไหนได้ | หน้าของแต่ละเครื่องมือแสดงเอเจนต์ที่ได้รับสิทธิ์ |

## คำถามเกี่ยวกับเครื่องมือ

สิ่งที่คนถามก่อนเชื่อมต่อระบบแรก

### มีเครื่องมือในตัวกี่รายการ?

ตอนนี้มีหกสิบรายการ แบ่งเป็นค้นหา ความรู้ การคำนวณ ข้อมูล AI และสื่อ การเงิน ยูทิลิตี้ ประสิทธิภาพการทำงาน MCP server, Drive และการเชื่อมต่อ — รายการเต็มอยู่ในหน้านี้ นอกจากนี้ HTTP API ฟังก์ชัน Python หรือ MCP server ใดก็เป็นเครื่องมือได้

### ต้องมี API key ไหม?

บางเครื่องมือต้องใช้คีย์ของผู้ให้บริการ — Tavily, Serper, Gmail, GitHub และตัวอื่นที่มีไอคอนกุญแจ หลายตัวใช้ได้โดยไม่ต้องมีคีย์ เช่น DuckDuckGo, Wikipedia, ArXiv, Web Fetch, เบราว์เซอร์ Playwright และเครื่องมือ Drive

### เครื่องมือรอการอนุมัติก่อนรันได้ไหม?

ได้ เปิด Require human approval ให้เครื่องมือที่ต้องมีคนยืนยัน — โดยทั่วไปคือตัวที่ส่ง เขียน หรือลบ — แล้วการรันของเอเจนต์จะหยุดจนกว่าจะมีคนอนุมัติการเรียกนั้น สำหรับ MCP server หรือการเชื่อมต่อ การอนุมัติตั้งได้รายเครื่องมือที่ค้นพบ

### เชื่อม MCP server ของตัวเองได้ไหม?

ได้ เพิ่มเครื่องมือ MCP พร้อม URL, transport และการยืนยันตัวตนของเซิร์ฟเวอร์ เครื่องมือที่มันเปิดให้จะถูกค้นพบและแสดงรายการ แล้วคุณเปิดปิดทีละตัว ในแคตตาล็อกมีค่าตั้งต้นสำหรับ N8N, Slack, Notion, GitHub, Google Drive และ WordPress

### เอเจนต์หนึ่งใช้อีกตัวเป็นเครื่องมือได้ไหม?

ได้ สร้าง Agent as tool แล้วเลือกเอเจนต์ เอเจนต์ที่ได้รับสิทธิ์จะส่งงานให้มันและใช้คำตอบได้ โดยมันยังมีพรอมต์ โมเดล และเครื่องมือของตัวเอง

### Viettel Post และ KiotViet อยู่ตรงไหน?

เป็นการเชื่อมต่อในตัว เชื่อมบัญชีครั้งเดียว แล้วเอเจนต์จะได้การทำงานของระบบเหล่านั้นเป็นเครื่องมือ — ประเมินค่าส่ง สร้างพัสดุ เช็กสต็อก ค้นหาคำสั่งซื้อ
