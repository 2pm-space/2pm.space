### 2pm AI ให้คำปรึกษา

เอเจนต์ตัวเดียวอยู่เบื้องหลังทุกช่องทาง ใช้ทุกอย่างที่เวิร์กสเปซของคุณรู้

- **ความรู้** — ตอบจากเอกสารและแคตตาล็อกของคุณ รวมถึงรูปสินค้า
- **ทักษะ** — คู่มือการขายของคุณ — ถามอะไร เสนออะไร และพูดด้วยน้ำเสียงแบบไหน
- **เครื่องมือ** — ค้นหาสินค้า ออร์เดอร์เก่า และค่าส่งได้ระหว่างการสนทนา
- **หน่วยความจำ** — จำสิ่งที่ลูกค้าเคยบอกไว้เมื่อครั้งก่อน
- **Customer 360** — ทุกช่องทางที่ลูกค้าเคยใช้ รวมเป็นประวัติเดียว
- **การ์ดเรล** — คุมทุกคำตอบให้อยู่ในขอบเขตที่พูดและทำได้

1. **ดำเนินการ** — ทวนรายการสินค้า เบอร์โทร และที่อยู่จัดส่งกับลูกค้าอีกครั้ง `บันทึกที่อยู่แล้ว`
2. **สร้างคำสั่งซื้อ** — ใบสั่งขายที่คิดราคาจากแคตตาล็อกของคุณ — เป็นฉบับร่างให้ทีมยืนยัน หรือส่งเข้าระบบทันที `SO-2026-48213`
3. **จองขนส่งแบบ COD** — จองกับ Viettel Post พร้อมยอดที่ต้องเก็บเงินปลายทาง หรือเก็บไว้ในใบส่งสินค้าสำหรับขนส่งของคุณเอง `COD · เลขพัสดุ`
4. **กล่าวขอบคุณ** — เมื่อมีแจ้งว่าส่งถึงแล้ว กฎตามเหตุการณ์จะส่งคำขอบคุณ — เขียนจากบทสนทนา หรือจากเทมเพลตของคุณ `ส่งถึงแล้ว → ขอบคุณแล้ว`

**ระหว่างทาง**

- **หากลูกค้าให้เบอร์โทร → เพิ่มเพื่อนบน Zalo.** เบอร์จะถูกปักไว้กับผู้ติดต่อ แล้ว Zalo ส่วนตัวของคุณจะส่งคำขอเป็นเพื่อน — ทยอยส่ง ระหว่าง 08:00–20:00 น. เมื่อลูกค้ากดรับ แชท Zalo จะรวมเข้ากับลูกค้าคนเดิม `+84 ••• 412 → Zalo`
- **หากลูกค้าเงียบไป → Care ติดตามต่อ.** Care agent อ่านบทสนทนาแล้วติดตามผลหลังลูกค้าเงียบไปตามเวลาที่คุณตั้ง — เคารพช่วงงดส่งของคุณ จำกัดจำนวนต่อคน และอยู่ในกรอบเวลาส่งข้อความของช่องทาง `เงียบ 2 ชม. → ติดตามผล`
- **หากลูกค้าขอคุยกับคน → ทีมของคุณเข้าช่วย.** Agent ส่งการแจ้งเตือนแบบพุชที่เปิดบทสนทนาให้ทีมของคุณ ใครก็ตอบตรงนั้นได้ — หรือหยุด AI เพื่อรับบทสนทนาไว้เอง `แจ้งเตือน → หยุด AI`
- **หากลูกค้าสแปมหรือพูดจาหยาบคาย → เอเจนต์หยุดตอบ.** ปิด AI และ Care สำหรับบทสนทนานั้น แล้วทิ้งเหตุผลสั้นๆ หนึ่งบรรทัดไว้ให้ทีม ใครก็เปิดกลับได้จากกล่องข้อความ `ปิด AI · บันทึกเหตุผลแล้ว`

## ตัวสร้างเอเจนต์ที่อยู่เบื้องหลังทั้งหมด

ทุกอย่างข้างบนทำงานบนตัวสร้างเดียวกัน — ทักษะที่คุณเขียนครั้งเดียวจึงใช้ได้ทุกที่ที่คุณวางเอเจนต์

### เอเจนต์ AI

สร้างและปรับแต่งเอเจนต์อัจฉริยะให้ตรงกับงานของคุณ กำหนดเพอร์โซนา คำสั่ง และพฤติกรรมด้วยตัวสร้างแบบภาพ — แล้วเก็บเวอร์ชันของแคนวาสไว้ การเปลี่ยนแปลงที่เสียใจทีหลังจึงกู้คืนได้ในคลิกเดียว

### ทักษะกำหนดเอง

สอนเอเจนต์ให้มีทักษะและเวิร์กโฟลว์เฉพาะด้าน ทักษะใส่เข้าไปในทุกพรอมต์ได้ หรือเฉพาะเมื่อคำถามตรงกับทักษะนั้น — คลังพฤติกรรมขนาดใหญ่จึงไม่กินโทเคนทุกครั้งที่เรียก

### การเชื่อมต่อเครื่องมือ

เชื่อมเอเจนต์กับ API ภายนอก ฐานข้อมูล และบริการต่างๆ ทั้งเครื่องมือเว็บฮุก ฟังก์ชัน Python ในแซนด์บ็อกซ์ การเชื่อมต่อในตัว MCP server หรือเอเจนต์ตัวอื่นที่เปิดเป็นเครื่องมือ

[ดูทุกอย่างที่เชื่อมต่อได้ →](tools.md)

### การ์ดเรล

ตั้งข้อจำกัดด้านความปลอดภัยและนโยบายเนื้อหา ทั้งขาเข้าและขาออกของเอเจนต์ — พร้อมบันทึกตรวจสอบว่าการ์ดตัวไหนทำงาน ทำอะไร และทำไม

### Collaborative Drive

เอกสาร มายด์แมป และตาราง ที่ทำงานร่วมกันแบบเรียลไทม์ เป็นฐานความรู้ร่วมของทีม และเป็นแหล่งที่เอเจนต์ดึงข้อมูลไปใช้

[ลองสร้างมายด์แมปฟรี →](mind-map.md)

### ใช้งานได้ในคลิกเดียว

วางเอเจนต์ไว้บนช่องทาง ตั้งตารางเวลา หรือเปิดเป็น API endpoint ติดตามประสิทธิภาพ ดูต้นทุนต่อรอบ และปรับปรุงโดยมีบันทึกอยู่ตรงหน้า

## วิธีการทำงาน

จากไอเดียสู่การใช้งานจริงในสามขั้นตอน ไม่ต้องตั้งค่าซับซ้อน ไม่ต้องปวดหัวกับโครงสร้างพื้นฐาน

1. **สร้างเอเจนต์** — กำหนดเพอร์โซนา คำสั่ง และพฤติกรรมของเอเจนต์ เริ่มจากเทมเพลตในมาร์เก็ตเพลส หรือจากแคนวาสเปล่าในตัวสร้างแบบภาพ
2. **ใส่ทักษะ เครื่องมือ และความรู้** — เพิ่มทักษะ เชื่อมเครื่องมือ ชี้ไปยังเอกสารและฐานข้อมูลที่ต้องใช้ และตั้งการ์ดเรลที่มันต้องอยู่ภายใน
3. **ให้ลงมือทำงาน** — ส่งไปประจำช่องทาง ตั้งตารางเวลา หรือเปิดเป็น API ดูทุกรอบการทำงานพร้อมการเรียกเครื่องมือและต้นทุน แล้วปรับปรุงจากสิ่งที่เกิดขึ้นจริง

## ขับเคลื่อนด้วยเอนจินทรงพลัง

เบื้องหลัง 2pm.space ไม่ได้เป็นแค่หน้าแชท ทุกความสามารถคือเอนจินระดับโปรดักชันที่ออกแบบมาให้เอเจนต์ของคุณฉลาดขึ้น เร็วขึ้น และปลอดภัยขึ้น

### แนวคิดเอเจนต์

**เอเจนต์ที่คิด ลงมือ และปรับแก้ซ้ำ**

ทุกเอเจนต์บน 2pm.space สร้างบนลูป ReAct — คิด (Reason) ลงมือ (Act) สังเกต (Observe) แล้ววนซ้ำ เอเจนต์ไม่ได้แค่ตอบ แต่วางแผน เรียกเครื่องมือ ประเมินผล และปรับจนกว่างานจะเสร็จ

- โหมด Simple: เรียก LLM ครั้งเดียว ได้คำตอบเร็วและตรง
- โหมด Agentic: กราฟเวิร์กโฟลว์หลายโหนด กำหนดเส้นทางตามเงื่อนไขและรันขนานกันได้
- แต่ละโหนดเรียกเครื่องมือได้สูงสุด 10 รอบโดยค่าเริ่มต้น
- เส้นย้อนกลับ (วงวน) ให้เอเจนต์กลับไปทำขั้นตอนเดิมได้ โดยไม่ติดลูปไม่รู้จบ

### หน่วยความจำและบริบท

**หน่วยความจำที่ฉลาดขึ้นทุกบทสนทนา**

เอเจนต์บน 2pm.space จำได้ ระบบหน่วยความจำสามชั้น — หน่วยความจำส่วนกลางของเวิร์กสเปซ บริบทที่แชร์ในแต่ละเอเจนต์ และโน้ตรายผู้ใช้ — ทำให้ทุกการโต้ตอบรู้ว่าก่อนหน้านี้เกิดอะไรขึ้น

- ดึงหน่วยความจำจากทุกบทสนทนาอัตโนมัติในเบื้องหลัง
- ค้นคืนเชิงความหมายพร้อมคะแนนลดทอนตามเวลา — ความจำที่ใหม่และเกี่ยวข้องขึ้นมาก่อน
- หน่วยความจำหกประเภท: ข้อเท็จจริง ความชอบ คำสั่ง ฟีดแบ็ก เหตุการณ์ ขั้นตอน
- ตัดข้อมูลซ้ำสามระดับ: พรอมต์ LLM ความคล้ายของเวกเตอร์ และการรวบรวมเป็นระยะ

### เครื่องมือ

**เชื่อมเอเจนต์เข้ากับทุกอย่าง**

เอเจนต์เรียกใช้เครื่องมือที่คุณให้ — เครื่องมือในตัวของแพลตฟอร์ม เว็บฮุกภายนอก ฟังก์ชัน Python ในแซนด์บ็อกซ์ หรือเครื่องมือของ MCP server ลูป ReAct จัดการข้อผิดพลาดได้อย่างราบรื่นและลองใหม่อย่างชาญฉลาดโดยไม่ต้องให้คนเข้าไปแทรก

- เครื่องมือในตัว: ค้นเว็บ สร้างภาพ รันโค้ด และอื่นๆ
- เครื่องมือเว็บฮุก: POST/GET/PUT/PATCH ไปยัง API ใดก็ได้ ยืนยันตัวตนด้วย bearer หรือ API key
- โค้ด: ฟังก์ชัน Python ในแซนด์บ็อกซ์เป็นเครื่องมือ และ Python หรือ Bash ในโหนดโค้ดของเวิร์กโฟลว์
- รองรับ MCP: เชื่อมต่อ MCP server ใดก็ได้ ค้นหาเครื่องมือ และเปิดหรือปิดทีละตัว

### เอกสารและ RAG

**ฐานความรู้ของคุณ หยิบใช้ได้เสมอ**

อัปโหลดเอกสาร มายด์แมป สเปรดชีต และตาราง ขึ้น Collaborative Drive เอเจนต์ดึงส่วนที่เกี่ยวข้องที่สุดมาใช้เมื่อต้องการด้วยการค้นหาแบบไฮบริด — ผสานการค้นคืนด้วย dense vector กับคีย์เวิร์ด BM25

- ค้นหาแบบไฮบริดเป็นค่าเริ่มต้น: vector 70% + คีย์เวิร์ด 30% ผสานด้วย RRF
- แบ่งชิ้นเนื้อหาตามความหมาย พร้อม contextual embedding เพื่อค้นคืนได้แม่นยำขึ้น
- RAG สองโหมด: “tool” (เอเจนต์เป็นผู้เรียก) หรือ “auto” (ใส่เข้าไปทุกครั้ง)
- ค้นคืนแบบลำดับขั้น: ดึงสรุปของแต่ละชิ้นก่อน แล้วค่อยดึงเนื้อหาเต็มเมื่อต้องการ — ประหยัดโทเคน

### ทักษะ

**คำสั่งที่ใช้ซ้ำได้ ให้เอเจนต์เชี่ยวชาญ**

ทักษะคือเทมเพลตพรอมต์ที่ถูกใส่เข้าไปใน system prompt ของเอเจนต์ — ทุกครั้ง หรือโดยอัตโนมัติเมื่อคำถามของผู้ใช้ตรงกัน กำหนดครั้งเดียว ใช้ซ้ำได้กับทุกเอเจนต์ในเวิร์กสเปซ

- โหมด “Always”: ใส่ในทุก system prompt เพื่อให้พฤติกรรมแน่นอน
- โหมด “Auto”: ใส่เฉพาะเมื่อคำถามตรงกันผ่านการค้นหาแบบ full-text — ประหยัดโทเคน
- ทักษะส่วนกลางใช้กับทุกเอเจนต์ ทักษะเฉพาะเอเจนต์จำกัดอยู่ในขอบเขตของตัวเอง
- ทักษะระบบใช้ได้ทั้งแพลตฟอร์ม ข้ามข้อจำกัดของแต่ละเวิร์กสเปซ

### การติดตามการทำงาน

**มองเห็นทุกรอบการทำงานของเอเจนต์**

ทุกการทำงานถูกติดตามตั้งแต่ต้นจนจบ — การใช้โทเคน ต้นทุน ความหน่วง การเรียกเครื่องมือ และผลของการ์ด แยกรายโหนด ดีบักทุกความล้มเหลว ลดต้นทุน และรู้ชัดว่าเอเจนต์กำลังทำอะไร

- ติดตามรายโหนด: โทเคนขาเข้า โทเคนขาออก และต้นทุนแต่ละขั้น
- บันทึกการทำงานพร้อมประวัติข้อความทั้งหมดและผลการเรียกเครื่องมือ
- บันทึกตรวจสอบการ์ดเรล: ดูว่าการ์ดตัวไหนทำงาน ดำเนินการอะไร และทำไม
- บันทึกการดึงหน่วยความจำ: ติดตามว่าเรียนรู้อะไรจากแต่ละบทสนทนา

## ทำไมทีมต่างๆ เลือก 2pm.space

ดูว่า 2pm.space เปลี่ยนเวิร์กโฟลว์ AI ของคุณ จากเครื่องมือที่กระจัดกระจาย เป็นแพลตฟอร์มเดียวได้อย่างไร

| ถ้าไม่มี 2pm.space | เมื่อใช้ 2pm.space |
| --- | --- |
| เครื่องมือหนึ่งไว้ดูกล่องข้อความ อีกตัวไว้ทำแดชบอร์ด ตัวที่สามไว้ทำคอนเทนต์ — และไม่มีตัวไหนแชร์สิ่งที่รู้กัน | เวิร์กสเปซเดียวที่เอเจนต์ หน่วยความจำ และฐานความรู้ชุดเดียวกัน รองรับทั้งสามงาน |
| แชทบอตบนเพจที่ตอบตามสคริปต์ และยอมแพ้ทันทีเมื่อเจอคำถามจริง | เอเจนต์ที่มีเอกสาร แคตตาล็อก และเครื่องมือของคุณ — และมีเพื่อนร่วมทีมพร้อมรับต่อในคลิกเดียว |
| ทุกคำถามเรื่องตัวเลขต้องรอคิวนักวิเคราะห์ | ใครก็ถามได้ด้วยภาษาธรรมดา และได้คำตอบพร้อม SQL แนบมา |
| ไม่มีหน่วยความจำระหว่างเซสชัน บริบทหายทุกครั้งที่เริ่มแชทใหม่ | หน่วยความจำหลายชั้นที่คงอยู่ข้ามเอเจนต์ ช่องทาง และเซสชัน |
| คิดราคาต่อที่นั่ง ยิ่งชวนทีมมาใช้ยิ่งต้องจ่ายเพิ่ม | ทุกฟีเจอร์ฟรี สมาชิกไม่จำกัด และคิดค่าใช้งานตามราคาของผู้ให้บริการโมเดลเอง |
| สิทธิ์เข้าถึงมีแค่ได้ทั้งหมดหรือไม่ได้เลย ฟรีแลนซ์ที่ดูแลเพจเดียวจึงเห็นทั้งเวิร์กสเปซ | สิทธิ์รายทรัพยากรและสิทธิ์ระดับช่องทาง สำหรับสมาชิก บทบาท และทีม |

### มาร์เก็ตเพลสและแอป

ติดตั้งเทมเพลตเอเจนต์ลงเวิร์กสเปซแล้วแก้ไขต่อ หรือนำแอปที่สร้างบนแพลตฟอร์มไปใช้ในเวิร์กสเปซของคุณเอง

### เพลย์กราวด์

ทดสอบเอเจนต์ก่อนเจอลูกค้าจริง เล่นบทสนทนาซ้ำ ตรวจดูลำดับความคิด และดูการเรียกเครื่องมือแต่ละครั้งทำงานจนจบ

### เวิร์กสเปซของทีม

### หน่วยความจำส่วนกลาง

## คำถามที่พบบ่อย

ทุกสิ่งที่คุณต้องรู้เกี่ยวกับการสร้างและใช้งานเอเจนต์ AI กับ 2pm.space

### 2pm.space คืออะไร ในประโยคเดียว?

เวิร์กสเปซที่คุณสร้างเอเจนต์ AI แล้วให้มันทำงานจริง — ตอบลูกค้าทาง Messenger, Zalo, Telegram และแชทบนเว็บไซต์ ตอบคำถามเกี่ยวกับฐานข้อมูลของคุณด้วยภาษาธรรมดา และดูแลปฏิทินคอนเทนต์ — ทั้งหมดอยู่บน Drive ที่แชร์ร่วมกัน มีเอกสาร มายด์แมป และตารางที่อัปเดตสด

### สร้างเอเจนต์ AI แบบไหนได้บ้าง?

ตั้งแต่ผู้ช่วยที่เรียกโมเดลครั้งเดียว ไปจนถึงเวิร์กโฟลว์หลายโหนดที่มีการกำหนดเส้นทางตามเงื่อนไข สาขาที่รันขนานกัน และลูปประเมินผล รูปแบบที่ใช้กันบ่อยคือเอเจนต์ซัพพอร์ต ผู้ช่วยค้นคว้า นักเขียนคอนเทนต์ นักวิเคราะห์ข้อมูล และระบบอัตโนมัติภายใน ทุกตัวประกอบจากทักษะ เครื่องมือ ความรู้ และการ์ดเรลชุดเดียวกัน

### ต้องเขียนโค้ดเป็นไหม ถึงจะสร้างเอเจนต์ได้?

ไม่ต้อง เอเจนต์สร้างแบบภาพ — เพอร์โซนา คำสั่ง ทักษะ เครื่องมือ และการ์ดเรล เป็นการตั้งค่าทั้งหมด และมีมาร์เก็ตเพลสเทมเพลตให้เริ่มต้น ถ้าคุณเขียนโค้ด ก็มีเครื่องมือ Python ในแซนด์บ็อกซ์ API และ MCP endpoint รออยู่เมื่อต้องการ

### เอเจนต์เรียนรู้และจำบริบทได้อย่างไร?

สามวิธีทำงานร่วมกัน หน่วยความจำถูกดึงจากบทสนทนาในเบื้องหลังและค้นคืนตามความหมาย เอเจนต์จึงจำสิ่งที่เคยได้รับรู้ได้ เอกสารใน Drive ถูกดึงมาใช้เมื่อต้องการด้วยการค้นหาแบบไฮบริด ทั้งเวกเตอร์และคีย์เวิร์ด และทักษะ — คำสั่งที่ใช้ซ้ำได้ซึ่งคุณเขียนครั้งเดียว — ถูกใส่เข้าไปในพรอมต์ทุกครั้ง หรือเฉพาะเมื่อคำถามตรงกัน

### เชื่อมกับระบบที่เราใช้อยู่แล้วได้ไหม?

ได้ ช่องทางแชทเชื่อมเป็นช่องทางหลักโดยตรง HTTP API เชื่อมเป็นเครื่องมือเว็บฮุก ฐานข้อมูลและ data warehouse หกชนิดเชื่อมเป็นการเชื่อมต่อข้อมูล และ MCP server ใดก็ได้เป็นแหล่งเครื่องมือที่คุณค้นหาแล้วเปิดใช้ ส่วนอย่างอื่นส่งถึงเราผ่านเว็บฮุกธรรมดา

### ค่าใช้จ่ายเท่าไหร่?

ทุกฟีเจอร์ฟรี ไม่มีแพ็กเกจแบบเสียเงิน และไม่คิดค่าต่อที่นั่ง คุณจ่ายเฉพาะการใช้ AI — โทเคนของโมเดลคิดตามราคาของผู้ให้บริการเองโดยไม่บวกเพิ่ม และแพลตฟอร์มเก็บค่าธรรมเนียมคงที่ครั้งเดียวเมื่อคุณเติมเครดิต พื้นที่จัดเก็บที่เกินโควตาพื้นฐานเป็นสิ่งเดียวที่คิดรายเดือน

### ทีมทำงานร่วมกันอย่างไร?

เวิร์กสเปซมีสมาชิก บทบาท และทีม โดยให้สิทธิ์แยกตามทรัพยากรและการกระทำ นอกจากนี้ เอเจนต์ เอกสาร ช่องทาง หรือบอร์ดแต่ละรายการยังมีรายชื่อผู้มีสิทธิ์ของตัวเอง — จึงให้ฟรีแลนซ์ดูแลเพจเดียวได้โดยไม่ต้องให้ทั้งเวิร์กสเปซ

### ดูได้ไหมว่าเอเจนต์ทำอะไรไปบ้าง?

ทุกรอบการทำงานถูกบันทึกตั้งแต่ต้นจนจบ: ข้อความ การเรียกเครื่องมือแต่ละครั้งและผลที่ได้ โทเคนและต้นทุนแต่ละขั้น และการ์ดเรลตัวไหนทำงานและทำอะไร การรันตามตารางเวลา การส่งเว็บฮุก และการส่งข้อความติดตามผล ต่างก็มีบันทึกของตัวเองอยู่ข้างกัน
