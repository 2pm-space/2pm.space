## เวิร์กสเปซของคุณ ใน AI client ของคุณ

เชื่อม Claude Code, Cursor หรือ MCP client ใดก็ได้กับ 2pm.space ด้วย API key เดียว ขอให้มันสร้างเอเจนต์ แก้เวิร์กโฟลว์ กรอกตาราง Drive หรือวางกราฟลงบอร์ด — มันทำงานผ่านการทำงานเดียวกับที่แอปใช้ และเฉพาะที่คีย์ของคุณอนุญาต

## เชื่อมต่อในสามขั้นตอน

คีย์ สนิปเพ็ต และคำขอ

1. **สร้าง API key** — ใน การตั้งค่า › API Keys & MCP สร้างคีย์และเลือกสิ่งที่มันทำได้ คีย์ไม่มีทางมีสิทธิ์มากกว่าคนที่สร้างมัน
2. **วางสนิปเพ็ต** — คัดลอกบล็อกเซิร์ฟเวอร์สำหรับ Claude Code หรือ Cursor — endpoint และคีย์ของคุณใน header X-API-Key — ไปวางในไฟล์ตั้งค่าของ client
3. **ขอให้ทำงาน** — บอก client ว่าคุณต้องการอะไร มันจะแสดงรายการเครื่องมือของเวิร์กสเปซ อ่านเพลย์บุ๊กของงานนั้น แล้วเรียกใช้ทีละขั้น

## ทั้งเวิร์กสเปซ ในรูปเครื่องมือ

ไม่ใช่หน้าต่างอ่านอย่างเดียว — แต่เป็นการทำงานเดียวกับที่แอปทำ

### MCP client ใดก็ได้

เซิร์ฟเวอร์ระยะไกลผ่าน Streamable HTTP จึงใช้ได้กับ Claude Code, Cursor และ client อื่นที่พูด MCP ได้ หน้าตั้งค่าในแอปมีสนิปเพ็ตให้แต่ละตัว

### มากกว่า 300 เครื่องมือ

เอเจนต์และแคนวาส เครื่องมือ ทักษะ ความรู้ การ์ดเรลและหน่วยความจำ เอกสาร ตาราง มายด์แมป และสตอรีบอร์ดใน Drive แหล่งข้อมูลและบอร์ด แบรนด์ content calendar และช่องทาง

### จำกัดตามคีย์

เซิร์ฟเวอร์แสดงเฉพาะเครื่องมือที่สิทธิ์ของคีย์อนุญาต และคีย์ทำงานในนามสมาชิกที่สร้างมัน ให้คีย์แค่สิทธิ์อ่าน แล้วมันจะเปลี่ยนอะไรไม่ได้เลย

### เพลย์บุ๊กสำหรับงานยาว

คู่มือในตัวสิบเก้าฉบับ — สร้างเอเจนต์ ตั้งค่า RAG จัดระเบียบแหล่งข้อมูล วางแผน content calendar — ที่ client อ่านก่อนเริ่มงาน

### Drive ของคุณ จากเอดิเตอร์

สร้างและแก้เอกสาร กรอกตาราง Drive เพิ่มโหนดในมายด์แมปหรือช็อตในสตอรีบอร์ด — แล้วการเปลี่ยนแปลงจะอยู่ในแอปให้ทีมของคุณ

### ข้อมูลและบอร์ด

คิวรีฐานข้อมูลที่เชื่อมไว้ผ่านโมเดลเชิงความหมาย สร้างบอร์ดและเพิ่มกราฟ หรือปรับตัวชี้วัดและความสัมพันธ์ของโมเดล

## เซิร์ฟเวอร์เปิดอะไรให้บ้าง

การเชื่อมต่อ คีย์ และส่วนของเวิร์กสเปซที่ client ทำงานได้

### การเชื่อมต่อ

- MCP server ระยะไกลผ่าน Streamable HTTP
- endpoint เดียว แสดงในหน้าตั้งค่า
- สนิปเพ็ตสำหรับ Claude Code และ Cursor
- ค้นพบได้ที่ /.well-known/ai-catalog.json

### คีย์และสิทธิ์

- API key ของเวิร์กสเปซใน header X-API-Key
- คีย์ทำงานในนามสมาชิกที่สร้างมัน
- สิทธิ์ไม่กว้างกว่าของผู้สร้าง
- วันหมดอายุ (ไม่บังคับ)
- แสดงเฉพาะเครื่องมือที่ได้รับอนุญาต

### เอเจนต์

- สร้าง ตั้งค่า และลบเอเจนต์
- แก้แคนวาสเวิร์กโฟลว์ทีละโหนด
- กำหนดเครื่องมือ ทักษะ และความรู้
- บันทึกและกู้คืนเวอร์ชันของแคนวาส
- ทดสอบรันและอ่าน trace

### Drive และคอนเทนต์

- เอกสาร โฟลเดอร์ และตาราง Drive
- มายด์แมป — โหนด รูปทรง และตาราง
- สตอรีบอร์ด — ฉาก ช็อต และเฟรม
- แบรนด์ สินค้า และภาพของแบรนด์
- สล็อตใน content calendar

### ข้อมูล

- แหล่งข้อมูล ตาราง และขอบเขต
- โมเดลเชิงความหมาย: cube ตัวชี้วัด และการเชื่อม
- คิวรีด้วย CubeQL หรือ SQL
- บอร์ด BI แท็บ กราฟ และตัวกรอง

### ช่องทางและกล่องข้อความ

- ช่องทางและการตั้งค่าของช่องทาง
- บทสนทนาและข้อความ
- Care agent และทริกเกอร์
- การ์ดเรลและหน่วยความจำ

## คำถามเกี่ยวกับ MCP

สิ่งที่คนถามก่อนเชื่อม client

### client ไหนใช้ได้บ้าง?

ทุก client ที่รองรับ MCP server ระยะไกลผ่าน Streamable HTTP หน้าตั้งค่ามีสนิปเพ็ตพร้อมใช้สำหรับ Claude Code และ Cursor

### client ทำอะไรในเวิร์กสเปซของฉันได้บ้าง?

ทุกอย่างที่คีย์อนุญาต: สร้างและทดสอบเอเจนต์ แก้เอกสาร ตาราง มายด์แมป และสตอรีบอร์ดใน Drive คิวรีฐานข้อมูลที่เชื่อมไว้ จัดการบอร์ด แบรนด์ content calendar และการตั้งค่าช่องทาง รายการเครื่องมือที่ client เห็นถูกกรองตามสิทธิ์เหล่านั้นแล้ว

### ให้คีย์กับ AI client ปลอดภัยไหม?

คีย์ทำงานในนามสมาชิกที่สร้างมัน และมีสิทธิ์ที่คนนั้นไม่มีไม่ได้ ผ่าน MCP ไม่มีขั้นถามอนุมัติ สิทธิ์ของคีย์จึงเป็นด่านกั้น: ให้แค่สิทธิ์อ่านกับ client ที่ควรอ่านอย่างเดียว และตั้งวันหมดอายุให้คีย์ที่ควรหยุดทำงาน

### ใช้เครดิตของฉันไหม?

เครื่องมือส่วนใหญ่เป็นแค่การอ่านและเขียนธรรมดา เครื่องมือที่สร้างบางอย่าง — โครงร่าง calendar ภาพ หรือการทดสอบรันเอเจนต์ — ใช้เครดิตของเวิร์กสเปซเหมือนตอนใช้ในแอป
