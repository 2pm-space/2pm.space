# ตัวสร้าง AI Agent พร้อมแคนวาสเวิร์กโฟลว์แบบภาพ

เริ่มจากพรอมต์เดียว หรือวาดงานให้เป็นเวิร์กโฟลว์: หาเอกสารที่ถูกต้อง คิดและเรียกเครื่องมือ ตรวจคำตอบ ถามคนเมื่อจำเป็น แล้วตอบกลับ ทุกการรันบอกว่าแต่ละขั้นทำอะไร ใช้ไปเท่าไร และเพราะอะไร

## จากไอเดียสู่เอเจนต์ที่ใช้งานได้ในสามขั้นตอน

วาดขึ้นมา ติดอาวุธ แล้ววางไว้ตรงที่งานอยู่

1. **วาดงาน** — เลือก Simple สำหรับพรอมต์เดียว หรือ Agentic เพื่อจัดงานเป็นโหนดบนแคนวาส — ค้นข้อมูล คิด ตรวจ แตกแขนง — ต่อกันจากซ้ายไปขวา
2. **ให้สิ่งที่มันต้องใช้** — แนบเครื่องมือ ทักษะ ความรู้ และหน่วยความจำให้เอเจนต์หรือให้โหนดเดียว แล้วตั้งการ์ดเรลที่ทุกข้อความต้องผ่าน
3. **ส่งไปทำงาน** — ทดสอบบนแคนวาส แล้วเชื่อมกับช่องทางในกล่องข้อความ ตารางเวลา ให้เอเจนต์อื่นใช้เป็นเครื่องมือ หรือ MCP client

## มากกว่าพรอมต์ที่มีเครื่องมือ

แคนวาสสำหรับงานที่พรอมต์เดียวทำเองไม่ได้

### Simple หรือ Agentic

เอเจนต์แบบง่ายคือการเรียกโมเดลครั้งเดียวด้วย system prompt ของคุณ — เหมาะกับถามตอบ แปล และสรุป เอเจนต์แบบ agentic คือกราฟของโหนด สำหรับงานที่ต้องมีหลายขั้นและการตัดสินใจระหว่างขั้น

### ขั้นตอนสิบหกแบบ

Agent, Crew, Run Agent, Code, Knowledge และ Skill Retrieval, Drive Action, Condition, Parallel, Loop, Evaluation, Human Review, Message, Send — แต่ละแบบเป็นการ์ดที่ลากลงแคนวาสแล้วต่อกับขั้นถัดไป

### ตรวจงานตัวเอง

โหนด Evaluation ให้คะแนนคำตอบด้วยกฎหรือให้ LLM ตัดสิน แล้วส่งต่อ: Pass ไปต่อ Retry ส่งกลับให้เอเจนต์ลองใหม่ ได้ตามจำนวนครั้งที่คุณอนุญาต

### มีคนอยู่ตรงจุดสำคัญ

โหนด Human Review หยุดการรันไว้จนกว่าจะมีคนอนุมัติหรือปฏิเสธ และโหนด Message ถามรายละเอียดจากลูกค้าผ่านฟอร์มหรือปุ่มก่อนที่เวิร์กโฟลว์จะไปต่อได้

### เครื่องมือ ทักษะ และความรู้

เครื่องมือในตัวหกสิบรายการ HTTP API และ Python ของคุณเอง MCP server และเอเจนต์อื่นในฐานะเครื่องมือ ทักษะโหลดเข้าได้ทุกพรอมต์ หรือเฉพาะเมื่อคำถามตรงกัน — คลังขนาดใหญ่จึงไม่กินโทเคนทุกครั้งที่เรียก

### ทดสอบ ตามรอย ย้อนกลับ

รันเวิร์กโฟลว์จากแคนวาสและดูผลลัพธ์ โทเคน และต้นทุนของแต่ละโหนด บันทึกเวอร์ชันของแคนวาส แล้วกู้คืนเมื่อการเปลี่ยนแปลงไม่เวิร์ก

## บนแคนวาสมีอะไรบ้าง

ทุกโหนด รายการโมเดล และทุกที่ที่เอเจนต์รันได้

### การคิดและการลงมือ

- Agent — โมเดล พรอมต์ และเครื่องมือของตัวเอง ในลูปคิดแล้วลงมือ
- Crew — ทีม CrewAI ที่มีหลายเอเจนต์และหลายงาน
- Run Agent — เรียกเอเจนต์ที่คุณสร้างไว้แล้ว
- Code — Python หรือ Bash ในแซนด์บ็อกซ์ ไม่มีค่า LLM

### การควบคุมโฟลว์

- Start — จุดที่ข้อความเข้ามา
- Condition — แตกแขนงตามกฎ ไม่มีค่า LLM
- Parallel — รันทุกแขนงขาออกพร้อมกัน
- Loop และ Exit Loop — วนตามรายการหรือ N ครั้ง

### การตรวจและคน

- Evaluation — กฎหรือ LLM ตัดสิน แล้ว Pass หรือ Retry
- Human Review — หยุดรออนุมัติหรือปฏิเสธ
- Message — ข้อความแชท ฟอร์ม หรือปุ่ม
- Send — ส่งข้อความถึงลูกค้าแล้วไปต่อ

### ความรู้และข้อมูล

- Knowledge Retrieval — ค้นแบบความหมาย คีย์เวิร์ด หรือแบบผสม
- Skill Retrieval — จับคู่ทักษะโดยไม่ต้องมีขั้น LLM
- Drive Action — สร้าง อ่าน หรืออัปเดตเอกสาร ตาราง มายด์แมป และสตอรีบอร์ด
- หน่วยความจำที่คงอยู่ระหว่างบทสนทนา และหน่วยความจำของเวิร์กสเปซที่ทุกเอเจนต์ใช้ร่วมกัน

### โมเดล

- Anthropic, OpenAI, Google และ DeepSeek
- Alibaba Qwen, Z.AI GLM, xAI และ MiniMax
- โมเดลต่อโหนด Agent ไม่ใช่โมเดลเดียวทั้งเวิร์กโฟลว์
- หักจากเครดิตของเวิร์กสเปซ — ไม่ต้องจัดการคีย์ของผู้ให้บริการ

### รันที่ไหนได้บ้าง

- ช่องทางในกล่องข้อความ: Messenger, Telegram, Zalo ส่วนตัว แชทบนเว็บไซต์
- ตัวจัดตารางเวลา ตามรอบที่กำหนด
- เอเจนต์ตัวอื่น ในฐานะเครื่องมือ
- MCP client อย่าง Claude Code และ Cursor
- Playground ก่อนที่ลูกค้าคนไหนจะเห็น

## คำถามเกี่ยวกับตัวสร้างเอเจนต์

สิ่งที่คนถามก่อนสร้างเวิร์กโฟลว์แรก

### ต้องเขียนโค้ดเป็นไหมถึงจะสร้างเอเจนต์ได้?

ไม่ต้อง เอเจนต์แบบง่ายคือฟอร์ม: โมเดล พรอมต์ เครื่องมือ เอเจนต์แบบ agentic วาดบนแคนวาสด้วยการลากโหนดแล้วต่อเข้าด้วยกัน โค้ดเป็นทางเลือก — โหนด Code รัน Python หรือ Bash เมื่อคุณอยากให้ขั้นหนึ่งทำงานโดยไม่ใช้โมเดล

### เอเจนต์แบบง่ายกับแบบ agentic ต่างกันอย่างไร?

เอเจนต์แบบง่ายเรียกโมเดลครั้งเดียวด้วย system prompt พร้อมเครื่องมือและความรู้ที่คุณแนบไว้ เอเจนต์แบบ agentic รันกราฟ: แต่ละโหนดทำงานหนึ่งอย่าง — ค้นข้อมูล คิด ตรวจ แตกแขนง วนลูป ถามคน — และเส้นเชื่อมกำหนดว่าจะเกิดอะไรต่อ

### เอเจนต์ใช้โมเดลอะไรได้บ้าง?

รายการครอบคลุม Anthropic, OpenAI, Google, DeepSeek, Alibaba (Qwen), Z.AI (GLM), xAI และ MiniMax และบนแคนวาสแบบ agentic แต่ละโหนด Agent เลือกโมเดลของตัวเองได้ ค่าใช้งานหักจากเครดิตของเวิร์กสเปซ จึงไม่ต้องจัดการคีย์ของผู้ให้บริการ

### จะทดสอบเอเจนต์ก่อนที่ลูกค้าจะเห็นได้อย่างไร?

รันจากแคนวาสหรือใน Playground ทุกการรันถูกบันทึกพร้อมอินพุต เอาต์พุต โทเคน ต้นทุน และการเรียกเครื่องมือของแต่ละขั้น คุณจึงเห็นว่าคำตอบผิดตรงไหน และแก้เฉพาะโหนดนั้นแทนการแก้ทั้งพรอมต์

### หลายคนแก้เอเจนต์ตัวเดียวกันได้ไหม?

ได้ แคนวาสซิงก์แบบเรียลไทม์และแสดงว่าใครเปิดอยู่บ้าง ส่วนเวอร์ชันของแคนวาสช่วยบันทึกสถานะที่ใช้งานได้ดีไว้และกู้คืนภายหลัง

### สร้างเสร็จแล้วเอเจนต์รันที่ไหนได้?

บนช่องทางในกล่องข้อความ — Messenger, Telegram, Zalo ส่วนตัว หรือแชทบนเว็บไซต์ — ตามตารางเวลา เป็นเครื่องมือที่เอเจนต์อื่นเรียกใช้ หรือจาก MCP client อย่าง Claude Code หรือ Cursor
