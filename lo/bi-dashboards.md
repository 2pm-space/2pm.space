## ແດຊບອດທີ່ເລີ່ມຕົ້ນ ດ້ວຍຄຳຖາມ

ຖາມຖານຂໍ້ມູນຂອງທ່ານດ້ວຍພາສາທຳມະດາ, ປັກໝຸດກຣາຟ, ແລ້ວມັນເຂົ້າຮ່ວມບອດທີ່ທີມຂອງທ່ານເປີດຄ້າງໄວ້ — ພ້ອມແທັບ, ຕົວກັ່ນຕອງທີ່ເຖິງທຸກແຜ່ນ, ແລະ ການປຽບທຽບກັບໄລຍະກ່ອນພຽງຄລິກດຽວ.

## ຈາກຄຳຖາມ ສູ່ບອດ ໃນສາມຂັ້ນຕອນ

ຖາມມັນ, ປັກໝຸດມັນ, ແບ່ງປັນມັນ.

1. **ຖາມ, ຫຼື ຂຽນ SQL ເອງ** — Ask Data ຕອບເປັນພາສາທຳມະດາພ້ອມກຣາຟ. SQL Lab ໃຫ້ທ່ານຂຽນຄຳສັ່ງເອງ, ຫຼື ໃຫ້ AI ຮ່າງມັນຈາກຄຳອະທິບາຍ.
2. **ປັກໝຸດໃສ່ບອດ** — ປັກໝຸດກຣາຟໃສ່ບອດ ແລະ ແທັບ — ອັນໃໝ່ ຫຼື ອັນທີ່ມີຢູ່ແລ້ວ. ແຜ່ນຮັກສາຄຳສັ່ງຂອງມັນໄວ້, ບໍ່ແມ່ນພຽງແຕ່ຮູບພາບ.
3. **ແບ່ງປັນມັນ** — ແບ່ງປັນບອດໃຫ້ຄົນທີ່ຕ້ອງການ. ຕົວກັ່ນຕອງຢູ່ໃນ URL, ລິ້ງດຽວກັນຈຶ່ງເປີດຕາມມຸມມອງທີ່ທ່ານກຳລັງເບິ່ງຢູ່.

## ບອດທີ່ຮັກສາຄວາມຈິງ

ທຸກແຜ່ນເປັນຄຳສັ່ງເທິງໂມເດວຂໍ້ມູນຂອງທ່ານ, ບໍ່ແມ່ນພາບໜ້າຈໍຂອງມັນ.

### ນິຍາມລາຍຮັບດຽວ

ແຜ່ນສືບຄົ້ນໂມເດວເຊິງຄວາມໝາຍດຽວກັນກັບ Ask Data, ຕົວຊີ້ວັດທີ່ກຳນົດຄັ້ງດຽວຈຶ່ງມີຄວາມໝາຍດຽວກັນໃນທຸກກຣາຟ ແລະ ທຸກບອດ.

### ຕົວກັ່ນຕອງທີ່ເຖິງທຸກແຜ່ນ

ເພີ່ມຕົວກັ່ນຕອງລະດັບບອດເທິງມິຕິໃດກໍໄດ້ທີ່ໂມເດວຂອງທ່ານໝາຍວ່າກັ່ນຕອງໄດ້ — ຂໍ້ຄວາມ, ເລືອກ, ເລືອກຫຼາຍ, ວັນທີ ຫຼື ຊ່ວງວັນທີ — ແລ້ວທຸກແຜ່ນທີ່ໃຊ້ມິຕິນັ້ນຈະຮັນໃໝ່. ແຜ່ນທີ່ເຮັດຕາມບໍ່ໄດ້ ຈະບອກໄວ້.

### ໄລຍະນີ້ ທຽບກັບໄລຍະກ່ອນ

ປຽບທຽບກັບໄລຍະກ່ອນ, ໄລຍະດຽວກັນປີກ່ອນ ຫຼື ຊ່ວງທີ່ທ່ານເລືອກ, ແລະ ຈັດກຸ່ມເວລາໃໝ່ຕາມວັນ, ອາທິດ, ເດືອນ, ໄຕມາດ ຫຼື ປີ.

### ເກົ້າວິທີແຕ້ມມັນ

ແທ່ງ, ແທ່ງລວງນອນ, ວາງຊ້ອນ, ວາງຊ້ອນ 100%, ເສັ້ນ, ພື້ນທີ່, ວົງມົນ, ກະແຈກກະຈາຍ ແລະ ກາດຕົວເລກດຽວ — ພ້ອມການຕັ້ງຄ່າແກນ, ຄຳອະທິບາຍ, ປ້າຍຂໍ້ມູນ ແລະ ສີຊຸດຂໍ້ມູນຕໍ່ແຜ່ນ.

### SQL Lab ສຳລັບຄວາມແມ່ນຍຳ

ຂຽນ CubeQL ເທິງໂມເດວ, ອ່ານ SQL ແທ້ທີ່ມັນຄອມໄພລ໌ອອກມາ, ບັນທຶກຄຳສັ່ງຂອງທ່ານ, ແລະ ປ່ຽນອັນທີ່ດີໃຫ້ເປັນ derived cube ໃຊ້ຄືນໄດ້.

### ຕົວແທນກໍສ້າງບອດໄດ້ນຳ

ເຄື່ອງມື BI Board ໃຫ້ຕົວແທນສ້າງບອດ, ເພີ່ມກຣາຟ ແລະ ອ່ານຂໍ້ມູນຂອງແຜ່ນໄດ້ — ແລະ ການດຳເນີນການດຽວກັນນີ້ຢູ່ໃນ MCP server ຂອງພວກເຮົາ ສຳລັບ Claude Code ຫຼື Cursor.

## ບອດຮອງຮັບຫຍັງແດ່

ກຣາຟ, ຮູບແບບ, ຕົວກັ່ນຕອງ ແລະ ເວລາ — ລາຍການເຕັມ.

### ຮູບແບບກຣາຟ

- ແທ່ງ ແລະ ແທ່ງລວງນອນ
- ວາງຊ້ອນ ແລະ ວາງຊ້ອນ 100%
- ເສັ້ນ ແລະ ພື້ນທີ່
- ວົງມົນ
- ກະແຈກກະຈາຍ
- ກາດຕົວເລກ

### ຮູບແບບການສະແດງ

- ຕົວເລກ, ເງິນ, ເປີເຊັນ ຫຼື ໄບຕ໌
- ຈຸດທົດສະນິຍົມ, ແບບຫຍໍ້ K / M / B ແລະ ຕົວແບ່ງຫຼັກ
- ຄຳນຳໜ້າ ແລະ ຄຳຕໍ່ທ້າຍ
- ຊື່ແກນ, ຄ່າຕ່ຳສຸດ, ສູງສຸດ ແລະ log scale
- ຄຳອະທິບາຍ, ປ້າຍຂໍ້ມູນ ແລະ ສີຊຸດຂໍ້ມູນ
- ການແກ້ໄຂຮູບແບບຂອງໂມເດວ ຕໍ່ຊ່ອງຂໍ້ມູນ

### ຕົວກັ່ນຕອງ

- ເທິງມິຕິໃດກໍໄດ້ຂອງໂມເດວທີ່ກັ່ນຕອງໄດ້
- ຂໍ້ຄວາມ, ເລືອກ, ເລືອກຫຼາຍ, ວັນທີ ແລະ ຊ່ວງວັນທີ
- ແມ່ນ, ບໍ່ແມ່ນ, ມີ, ຂຶ້ນຕົ້ນດ້ວຍ, ລົງທ້າຍດ້ວຍ
- ເກັບໄວ້ໃນ URL ສຳລັບມຸມມອງທີ່ແບ່ງປັນໄດ້
- ຄົ້ນຫາພາຍໃນໝວດຂອງແຜ່ນ

### ເວລາ

- ປຽບທຽບກັບໄລຍະກ່ອນ
- ຫຼື ໄລຍະດຽວກັນປີກ່ອນ
- ຫຼື ຊ່ວງກຳນົດເອງ
- ຈັດກຸ່ມຕາມວັນ, ອາທິດ, ເດືອນ, ໄຕມາດ ຫຼື ປີ
- ຊ່ວງວັນທີແບບສຳພັດ ທີ່ຍັງສຳພັດຕະຫຼອດ

### SQL Lab

- CubeQL ເທິງໂມເດວເຊິງຄວາມໝາຍ
- SQL ແທ້ທີ່ມັນຄອມໄພລ໌ອອກມາ
- AI ຮ່າງຄຳສັ່ງຈາກຄຳອະທິບາຍ
- ຄຳສັ່ງທີ່ບັນທຶກໄວ້
- ຄຳສັ່ງທີ່ບັນທຶກເປັນ derived cube

### ບອດ ແລະ ການແບ່ງປັນ

- ຫຼາຍແທັບຕໍ່ບອດ, ປ່ຽນຊື່ ແລະ ຈັດລຳດັບໃໝ່ໄດ້
- ໂຄງແປງແບບລາກ-ປັບຂະໜາດ
- ໂຫລດແຜ່ນໃໝ່ຕາມຕ້ອງການ
- ແບ່ງປັນກັບເພື່ອນຮ່ວມທີມ
- ຕົວແທນ ແລະ MCP client ສ້າງບອດໄດ້

## ຄຳຖາມກ່ຽວກັບ BI Dashboards

ສິ່ງທີ່ຄົນຖາມ ກ່ອນສ້າງບອດທຳອິດ.

### ບອດໃຊ້ຖານຂໍ້ມູນໃດໄດ້ແດ່?

ການເຊື່ອມຕໍ່ໃດກໍໄດ້ທີ່ Ask Data ຮອງຮັບ: PostgreSQL, MySQL, Redshift, ClickHouse, Snowflake ແລະ BigQuery. ບອດສືບຄົ້ນຜ່ານໂມເດວເຊິງຄວາມໝາຍຂອງທ່ານ.

### ກຣາຟຂຶ້ນບອດແນວໃດ?

ຈາກ Ask Data ຫຼື SQL Lab: ເມື່ອກຣາຟຖືກຕ້ອງແລ້ວ ເລືອກ Pin to board ແລ້ວເລືອກບອດ ແລະ ແທັບ. ແຜ່ນຮັກສາຄຳສັ່ງໄວ້, ບໍ່ແມ່ນພຽງແຕ່ຮູບພາບ.

### ຕົວກັ່ນຕອງເຮັດວຽກກັບທຸກແຜ່ນບໍ່?

ຕົວກັ່ນຕອງລະດັບບອດ ໃຊ້ກັບທຸກແຜ່ນທີ່ຄຳສັ່ງໃຊ້ມິຕິນັ້ນ, ແລ້ວຮັນໃໝ່. ແຜ່ນທີ່ກັ່ນຕອງບໍ່ໄດ້ ຈະບອກໄວ້ໃນຫົວຂອງມັນ ແທນທີ່ຈະສະແດງຕົວເລກທີ່ບໍ່ໄດ້ກັ່ນຕອງແບບງຽບໆ.

### ປຽບທຽບກັບເດືອນແລ້ວ ຫຼື ປີແລ້ວໄດ້ບໍ່?

ໄດ້. ເປີດການປຽບທຽບ ແລ້ວເລືອກໄລຍະກ່ອນ, ໄລຍະດຽວກັນປີກ່ອນ ຫຼື ຊ່ວງກຳນົດເອງ; ແຜ່ນທີ່ມີຊ່ວງວັນທີຈະສະແດງທັງສອງໄລຍະ.

### ຕົວແທນໃຊ້ບອດໄດ້ບໍ່?

ໄດ້. ເຄື່ອງມື BI Board ໃຫ້ຕົວແທນສ້າງບອດ, ເພີ່ມກຣາຟ ແລະ ອ່ານຂໍ້ມູນຂອງແຜ່ນ, ແລະ ການດຳເນີນການດຽວກັນນີ້ໃຫ້ Claude Code ຫຼື Cursor ຜ່ານ MCP server.
