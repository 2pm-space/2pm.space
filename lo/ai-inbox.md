### 2pm AI ໃຫ້ຄຳປຶກສາ

ຕົວແທນດຽວຢູ່ເບື້ອງຫຼັງທຸກຊ່ອງທາງ, ອີງໃສ່ທຸກສິ່ງທີ່ພື້ນທີ່ເຮັດວຽກຂອງທ່ານຮູ້.

- **ຄວາມຮູ້** — ຕອບຈາກເອກະສານ ແລະ ແຄັດຕາລັອກຂອງທ່ານ, ລວມທັງຮູບສິນຄ້າ
- **ທັກສະ** — ຄູ່ມືການຂາຍຂອງທ່ານ — ຖາມຫຍັງ, ສະເໜີຫຍັງ, ເວົ້າແບບໃດ
- **ເຄື່ອງມື** — ຊອກຫາສິນຄ້າ, ຄຳສັ່ງຊື້ເກົ່າ ແລະ ຄ່າສົ່ງ ໃນລະຫວ່າງການສົນທະນາ
- **ໜ່ວຍຄວາມຈຳ** — ຈື່ສິ່ງທີ່ລູກຄ້າເຄີຍບອກໄວ້ໃນຄັ້ງກ່ອນ
- **Customer 360** — ທຸກຊ່ອງທາງທີ່ລູກຄ້າເຄີຍໃຊ້ ລວມເປັນປະຫວັດດຽວ
- **ຮາວກັນ** — ຮັກສາທຸກຄຳຕອບໃຫ້ຢູ່ໃນຂອບເຂດທີ່ມັນເວົ້າ ແລະ ເຮັດໄດ້

1. **ດຳເນີນການ** — ຢືນຢັນລາຍການສິນຄ້າ, ເບີໂທ ແລະ ທີ່ຢູ່ຈັດສົ່ງ ກັບລູກຄ້າອີກຄັ້ງ. `ບັນທຶກທີ່ຢູ່ແລ້ວ`
2. **ສ້າງຄຳສັ່ງຊື້** — ຄຳສັ່ງຂາຍທີ່ຄິດລາຄາຈາກແຄັດຕາລັອກຂອງທ່ານ — ເປັນຮ່າງໃຫ້ທີມຢືນຢັນ ຫຼື ສົ່ງອະນຸມັດໂດຍກົງ. `SO-2026-48213`
3. **ຈອງການສົ່ງແບບ COD** — ຈອງກັບ Viettel Post ພ້ອມຍອດເງິນທີ່ຕ້ອງເກັບປາຍທາງ, ຫຼື ເກັບໄວ້ໃນໃບສົ່ງສິນຄ້າສຳລັບບໍລິສັດຂົນສົ່ງຂອງທ່ານເອງ. `COD · ລະຫັດຕິດຕາມ`
4. **ກ່າວຂອບໃຈ** — ເມື່ອມີການລາຍງານວ່າສົ່ງຮອດແລ້ວ, ກົດເຫດການຈະສົ່ງຄຳຂອບໃຈ — ຂຽນຈາກການສົນທະນາ ຫຼື ຈາກແມ່ແບບຂອງທ່ານ. `ສົ່ງຮອດ → ຂອບໃຈແລ້ວ`

**ລະຫວ່າງທາງ**

- **ຖ້າລູກຄ້າໃຫ້ເບີໂທ → ເພີ່ມເປັນໝູ່ໃນ Zalo.** ເບີໂທຖືກປັກໝຸດໄວ້ກັບຜູ້ຕິດຕໍ່ ແລະ Zalo ສ່ວນຕົວຂອງທ່ານຈະສົ່ງຄຳຂໍເປັນໝູ່ — ແບບເວັ້ນຈັງຫວະ, ລະຫວ່າງ 8 ໂມງເຊົ້າ ຫາ 8 ໂມງແລງ. ເມື່ອລູກຄ້າຍອມຮັບ, ແຊັດ Zalo ຈະລວມເຂົ້າກັບລູກຄ້າຄົນດຽວກັນ. `+84 ••• 412 → Zalo`
- **ຖ້າລູກຄ້າມິດງຽບ → Care ຕິດຕາມຕໍ່.** Care agent ອ່ານການສົນທະນາ ແລະ ຕິດຕາມຕໍ່ຫຼັງຈາກລູກຄ້າງຽບໄປຕາມເວລາທີ່ທ່ານກຳນົດ — ຕາມຊົ່ວໂມງງຽບທີ່ທ່ານຕັ້ງ, ຈຳກັດຈຳນວນຕໍ່ຄົນ ແລະ ຢູ່ພາຍໃນກອບເວລາສົ່ງຂໍ້ຄວາມຂອງຊ່ອງທາງ. `ງຽບ 2h → ຕິດຕາມຕໍ່`
- **ຖ້າລູກຄ້າຂໍລົມກັບຄົນ → ທີມຂອງທ່ານເຂົ້າຊ່ວຍ.** Agent ສົ່ງການແຈ້ງເຕືອນແບບ push ທີ່ເປີດການສົນທະນາໃຫ້ທີມຂອງທ່ານ. ໃຜກໍຕອບຢູ່ນັ້ນໄດ້ — ຫຼື ຢຸດ AI ເພື່ອຮັບການສົນທະນາໄວ້ເອງ. `ແຈ້ງເຕືອນ → ຢຸດ AI`
- **ຖ້າລູກຄ້າສະແປມ ຫຼື ໃຊ້ຄຳຫຍາບ → ຕົວແທນຢຸດຕອບ.** ມັນຈະປິດ AI ແລະ Care ສຳລັບການສົນທະນານັ້ນ ແລະ ຝາກເຫດຜົນສັ້ນໆໜຶ່ງແຖວໄວ້ໃຫ້ທີມ. ໃຜກໍເປີດຄືນໄດ້ຈາກກ່ອງຂໍ້ຄວາມ. `ປິດ AI · ບັນທຶກເຫດຜົນແລ້ວ`

## ຈາກເພຈທີ່ເຊື່ອມຕໍ່ ສູ່ຕົວແທນທີ່ເຮັດວຽກໄດ້

1. **ເຊື່ອມຕໍ່ຊ່ອງທາງ** — ເຊື່ອມເພຈ Facebook, ບັນຊີ Zalo, ບອດ Telegram ຫຼື ວິດເຈັດເວັບໄຊ. ປະຫວັດທີ່ມີຢູ່ຈະຖືກດຶງເຂົ້າມາ, ກ່ອງຂໍ້ຄວາມຈຶ່ງເປີດມາພ້ອມການສົນທະນາທີ່ທ່ານມີຢູ່ແລ້ວ ແທນທີ່ຈະເປັນລາຍການເປົ່າ.
2. **ວາງຕົວແທນໄວ້ເບື້ອງຫຼັງ** — ເລືອກວ່າ agent ໃດຕອບຢູ່ຊ່ອງທາງໃດ ແລະ ໃຫ້ເອກະສານ ແລະ ເຄື່ອງມືທີ່ມັນຕ້ອງການ. Agent ຈະຕອບເອງເມື່ອລູກຄ້າສົ່ງຂໍ້ຄວາມຊຸດໜຶ່ງຈົບ — ທ່ານກຳນົດໄດ້ວ່າໃຫ້ລໍຖ້າດົນປານໃດ, ການສົນທະນາທີ່ຕິດແທັກໃດໃຫ້ທີມຂອງທ່ານຈັດການເອງ, ແລະ ໂໝດ sandbox ທີ່ເກັບຄຳຕອບໄວ້ໃນແອັບລະຫວ່າງທົດສອບ.
3. **ຕິດຕາມ, ເຂົ້າຊ່ວຍ, ປັບປຸງ** — ທຸກຄຳຕອບເກັບການເຮັດວຽກຂອງມັນ — ການເອີ້ນເຄື່ອງມື ແລະ ຄ່າໃຊ້ຈ່າຍ — ໄວ້ໃນບັນທຶກການປະມວນຜົນ. ຢຸດ AI ໃນການສົນທະນາທີ່ຕ້ອງການຄົນ, ແລະ ໃຫ້ຄະແນນ ຫຼື ປັບປຸງຄຳຕອບ: ການແກ້ໄຂຊ່ວຍ agent ດີຂຶ້ນທັນທີ ແລະ ໃຊ້ຝຶກພາຍຫຼັງ.

## ສ້າງມາສຳລັບທີມທີ່ເຮັດວຽກກັບກ່ອງຂໍ້ຄວາມແທ້ໆ

ບໍ່ແມ່ນແຊັດບອດທີ່ຕິດໄວ້ກັບເພຈ — ແຕ່ເປັນຄິວຮ່ວມທີ່ທີມ ແລະ ຕົວແທນຂອງທ່ານເຮັດວຽກນຳກັນ.

### ຕົວແທນຢູ່ແນວໜ້າ

ຊີ້ຕົວແທນໜຶ່ງຂອງທ່ານໄປທີ່ຊ່ອງທາງ ແລ້ວມັນຈະຕອບດ້ວຍນ້ຳສຽງຂອງທ່ານ, ໃຊ້ແຄັດຕາລັອກສິນຄ້າ, ເອກະສານ ແລະ ທຸກສິ່ງທີ່ມັນຈື່ກ່ຽວກັບລູກຄ້າຄົນນັ້ນ. ມັນມີເຄື່ອງມືຂອງທ່ານນຳ, ຈຶ່ງກວດຄຳສັ່ງຊື້ໄດ້ ແທນທີ່ຈະຂໍໂທດວ່າບໍ່ຮູ້.

### ສົ່ງຕໍ່ ໂດຍບໍ່ຕ້ອງແຍ່ງກັນ

ເພື່ອນຮ່ວມທີມຄົນໃດກໍຕອບໄດ້ລະຫວ່າງການສົນທະນາ — ການສົນທະນາເກົ່າ, ປະຫວັດເກົ່າ — ແລະ ຄຳຕອບຂອງເຂົາຈະຍົກເລີກຄຳຕອບທີ່ agent ກຳລັງຂຽນ ໂດຍບໍ່ປິດ agent. ຢຸດ AI ຈະມອບການສົນທະນາໃຫ້ທີມຂອງທ່ານ ຈົນກວ່າມີຄົນເປີດຄືນ. ບ່ອນໃດທີ່ຄົນຕ້ອງຕັດສິນ agent ກໍປ່ອຍໃຫ້ຄົນ: ອໍເດີທີ່ມັນຮັບໄວ້ຈະເປັນຮ່າງລໍຖ້າທີມຢືນຢັນ ເວັ້ນແຕ່ທ່ານອະນຸຍາດໃຫ້ມັນຢືນຢັນເອງ, ແລະ ມັນສົ່ງການແຈ້ງເຕືອນແບບ push ທີ່ເປີດການສົນທະນາໃຫ້ທີມໄດ້.

### ລູກຄ້າຄົນດຽວ ບໍ່ແມ່ນຫ້າການສົນທະນາ

ຜູ້ຕິດຕໍ່ຖືກຈັບຄູ່ຂ້າມຊ່ອງທາງ, ຄອມເມັນ Facebook, ການຕອບ Messenger ແລະ ຂໍ້ຄວາມ Zalo ຈຶ່ງເປັນຄົນດຽວທີ່ມີປະຫວັດດຽວ — ພ້ອມເບີໂທ, ແທັກ ແລະ ຄຸນລັກສະນະຂອງເຂົາ.

### ເບີໂທ ຈັບໄດ້ ແລະ ເກັບໄວ້

ເບີທີ່ລູກຄ້າພິມມາໃນລະຫວ່າງການສົນທະນາ ຈະຖືກກວດຈັບ, ກວດຊ້ຳກັບເບີທີ່ທ່ານມີຢູ່ແລ້ວ, ແລະ ປັກໝຸດໄວ້ກັບຜູ້ຕິດຕໍ່ — ໂດຍຄັດສິ່ງລົບກວນອອກ (ເບີພະນັກງານ, ເບີໃນຂໍ້ຄວາມທີ່ສົ່ງຕໍ່ມາ) ແທນທີ່ຈະນັບເຂົ້າ.

### Care ຕິດຕາມຕໍ່ ໂດຍອ່ານການສົນທະນາກ່ອນ

ການສົນທະນາທີ່ງຽບໄປ ຈະຖືກຕິດຕາມຕໍ່ໂດຍຕົວແທນທີ່ໄດ້ອ່ານປະຫວັດແລ້ວ — ຕາມຊົ່ວໂມງງຽບທີ່ທ່ານຕັ້ງ, ຈຳກັດຈຳນວນເທື່ອທີ່ຕິດຕໍ່ຄົນໜຶ່ງໄດ້, ແລະ ບໍ່ເຄີຍສົ່ງຂໍ້ຄວາມດຽວກັນແບບຫວ່ານ.

### ຕົວເລກທີ່ນຳໄປໃຊ້ໄດ້

ປະລິມານ, ເວລາຕອບ ແລະ ການແຍກຕາມຊ່ອງທາງ, ຄຳນວນໄວ້ລ່ວງໜ້າເປັນລາຍຊົ່ວໂມງ ແດຊບອດຈຶ່ງເປີດທັນທີ ແທນທີ່ຈະສະແກນຂໍ້ຄວາມໜຶ່ງປີທຸກຄັ້ງທີ່ມີຄົນປ່ຽນຊ່ວງວັນທີ.

### ຂໍ້ຄວາມໜຶ່ງສົ່ງຫຍັງໄດ້ແດ່

- ຮູບພາບ ແລະ ອັລບັມ, ໄຟລ໌, ສະຕິກເກີ
- ຂໍ້ຄວາມສຽງ, ຖອດເປັນຕົວໜັງສືທີ່ຄົ້ນຫາໄດ້
- ສະຖານທີ່, ໂພລ, ບັດສິນຄ້າ ແລະ ບັດແຫຼ່ງທີ່ມາຈາກໂຄສະນາ
- ການຕອບແບບອ້າງອີງ, ສະແດງຄູ່ກັບຂໍ້ຄວາມທີ່ມັນຕອບ
- ແຊັດກຸ່ມ ພ້ອມລະບຸຕົວຕົນແຕ່ລະຜູ້ເວົ້າ

### ການຈັດການຄິວ

- ຄົ້ນຫາທັງຂໍ້ຄວາມ ພ້ອມສະແດງສ່ວນທີ່ກົງກັນ
- ກັ່ນຕອງຕາມຊ່ອງທາງ, ແທັກ, ປະເພດ ແລະ ລໍຖ້າຕອບ
- ຄຳຕອບດ່ວນທີ່ທັງທີມໃຊ້ຮ່ວມກັນ
- ແທັກ, ປ້າຍກຳກັບ ແລະ ຄຸນລັກສະນະກຳນົດເອງ
- ສະຫຼຸບການສົນທະນາໃນແຜງຜູ້ຕິດຕໍ່

### ການຄວບຄຸມ

- ສິດເຂົ້າຊ່ອງທາງ ຕໍ່ສະມາຊິກ, ບົດບາດ ຫຼື ທີມ
- ອໍເດີທີ່ agent ຮັບໄວ້ ເກັບເປັນຮ່າງຈົນກວ່າພະນັກງານຢືນຢັນ
- ຮາວກັນ ກຳນົດສິ່ງທີ່ຕົວແທນເວົ້າໄດ້
- ບລັອກຜູ້ຕິດຕໍ່ຈາກໃນການສົນທະນາ
- ບັນທຶກການເຮັດວຽກຄົບຖ້ວນຕໍ່ຄຳຕອບ, ພ້ອມຄ່າໃຊ້ຈ່າຍ

### ຕິດຕາມໃຫ້ທັນ

- ສະຖິຕິສະຫຼຸບລາຍຊົ່ວໂມງຕໍ່ຊ່ອງທາງ
- Care ຕິດຕາມຕໍ່ ພ້ອມຊົ່ວໂມງງຽບ ແລະ ການຈຳກັດ

## ຄຳຖາມກ່ຽວກັບ AI Inbox

ສິ່ງທີ່ທີມຕ່າງໆຖາມ ກ່ອນໃຫ້ຕົວແທນເບິ່ງແຍງເພຈທຳອິດ.

### ຂ້ອຍເຊື່ອມຕໍ່ຊ່ອງທາງສົ່ງຂໍ້ຄວາມໃດໄດ້ແດ່?

Facebook Messenger (ລວມທັງຄອມເມັນໃຕ້ໂພສໃນເພຈຂອງທ່ານ), Telegram, Zalo ສ່ວນຕົວທີ່ເຂົ້າສູ່ລະບົບດ້ວຍລະຫັດ QR, Pancake, ແລະ ວິດເຈັດແຊັດທີ່ທ່ານຝັງໄວ້ໃນເວັບໄຊຂອງທ່ານເອງ, ສ່ວນ Zalo Official Account ຈະມາໄວໆນີ້. ຊ່ອງທາງອື່ນໆເຊື່ອມຕໍ່ຜ່ານຊ່ອງທາງ API ກຳນົດເອງ, ເຊິ່ງເປັນພຽງ webhook ເຂົ້າ ແລະ webhook ອອກ — ບໍ່ຕ້ອງຂຽນໂຄດໃໝ່ຝັ່ງພວກເຮົາ.

### AI ຕອບເອງ ຫຼື ພະນັກງານຂອງຂ້ອຍຍັງຕ້ອງຕອບ?

ທັງສອງ. Agent ຕອບທຸກຂໍ້ຄວາມໃໝ່ເອງ ເມື່ອລູກຄ້າສົ່ງຂໍ້ຄວາມຊຸດໜຶ່ງຈົບ, ແລະ ທີມຂອງທ່ານຕອບໃນການສົນທະນາດຽວກັນໄດ້ທຸກເວລາ — ຄຳຕອບຂອງເພື່ອນຮ່ວມທີມຈະຍົກເລີກຄຳຕອບທີ່ agent ກຳລັງຂຽນ ແລະ AI ຍັງເປີດຢູ່. ຢຸດ AI ຈະມອບການສົນທະນາໃຫ້ທີມ (ແລະ ຢຸດການຕິດຕາມ care ໃນນັ້ນນຳ) ຈົນກວ່າມີຄົນເປີດຄືນ, ແລະ ການສົນທະນາທີ່ມີແທັກທີ່ທ່ານເລືອກ ສາມາດປ່ອຍໃຫ້ທີມຈັດການທັງໝົດ. ບໍ່ມີຂັ້ນຕອນອະນຸມັດລະຫວ່າງການສົນທະນາ; ສຳລັບອໍເດີ ຈຸດກວດແມ່ນຕົວອໍເດີເອງ — agent ສ້າງຮ່າງໃຫ້ທີມຢືນຢັນ ເວັ້ນແຕ່ທ່ານອະນຸຍາດໃຫ້ມັນຢືນຢັນເອງ.

### ການສົນທະນາຈາກລູກຄ້າຄົນດຽວກັນ ຢູ່ນຳກັນບໍ່?

ຢູ່ນຳກັນ. ການສົນທະນາຖືກເຊື່ອມໂຍງດ້ວຍເບີໂທ ຫຼື ອີເມວທີ່ກົງກັນ, ຄົນທີ່ຄອມເມັນໃນໂພສ Facebook ແລ້ວຕໍ່ມາສົ່ງຂໍ້ຄວາມຫາທ່ານທາງ Zalo ຈຶ່ງສະແດງເປັນລູກຄ້າຄົນດຽວທີ່ມີປະຫວັດດຽວ — ລວມທັງເບີໂທທີ່ກວດພົບໃນການສົນທະນາ, ຄຸນລັກສະນະກຳນົດເອງທີ່ທີມຂອງທ່ານກອກ, ແລະ ຂໍ້ມູນໂປຣໄຟລ໌ທີ່ດຶງມາຈາກລະບົບຂອງທ່ານເອງ.

### ຮູບ, ຂໍ້ຄວາມສຽງ ແລະ ໄຟລ໌ ຈະເປັນແນວໃດ?

ພວກມັນຖືກເກັບໄວ້ກັບການສົນທະນາ ແລະ ສະແດງໃນແຖວ — ຮູບ, ອັລບັມ, ສະຕິກເກີ, ໄຟລ໌, ສະຖານທີ່, ໂພລ ແລະ ບັດສິນຄ້າ ລ້ວນສະແດງເປັນຕົວມັນເອງ ບໍ່ແມ່ນລິ້ງທີ່ເສຍ. ຂໍ້ຄວາມສຽງຖືກຖອດອັດຕະໂນມັດ, ຂໍ້ຄວາມສຽງຈຶ່ງເປັນຕົວໜັງສືທີ່ຄົ້ນຫາໄດ້ ແລະ ຕົວແທນອ່ານ ແລະ ຕອບໄດ້ແທ້.

### ຂ້ອຍກຳນົດໄດ້ບໍ່ວ່າພະນັກງານຄົນໃດເຫັນຊ່ອງທາງໃດ?

ໄດ້. ສິດເຂົ້າຊ່ອງທາງກຳນົດຕໍ່ສະມາຊິກ, ຕໍ່ບົດບາດ ຫຼື ຕໍ່ທີມ, ເອເຈນຊີຈຶ່ງໃຫ້ທີມລູກຄ້າໜຶ່ງເຂົ້າເພຈໜຶ່ງໄດ້ ໂດຍບໍ່ເປີດເຜີຍສ່ວນອື່ນຂອງພື້ນທີ່ເຮັດວຽກ. ທຸກສິ່ງອື່ນໃນພື້ນທີ່ເຮັດວຽກໃຊ້ລະບົບສິດດຽວກັນ.

### ກ່ອງຂໍ້ຄວາມຕິດຕາມລູກຄ້າທີ່ມິດງຽບໄປໄດ້ບໍ່?

ໄດ້ — ນັ້ນແມ່ນໜ້າທີ່ຂອງ Care. ທ່ານຕັ້ງຕົວກະຕຸ້ນ (ການສົນທະນາທີ່ງຽບມາ N ຊົ່ວໂມງ, ແທັກ, ຕົວກັ່ນຕອງ), ຊົ່ວໂມງງຽບທີ່ຫ້າມສົ່ງເດັດຂາດ, ແລະ ຈຳກັດຈຳນວນເທື່ອທີ່ຕິດຕໍ່ຄົນໜຶ່ງໄດ້. ຂໍ້ຄວາມຕິດຕາມແມ່ນຕົວແທນຂຽນເອງຈາກປະຫວັດການສົນທະນາ, ບໍ່ແມ່ນແມ່ແບບຕາຍຕົວທີ່ສົ່ງແບບຫວ່ານ.
