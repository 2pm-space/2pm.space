## ເຊື່ອມຕໍ່ກັບ ທຸກລະບົບທີ່ທ່ານໃຊ້ຢູ່

ຊ່ອງທາງສົ່ງຂໍ້ຄວາມ, HTTP API, ຖານຂໍ້ມູນ, MCP server ແລະ ໂຄດໃນ sandbox — ດ້ວຍການອະທິບາຍ ບໍ່ແມ່ນການຂຽນໂຄດ, ຕົວແທນຈຶ່ງເຂົ້າເຖິງລະບົບທີ່ມີຄຳຕອບໄດ້ ແທນທີ່ຈະຂໍໂທດວ່າບໍ່ຮູ້.

## ຫົກວິທີ ເຂົ້າເຖິງລະບົບອື່ນຂອງທ່ານ

ບໍ່ວ່າລະບົບຈະເປັນຫຍັງ, ມີວິທີໃດໜຶ່ງໃນນີ້ຮອງຮັບຢູ່ແລ້ວ.

### API ໃດກໍໄດ້ ດ້ວຍການອະທິບາຍ ບໍ່ແມ່ນການຂຽນໂຄດ

ໃຫ້ເຄື່ອງມືມີ URL, method, auth header ແລະ JSON Schema ສຳລັບພາຣາມິເຕີ, ແລ້ວໃຫ້ສິດແກ່ຕົວແທນທີ່ຕ້ອງເອີ້ນມັນ. ບໍ່ຕ້ອງ deploy ຫຍັງນອກຈາກ endpoint ທີ່ທ່ານມີຢູ່ແລ້ວ.

### ໂຄດ ເມື່ອການອະທິບາຍຍາກກວ່າ

Python ໃນ sandbox ທີ່ເອີ້ນໃຊ້ເປັນເຄື່ອງມືໄດ້: ອາກິວເມັນເຂົ້າມາທາງ ARGS ແລະ ຜົນລັບແມ່ນສິ່ງທີ່ມັນພິມອອກ. ສຳລັບການຈັດຮູບແບບ, ການແຍກຂໍ້ມູນ ແລະ ການຄິດໄລ່ທີ່ຂຽນໄວກວ່າອະທິບາຍໃຫ້ model.

### MCP, ທັງສອງທິດທາງ

ຊີ້ເຄື່ອງມືໄປຫາ MCP server ໃດກໍໄດ້, ຄົ້ນພົບເຄື່ອງມືຂອງມັນດ້ວຍການຄລິກດຽວ ແລ້ວເປີດ, ປິດ ຫຼື ໃຫ້ຕ້ອງອະນຸມັດແຕ່ລະອັນ — ແລະ ຄວບຄຸມ workspace ນີ້ຈາກ MCP client ພາຍນອກ, ລວມທັງ coding agent ທີ່ສ້າງຕົວແທນໃຫ້ທ່ານ.

### ຕົວແທນເປັນເຄື່ອງມື

ເປີດຕົວແທນໜຶ່ງໃຫ້ອີກຕົວແທນໃຊ້. ຕົວແທນຫົວໜ້າມອບວຽກໃຫ້ຕົວແທນຊ່ຽວຊານ ແລະ ໄດ້ຄຳຕອບທີ່ມີໂຄງສ້າງກັບມາ, ແທນທີ່ຈະມີສຳເນົາຂອງຕົວແທນຊ່ຽວຊານຢູ່ໃນພຣອມຂອງມັນເອງ.

### ຊ່ອງທາງ ເປັນການເຊື່ອມຕໍ່

Messenger, Zalo ສ່ວນຕົວ, Telegram, Pancake ແລະ ວິດເຈັດເວັບໄຊ ເຊື່ອມຕໍ່ເປັນຊ່ອງທາງຫຼັກ. ສິ່ງອື່ນໆເຂົ້າມາຜ່ານຊ່ອງທາງ API ກຳນົດເອງ — webhook ເຂົ້າ, webhook ອອກ.

### ເຫດການ ສົ່ງມາຫາທ່ານ

ເຫດການໃນກ່ອງຂໍ້ຄວາມສົ່ງໄປຫາ endpoint ຂອງທ່ານ, ຂໍ້ຄວາມໃໝ່ຈຶ່ງກະຕຸ້ນບາງຢ່າງໃນລະບົບຂອງທ່ານໄດ້. ການສົ່ງຖືກບັນທຶກ, ຜູ້ຮັບທີ່ລົ້ມຢູ່ຈຶ່ງເຫັນໄດ້ ແທນທີ່ຈະຫາຍໄປ.

- ການອະນຸມັດໂດຍຄົນ ແລະ ການແຄຊຜົນລັບ ສຳລັບແຕ່ລະເຄື່ອງມື
- MCP server — ຄົ້ນພົບເຄື່ອງມື, ເປີດ ຫຼື ປິດແຕ່ລະອັນ

## ຄຳຖາມກ່ຽວກັບການເຊື່ອມຕໍ່

ສິ່ງທີ່ວິສະວະກອນຖາມ ກ່ອນເຊື່ອມມັນເຂົ້າກັບລະບົບພາຍໃນ.

### ຈະເຊື່ອມຕໍ່ບໍລິການທີ່ບໍ່ມີໃນລາຍການແນວໃດ?

ດ້ວຍເຄື່ອງມື webhook. ທ່ານໃສ່ URL, method, auth header ແລະ JSON Schema ສຳລັບພາຣາມິເຕີ, ແລ້ວໃຫ້ສິດແກ່ຕົວແທນທີ່ຈະໃຊ້ — ຫຼື ຕັ້ງເປັນທົ່ວໄປໃຫ້ທຸກຕົວແທນ. ບໍ່ຕ້ອງ deploy ໂຄດໃດໆຢູ່ຝັ່ງພວກເຮົາ ແລະ ຝັ່ງທ່ານກໍບໍ່ຕ້ອງການຫຍັງນອກຈາກ endpoint ທີ່ມີຢູ່ແລ້ວ.

### ຕົວແທນລັນໂຄດໄດ້ບໍ່?

ໄດ້ — Python ໃນ sandbox ເປັນເຄື່ອງມືທີ່ຕົວແທນເອີ້ນໃຊ້ໄດ້. ເໝາະກັບການແປງຂໍ້ມູນທີ່ຂຽນງ່າຍກວ່າອະທິບາຍ: ຈັດຮູບແບບ payload ໃໝ່, ຄິດໄລ່ທີ່ບໍ່ຄວນໄວ້ໃຈ model, ແຍກຂໍ້ມູນທີ່ຍຸ່ງຍາກ. ການເຂົ້າອິນເຕີເນັດປິດຢູ່ ຈົນກວ່າທ່ານຈະເປີດ.

### ຮອງຮັບ MCP ບໍ່?

ທັງສອງທິດທາງ. ເຄື່ອງມື MCP ຊີ້ໄປຫາ server ໃດກໍໄດ້: ຄົ້ນພົບເຄື່ອງມືຂອງມັນດ້ວຍການຄລິກດຽວ, ແລ້ວເລືອກອັນທີ່ຕົວແທນໃຊ້ໄດ້ ແລະ ອັນທີ່ຕ້ອງອະນຸມັດ. ແພລດຟອມຍັງເປີດ MCP server ຂອງຕົນເອງ ເພື່ອໃຫ້ client ພາຍນອກ — ລວມທັງ coding agent — ຄວບຄຸມ workspace ຂອງທ່ານ: ສ້າງຕົວແທນ, ແກ້ໄຂເອກະສານ, ສອບຖາມບອດ, ຈັດການທັກສະ ແລະ ເຄື່ອງມື.

### ຕົວແທນໜຶ່ງເອີ້ນອີກຕົວແທນໄດ້ບໍ່?

ໄດ້. ຕົວແທນສາມາດເປີດເປັນເຄື່ອງມື, ຕົວແທນຫົວໜ້າຈຶ່ງມອບວຽກໃຫ້ຕົວແທນຊ່ຽວຊານ ແລະ ໄດ້ຄຳຕອບທີ່ມີໂຄງສ້າງກັບມາ ແທນທີ່ຈະສ້າງສິ່ງທີ່ຕົວແທນຊ່ຽວຊານເຮັດຢູ່ແລ້ວຂຶ້ນມາໃໝ່.

### Webhook ໃນທິດທາງກັບກັນເຮັດວຽກແນວໃດ?

ເຫດການໃນກ່ອງຂໍ້ຄວາມສາມາດສົ່ງໄປຫາ endpoint ຂອງທ່ານ, ຂໍ້ຄວາມໃໝ່ ຫຼື ການສົນທະນາທີ່ແກ້ໄຂແລ້ວ ຈຶ່ງກະຕຸ້ນບາງຢ່າງໃນລະບົບຂອງທ່ານເອງໄດ້. ການສົ່ງຖືກບັນທຶກ, ຜູ້ຮັບທີ່ລົ້ມຢູ່ຈຶ່ງເຫັນໄດ້ ແທນທີ່ຈະເປັນຂໍ້ຄວາມທີ່ທ່ານບໍ່ເຄີຍຮູ້.

### ມີ API ບໍ່?

ມີ. API key ອອກໃຫ້ຕໍ່ພື້ນທີ່ເຮັດວຽກ ແລະ ມີສິດຂອງສະມາຊິກທີ່ສ້າງມັນ, key ຈຶ່ງເຮັດໄດ້ບໍ່ເກີນຄົນທີ່ຢູ່ເບື້ອງຫຼັງ. key ດຽວກັນນີ້ຢືນຢັນຕົວຕົນກັບ MCP endpoint.

## ເຊື່ອມມັນເຂົ້າກັບ ລະບົບທີ່ມີຄຳຕອບ
