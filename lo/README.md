ລູກຄ້າທັກມາທາງຊ່ອງທາງໃດກໍໄດ້. 2pm AI ໃຫ້ຄຳປຶກສາດ້ວຍຄວາມຮູ້, ທັກສະ, ເຄື່ອງມື ແລະ ໜ່ວຍຄວາມຈຳຂອງທ່ານ, ຮັບຄຳສັ່ງຊື້, ຈອງການຈັດສົ່ງແບບ COD ແລະ ກ່າວຂອບໃຈ — ແລະ ເມື່ອການສົນທະນາປ່ຽນທິດ, ມັນຮູ້ວ່າຄວນໄປທາງໃດ.

**ລູກຄ້າແຊັດມາ**

- **Messenger:** *ອັນສີຟ້າຍັງມີຂອງບໍ່?*
- **Telegram:** *ສົ່ງໄປດ່ານັງໄດ້ບໍ່?*
- **ວິດເຈັດເວັບໄຊ:** *ເອົາສອງອັນນີ້ ລາຄາເທົ່າໃດ?*
- **Zalo ສ່ວນຕົວ:** *ຈ່າຍເງິນປາຍທາງໄດ້ບໍ່?*

### 2pm AI ໃຫ້ຄຳປຶກສາ

ຕົວແທນດຽວຢູ່ເບື້ອງຫຼັງທຸກຊ່ອງທາງ, ອີງໃສ່ທຸກສິ່ງທີ່ພື້ນທີ່ເຮັດວຽກຂອງທ່ານຮູ້.

- **ຄວາມຮູ້** — ຕອບຈາກເອກະສານ ແລະ ແຄັດຕາລັອກຂອງທ່ານ, ລວມທັງຮູບສິນຄ້າ
- **ທັກສະ** — ຄູ່ມືການຂາຍຂອງທ່ານ — ຖາມຫຍັງ, ສະເໜີຫຍັງ, ເວົ້າແບບໃດ
- **ເຄື່ອງມື** — ຊອກຫາສິນຄ້າ, ຄຳສັ່ງຊື້ເກົ່າ ແລະ ຄ່າສົ່ງ ໃນລະຫວ່າງການສົນທະນາ
- **ໜ່ວຍຄວາມຈຳ** — ຈື່ສິ່ງທີ່ລູກຄ້າເຄີຍບອກໄວ້ໃນຄັ້ງກ່ອນ
- **Customer 360** — ທຸກຊ່ອງທາງທີ່ລູກຄ້າເຄີຍໃຊ້ ລວມເປັນປະຫວັດດຽວ
- **ຮາວກັນ** — ຮັກສາທຸກຄຳຕອບໃຫ້ຢູ່ໃນຂອບເຂດທີ່ມັນເວົ້າ ແລະ ເຮັດໄດ້

1. **ດຳເນີນການ** — ຢືນຢັນລາຍການສິນຄ້າ, ເບີໂທ ແລະ ທີ່ຢູ່ຈັດສົ່ງ ກັບລູກຄ້າອີກຄັ້ງ. `ບັນທຶກທີ່ຢູ່ແລ້ວ`
2. **ສ້າງຄຳສັ່ງຊື້** — ຄຳສັ່ງຂາຍທີ່ຄິດລາຄາຈາກແຄັດຕາລັອກຂອງທ່ານ — ເປັນຮ່າງໃຫ້ທີມຢືນຢັນ ຫຼື ສົ່ງອະນຸມັດໂດຍກົງ. `SO-2026-48213`
3. **ຈອງການສົ່ງແບບ COD** — ຈອງກັບ Viettel Post ພ້ອມຍອດເງິນທີ່ຕ້ອງເກັບປາຍທາງ, ຫຼື ເກັບໄວ້ໃນໃບສົ່ງສິນຄ້າສຳລັບບໍລິສັດຂົນສົ່ງຂອງທ່ານເອງ. `COD · ລະຫັດຕິດຕາມ`
4. **ກ່າວຂອບໃຈ** — ເມື່ອມີການລາຍງານວ່າສົ່ງຮອດແລ້ວ, ກົດເຫດການຈະສົ່ງຄຳຂອບໃຈ — ຂຽນຈາກການສົນທະນາ ຫຼື ຈາກແມ່ແບບຂອງທ່ານ. `ສົ່ງຮອດ → ຂອບໃຈແລ້ວ`

**ລະຫວ່າງທາງ**

- **ຖ້າລູກຄ້າໃຫ້ເບີໂທ → ເພີ່ມເປັນໝູ່ໃນ Zalo.** ເບີໂທຖືກປັກໝຸດໄວ້ກັບຜູ້ຕິດຕໍ່ ແລະ Zalo ສ່ວນຕົວຂອງທ່ານຈະສົ່ງຄຳຂໍເປັນໝູ່ — ແບບເວັ້ນຈັງຫວະ, ລະຫວ່າງ 8 ໂມງເຊົ້າ ຫາ 8 ໂມງແລງ. ເມື່ອລູກຄ້າຍອມຮັບ, ແຊັດ Zalo ຈະລວມເຂົ້າກັບລູກຄ້າຄົນດຽວກັນ. `+84 ••• 412 → Zalo`
- **ຖ້າລູກຄ້າມິດງຽບ → Care ຕິດຕາມຕໍ່.** Care agent ອ່ານການສົນທະນາ ແລະ ຕິດຕາມຕໍ່ຫຼັງຈາກລູກຄ້າງຽບໄປຕາມເວລາທີ່ທ່ານກຳນົດ — ຕາມຊົ່ວໂມງງຽບທີ່ທ່ານຕັ້ງ, ຈຳກັດຈຳນວນຕໍ່ຄົນ ແລະ ຢູ່ພາຍໃນກອບເວລາສົ່ງຂໍ້ຄວາມຂອງຊ່ອງທາງ. `ງຽບ 2h → ຕິດຕາມຕໍ່`
- **ຖ້າລູກຄ້າຂໍລົມກັບຄົນ → ທີມຂອງທ່ານເຂົ້າຊ່ວຍ.** Agent ສົ່ງການແຈ້ງເຕືອນແບບ push ທີ່ເປີດການສົນທະນາໃຫ້ທີມຂອງທ່ານ. ໃຜກໍຕອບຢູ່ນັ້ນໄດ້ — ຫຼື ຢຸດ AI ເພື່ອຮັບການສົນທະນາໄວ້ເອງ. `ແຈ້ງເຕືອນ → ຢຸດ AI`
- **ຖ້າລູກຄ້າສະແປມ ຫຼື ໃຊ້ຄຳຫຍາບ → ຕົວແທນຢຸດຕອບ.** ມັນຈະປິດ AI ແລະ Care ສຳລັບການສົນທະນານັ້ນ ແລະ ຝາກເຫດຜົນສັ້ນໆໜຶ່ງແຖວໄວ້ໃຫ້ທີມ. ໃຜກໍເປີດຄືນໄດ້ຈາກກ່ອງຂໍ້ຄວາມ. `ປິດ AI · ບັນທຶກເຫດຜົນແລ້ວ`

## ເບິ່ງມັນເຮັດວຽກ

ແຕ້ມຈາກ design token ດຽວກັນກັບຜະລິດຕະພັນ, ນີ້ຈຶ່ງເປັນໜ້າຈໍຕາມທີ່ມັນສະແດງໃນໂໝດສີຂອງທ່ານ — ບໍ່ແມ່ນພາບໜ້າຈໍຈາກພື້ນທີ່ເຮັດວຽກຂອງຄົນອື່ນ.

### ຕົວສ້າງຕົວແທນ

**ປະກອບຕົວແທນເທິງແຄນວາດ**

ວາງທັກສະທີ່ມັນຄວນຮູ້, ເຄື່ອງມືທີ່ມັນເອີ້ນໃຊ້ໄດ້ ແລະ ຮາວກັນທີ່ມັນຕ້ອງຢູ່ພາຍໃນ, ແລ້ວເບິ່ງມັນຄິດແກ້ວຽກທີລະໂໜດ.

- ຕົວແທນແບບງ່າຍ ເອີ້ນຄັ້ງດຽວ, ຫຼື ກຣາຟ workflow ເຕັມຮູບແບບ
- ທັກສະ ແລະ ເຄື່ອງມື ໃຊ້ຮ່ວມກັນທຸກຕົວແທນໃນພື້ນທີ່ເຮັດວຽກ
- ແຄນວາດມີເວີຊັນ — ກູ້ຄືນຮູບແບບກຣາຟກ່ອນໜ້າໄດ້ທຸກເມື່ອ

## ຕົວສ້າງຕົວແທນ ທີ່ຢູ່ເບື້ອງຫຼັງທັງໝົດ

ທຸກຢ່າງຂ້າງເທິງເຮັດວຽກເທິງຕົວສ້າງດຽວກັນ — ທັກສະທີ່ທ່ານຂຽນຄັ້ງດຽວ ຈຶ່ງໃຊ້ໄດ້ທຸກບ່ອນທີ່ທ່ານວາງຕົວແທນ.

### ຕົວແທນ AI

ສ້າງ ແລະ ປັບແຕ່ງຕົວແທນອັດສະລິຍະໃຫ້ເໝາະກັບການໃຊ້ງານຂອງທ່ານ. ກຳນົດບຸກຄະລິກ, ຄຳສັ່ງ ແລະ ພຶດຕິກຳ ດ້ວຍຕົວສ້າງແບບພາບ — ແລ້ວເກັບເວີຊັນຂອງແຄນວາດ ເພື່ອໃຫ້ການປ່ຽນແປງທີ່ທ່ານເສຍໃຈ ກູ້ຄືນໄດ້ໃນຄລິກດຽວ.

### ທັກສະກຳນົດເອງ

ສອນທັກສະ ແລະ workflow ສະເພາະຂົງເຂດໃຫ້ຕົວແທນ. ທັກສະໃສ່ເຂົ້າທຸກພຣອມໄດ້, ຫຼື ສະເພາະເມື່ອຄຳຖາມກົງກັນ — ຄັງພຶດຕິກຳຂະໜາດໃຫຍ່ຈຶ່ງບໍ່ກິນໂທເຄັນໃນທຸກການເອີ້ນ.

### ການເຊື່ອມຕໍ່ເຄື່ອງມື

ເຊື່ອມຕົວແທນກັບ API, ຖານຂໍ້ມູນ ແລະ ບໍລິການພາຍນອກ. ເຄື່ອງມື webhook, ຟັງຊັນ Python ໃນ sandbox, ການເຊື່ອມຕໍ່ມີໃນຕົວ, MCP server, ຫຼື ຕົວແທນອື່ນທີ່ເປີດໃຫ້ໃຊ້ເປັນເຄື່ອງມື.

### ຮາວກັນ

ຕັ້ງຂໍ້ຈຳກັດດ້ານຄວາມປອດໄພ ແລະ ນະໂຍບາຍເນື້ອຫາ ສຳລັບສິ່ງທີ່ເຂົ້າ ແລະ ອອກຈາກຕົວແທນ — ພ້ອມບັນທຶກກວດສອບວ່າຮາວກັນໃດເຮັດວຽກ, ມັນເຮັດຫຍັງ ແລະ ເປັນຫຍັງ.

### Collaborative Drive

ເອກະສານ, ແຜນຜັງຄວາມຄິດ ແລະ ຕາຕະລາງ ທີ່ເຮັດວຽກຮ່ວມກັນແບບເວລາຈິງ. ຖານຄວາມຮູ້ຮ່ວມຂອງທີມທ່ານ, ແລະ ເປັນອັນດຽວກັນທີ່ຕົວແທນຂອງທ່ານດຶງຂໍ້ມູນ.

### ນຳໃຊ້ໃນຄລິກດຽວ

ວາງຕົວແທນໄວ້ທີ່ຊ່ອງທາງ, ຕາຕະລາງເວລາ ຫຼື API endpoint. ຕິດຕາມປະສິດທິພາບ, ຕິດຕາມຄ່າໃຊ້ຈ່າຍຕໍ່ຮອບ, ແລະ ປັບປຸງໂດຍມີບັນທຶກຢູ່ຕໍ່ໜ້າ.

## ວິທີເຮັດວຽກ

ຈາກໄອເດຍ ສູ່ການໃຊ້ງານຈິງ ໃນສາມຂັ້ນຕອນ. ບໍ່ຕ້ອງຕັ້ງຄ່າຊັບຊ້ອນ, ບໍ່ຕ້ອງປວດຫົວກັບໂຄງສ້າງພື້ນຖານ.

1. **ສ້າງຕົວແທນຂອງທ່ານ** — ກຳນົດບຸກຄະລິກ, ຄຳສັ່ງ ແລະ ພຶດຕິກຳຂອງຕົວແທນ. ເລີ່ມຈາກແມ່ແບບໃນຕະຫຼາດ ຫຼື ຈາກແຄນວາດເປົ່າໃນຕົວສ້າງແບບພາບ.
2. **ໃຫ້ທັກສະ, ເຄື່ອງມື ແລະ ຄວາມຮູ້** — ເພີ່ມທັກສະ, ເຊື່ອມເຄື່ອງມື, ຊີ້ໄປຫາເອກະສານ ແລະ ຖານຂໍ້ມູນທີ່ມັນຕ້ອງການ, ແລະ ຕັ້ງຮາວກັນທີ່ມັນຕ້ອງຢູ່ພາຍໃນ.
3. **ໃຫ້ມັນເຮັດວຽກ** — ສົ່ງມັນໄປທີ່ຊ່ອງທາງ, ຕາຕະລາງເວລາ ຫຼື API. ເບິ່ງທຸກຮອບພ້ອມການເອີ້ນໃຊ້ເຄື່ອງມື ແລະ ຄ່າໃຊ້ຈ່າຍ, ແລ້ວປັບປຸງຈາກສິ່ງທີ່ເກີດຂຶ້ນແທ້.

## ສ້າງເທິງເຄື່ອງຈັກທີ່ມີພະລັງ

ເບື້ອງຫຼັງ, 2pm.space ເປັນຫຼາຍກວ່າໜ້າຈໍແຊັດ. ທຸກຄວາມສາມາດເປັນເຄື່ອງຈັກລະດັບໃຊ້ງານຈິງ ທີ່ອອກແບບມາໃຫ້ຕົວແທນຂອງທ່ານສະຫຼາດກວ່າ, ໄວກວ່າ ແລະ ປອດໄພກວ່າ.

### ແນວຄິດຕົວແທນ

**ຕົວແທນທີ່ຄິດ, ລົງມື ແລະ ປັບປຸງຊ້ຳ**

ທຸກຕົວແທນໃນ 2pm.space ສ້າງເທິງວົງຈອນ ReAct — ຄິດ, ລົງມື, ສັງເກດ, ເຮັດຊ້ຳ. ຕົວແທນບໍ່ພຽງແຕ່ຕອບ; ມັນວາງແຜນ, ເອີ້ນໃຊ້ເຄື່ອງມື, ປະເມີນຜົນ ແລະ ປັບຕົວຈົນກວ່າວຽກຈະສຳເລັດ.

- ໂໝດງ່າຍ: ເອີ້ນ LLM ຄັ້ງດຽວ ສຳລັບຄຳຕອບທີ່ໄວ ແລະ ກົງ
- ໂໝດ Agentic: ກຣາຟ workflow ຫຼາຍໂໜດ ພ້ອມການແຍກທາງຕາມເງື່ອນໄຂ ແລະ ການເຮັດວຽກຂະໜານ
- ແຕ່ລະໂໜດຮອງຮັບການເອີ້ນໃຊ້ເຄື່ອງມືສູງສຸດ 10 ຮອບ ໂດຍຄ່າເລີ່ມຕົ້ນ
- ເສັ້ນຍ້ອນກັບ (ວົງຈອນ) ໃຫ້ຕົວແທນກັບໄປທວນຂັ້ນຕອນໄດ້ ໂດຍບໍ່ວົນບໍ່ສິ້ນສຸດ

### ໜ່ວຍຄວາມຈຳ ແລະ ບໍລິບົດ

**ໜ່ວຍຄວາມຈຳທີ່ສະຫຼາດຂຶ້ນ ທຸກການສົນທະນາ**

ຕົວແທນໃນ 2pm.space ຈື່ໄດ້. ລະບົບໜ່ວຍຄວາມຈຳສາມຊັ້ນ — ໜ່ວຍຄວາມຈຳສ່ວນກາງຂອງອົງກອນ, ບໍລິບົດຮ່ວມຕໍ່ຕົວແທນ, ແລະ ບັນທຶກຕໍ່ຜູ້ໃຊ້ — ເຮັດໃຫ້ທຸກການໂຕ້ຕອບອີງໃສ່ສິ່ງທີ່ເກີດຂຶ້ນກ່ອນໜ້າ.

- ສະກັດໜ່ວຍຄວາມຈຳອັດຕະໂນມັດຈາກທຸກການສົນທະນາ ຢູ່ເບື້ອງຫຼັງ
- ດຶງຂໍ້ມູນເຊິງຄວາມໝາຍ ພ້ອມຄະແນນທີ່ຫຼຸດລົງຕາມເວລາ — ຄວາມຈຳທີ່ໃໝ່ ແລະ ກ່ຽວຂ້ອງຂຶ້ນມາກ່ອນ
- ໜ່ວຍຄວາມຈຳຫົກປະເພດ: ຂໍ້ເທັດຈິງ, ຄວາມມັກ, ຄຳສັ່ງ, ຄຳຕິຊົມ, ເຫດການ, ຂັ້ນຕອນ
- ລຶບລາຍການຊ້ຳສາມລະດັບ: ພຣອມ LLM, ຄວາມຄ້າຍຄືກັນຂອງ vector, ແລະ ການລວມຂໍ້ມູນເປັນໄລຍະ

### ເຄື່ອງມື

**ເຊື່ອມຕົວແທນກັບທຸກສິ່ງ**

ຕົວແທນເອີ້ນໃຊ້ເຄື່ອງມືທີ່ທ່ານໃຫ້ — ເຄື່ອງມືມີໃນຕົວຂອງແພລດຟອມ, webhook ພາຍນອກ, ຟັງຊັນ Python ໃນ sandbox, ຫຼື ເຄື່ອງມືຂອງ MCP server. ວົງ ReAct ຈັດການຂໍ້ຜິດພາດຢ່າງລຽບງ່າຍ ແລະ ລອງໃໝ່ຢ່າງສະຫຼາດ ໂດຍບໍ່ຕ້ອງແຊກແຊງດ້ວຍມື.

- ເຄື່ອງມືໃນຕົວ: ຄົ້ນຫາເວັບ, ສ້າງຮູບ, ລັນໂຄດ ແລະ ອື່ນໆ
- ເຄື່ອງມື webhook: POST/GET/PUT/PATCH ໄປຫາ API ໃດກໍໄດ້ ດ້ວຍ bearer ຫຼື API key
- ໂຄດ: ຟັງຊັນ Python ໃນ sandbox ເປັນເຄື່ອງມື, ແລະ Python ຫຼື Bash ໃນໂໜດໂຄດຂອງ workflow
- ຮອງຮັບ MCP: ເຊື່ອມຕໍ່ MCP server ໃດກໍໄດ້, ຄົ້ນພົບເຄື່ອງມື ແລະ ເປີດ ຫຼື ປິດແຕ່ລະອັນ

### ເອກະສານ ແລະ RAG

**ຖານຄວາມຮູ້ຂອງທ່ານ ຢູ່ໃກ້ມືສະເໝີ**

ອັບໂຫລດເອກະສານ, ແຜນຜັງຄວາມຄິດ, ສະເປຣດຊີດ ແລະ ຕາຕະລາງ ໃສ່ Collaborative Drive. ຕົວແທນດຶງສ່ວນທີ່ກ່ຽວຂ້ອງທີ່ສຸດຕາມຕ້ອງການ ດ້ວຍການຄົ້ນຫາແບບປະສົມ — ລວມ dense vector ກັບການຄົ້ນຫາຄຳສຳຄັນ BM25.

- ຄົ້ນຫາແບບປະສົມເປັນຄ່າເລີ່ມຕົ້ນ: 70% vector + 30% ຄຳສຳຄັນ ຜ່ານການລວມ RRF
- ແບ່ງສ່ວນຕາມຄວາມໝາຍ ພ້ອມ embedding ແບບມີບໍລິບົດ ເພື່ອການດຶງຂໍ້ມູນທີ່ແມ່ນຍຳກວ່າ
- RAG ສອງໂໝດ: “tool” (ຕົວແທນເອີ້ນເອງ) ຫຼື “auto” (ໃສ່ເຂົ້າຕະຫຼອດ)
- ດຶງຂໍ້ມູນເປັນຂັ້ນ: ສະຫຼຸບສ່ວນກ່ອນ, ເນື້ອຫາເຕັມເມື່ອຕ້ອງການ — ປະຢັດໂທເຄັນ

### ທັກສະ

**ຄຳສັ່ງທີ່ໃຊ້ຄືນໄດ້ ທີ່ຕົວແທນຂອງທ່ານຊຳນານ**

ທັກສະແມ່ນແມ່ແບບພຣອມ ທີ່ໃສ່ເຂົ້າໃນ system prompt ຂອງຕົວແທນ — ບໍ່ວ່າຈະຕະຫຼອດ, ຫຼື ອັດຕະໂນມັດເມື່ອຄຳຖາມຂອງຜູ້ໃຊ້ກົງກັນ. ກຳນົດຄັ້ງດຽວ, ໃຊ້ຄືນໄດ້ທຸກຕົວແທນໃນພື້ນທີ່ເຮັດວຽກຂອງທ່ານ.

- ໂໝດ “Always”: ໃສ່ເຂົ້າທຸກ system prompt ເພື່ອຮັບປະກັນພຶດຕິກຳ
- ໂໝດ “Auto”: ໃສ່ເຂົ້າສະເພາະເມື່ອຄຳຖາມກົງກັນຜ່ານການຄົ້ນຫາທັງຂໍ້ຄວາມ — ປະຢັດໂທເຄັນ
- ທັກສະສ່ວນກາງໃຊ້ກັບທຸກຕົວແທນ; ທັກສະສະເພາະຕົວແທນຢູ່ໃນຂອບເຂດຂອງມັນ
- ທັກສະລະບົບໃຊ້ທົ່ວແພລດຟອມ, ຂ້າມຂໍ້ຈຳກັດຂອງອົງກອນ

### ການຕິດຕາມ

**ເຫັນທຸກຢ່າງ ໃນທຸກຮອບການເຮັດວຽກຂອງຕົວແທນ**

ທຸກການເຮັດວຽກຖືກຕິດຕາມຕັ້ງແຕ່ຕົ້ນຈົນຈົບ — ການໃຊ້ໂທເຄັນຕໍ່ໂໜດ, ຄ່າໃຊ້ຈ່າຍ, ເວລາຕອບສະໜອງ, ການເອີ້ນໃຊ້ເຄື່ອງມື ແລະ ຜົນຂອງຮາວກັນ. ແກ້ບັນຫາທຸກຄວາມລົ້ມເຫຼວ, ເພີ່ມປະສິດທິພາບຄ່າໃຊ້ຈ່າຍ, ແລະ ເຂົ້າໃຈແທ້ວ່າຕົວແທນຂອງທ່ານກຳລັງເຮັດຫຍັງ.

- ຕິດຕາມລາຍໂໜດ: ໂທເຄັນຂາເຂົ້າ, ໂທເຄັນຂາອອກ ແລະ ຄ່າໃຊ້ຈ່າຍຕໍ່ຂັ້ນຕອນ
- ບັນທຶກການເຮັດວຽກ ພ້ອມປະຫວັດຂໍ້ຄວາມເຕັມ ແລະ ຜົນຂອງການເອີ້ນໃຊ້ເຄື່ອງມື
- ກວດສອບຮາວກັນ: ເບິ່ງວ່າຮາວກັນໃດເຮັດວຽກ, ມີການດຳເນີນການຫຍັງ ແລະ ເປັນຫຍັງ
- ບັນທຶກການສະກັດໜ່ວຍຄວາມຈຳ: ຕິດຕາມວ່າໄດ້ຮຽນຮູ້ຫຍັງຈາກແຕ່ລະການສົນທະນາ

ພື້ນທີ່ເຮັດວຽກທີ່ທ່ານສ້າງຕົວແທນ AI ແລ້ວນຳໄປເຮັດວຽກແທ້ — ຕອບລູກຄ້າທາງ Messenger, Zalo, Telegram ແລະ ແຊັດເວັບໄຊ, ຕອບຄຳຖາມກ່ຽວກັບຖານຂໍ້ມູນຂອງທ່ານດ້ວຍພາສາທຳມະດາ, ແລະ ດຳເນີນປະຕິທິນເນື້ອຫາຂອງທ່ານ — ທັງໝົດຢູ່ເທິງໄດຣຟ໌ຮ່ວມຂອງເອກະສານ, ແຜນຜັງຄວາມຄິດ ແລະ ຕາຕະລາງແບບສົດ.

### ຂ້ອຍສ້າງຕົວແທນ AI ປະເພດໃດໄດ້ແດ່?

ທຸກຢ່າງ ຕັ້ງແຕ່ຜູ້ຊ່ວຍທີ່ເອີ້ນຄັ້ງດຽວ ຈົນເຖິງ workflow ຫຼາຍໂໜດ ພ້ອມການແຍກທາງຕາມເງື່ອນໄຂ, ສາຂາຂະໜານ ແລະ ວົງຈອນປະເມີນຜົນ. ຕົວແທນຊ່ວຍເຫຼືອ, ຜູ້ຊ່ວຍຄົ້ນຄວ້າ, ນັກຂຽນເນື້ອຫາ, ນັກວິເຄາະຂໍ້ມູນ ແລະ ລະບົບອັດຕະໂນມັດພາຍໃນ ແມ່ນຮູບແບບທີ່ພົບເລື້ອຍ, ແລະ ແຕ່ລະອັນປະກອບຈາກທັກສະ, ເຄື່ອງມື, ຄວາມຮູ້ ແລະ ຮາວກັນຊຸດດຽວກັນ.

### ຕ້ອງມີປະສົບການຂຽນໂຄດ ຈຶ່ງຈະສ້າງຕົວແທນໄດ້ບໍ່?

ບໍ່ຕ້ອງ. ຕົວແທນສ້າງແບບພາບ — ບຸກຄະລິກ, ຄຳສັ່ງ, ທັກສະ, ເຄື່ອງມື ແລະ ຮາວກັນ ລ້ວນແຕ່ເປັນການຕັ້ງຄ່າ, ແລະ ມີຕະຫຼາດແມ່ແບບໃຫ້ເລີ່ມຕົ້ນ. ຖ້າທ່ານຂຽນໂຄດ, ເຄື່ອງມື Python ໃນ sandbox, API ແລະ MCP endpoint ກໍມີພ້ອມເມື່ອທ່ານຕ້ອງການ.

### ຕົວແທນຮຽນຮູ້ ແລະ ຈື່ບໍລິບົດແນວໃດ?

ສາມທາງ, ພ້ອມກັນ. ໜ່ວຍຄວາມຈຳຖືກສະກັດຈາກການສົນທະນາຢູ່ເບື້ອງຫຼັງ ແລະ ດຶງມາຕາມຄວາມໝາຍ, ຕົວແທນຈຶ່ງຈື່ສິ່ງທີ່ຖືກບອກໄວ້. ເອກະສານໃນໄດຣຟ໌ຖືກດຶງມາຕາມຕ້ອງການ ດ້ວຍການຄົ້ນຫາແບບປະສົມ vector ແລະ ຄຳສຳຄັນ. ແລະ ທັກສະ — ຄຳສັ່ງທີ່ໃຊ້ຄືນໄດ້ທີ່ທ່ານຂຽນຄັ້ງດຽວ — ຖືກໃສ່ເຂົ້າພຣອມ ບໍ່ວ່າຈະຕະຫຼອດ ຫຼື ສະເພາະເມື່ອຄຳຖາມກົງກັນ.

### ເຊື່ອມຕໍ່ກັບລະບົບທີ່ພວກເຮົາໃຊ້ຢູ່ໄດ້ບໍ່?

ໄດ້. ຊ່ອງທາງສົ່ງຂໍ້ຄວາມເຊື່ອມຕໍ່ເປັນຊ່ອງທາງຫຼັກ, HTTP API ເປັນເຄື່ອງມື webhook, ຫົກຖານຂໍ້ມູນ ແລະ ຄັງຂໍ້ມູນເປັນການເຊື່ອມຕໍ່ຂໍ້ມູນ, ແລະ MCP server ໃດກໍໄດ້ເປັນແຫຼ່ງເຄື່ອງມືທີ່ທ່ານຄົ້ນພົບ ແລ້ວເປີດໃຊ້. ສິ່ງອື່ນໆເຊື່ອມມາຫາພວກເຮົາຜ່ານ webhook ທຳມະດາ.

### ລາຄາເທົ່າໃດ?

ທຸກຄຸນສົມບັດຟຣີ, ບໍ່ມີແພັກເກັດແບບເສຍເງິນ ແລະ ບໍ່ຄິດຄ່າຕໍ່ຜູ້ໃຊ້. ທ່ານຈ່າຍສະເພາະການໃຊ້ AI — ໂທເຄັນຂອງໂມເດວຄິດຕາມອັດຕາຂອງຜູ້ໃຫ້ບໍລິການເອງ ໂດຍບໍ່ບວກເພີ່ມ, ແລະ ແພລດຟອມເກັບຄ່າທຳນຽມຄົງທີ່ຄັ້ງດຽວເມື່ອທ່ານເຕີມເຄຣດິດ. ບ່ອນເກັບຂໍ້ມູນທີ່ເກີນສ່ວນພື້ນຖານທີ່ລວມໃຫ້ ແມ່ນສິ່ງດຽວທີ່ຄິດຄ່າລາຍເດືອນ.

### ການເຮັດວຽກຮ່ວມກັນເປັນທີມເຮັດວຽກແນວໃດ?

ພື້ນທີ່ເຮັດວຽກມີສະມາຊິກ, ບົດບາດ ແລະ ທີມ, ພ້ອມສິດທີ່ກຳນົດຕໍ່ຊັບພະຍາກອນ ແລະ ຕໍ່ການກະທຳ. ນອກຈາກນັ້ນ, ຕົວແທນ, ເອກະສານ, ຊ່ອງທາງ ຫຼື ບອດແຕ່ລະອັນ ມີລາຍຊື່ສິດເຂົ້າເຖິງຂອງຕົນເອງ — ຜູ້ຮັບເໝົາຈຶ່ງໄດ້ສິດເພຈດຽວ ໂດຍບໍ່ໄດ້ທັງພື້ນທີ່ເຮັດວຽກ.

### ຂ້ອຍເບິ່ງໄດ້ບໍ່ວ່າຕົວແທນເຮັດຫຍັງແທ້?

ທຸກຮອບຖືກບັນທຶກຕັ້ງແຕ່ຕົ້ນຈົນຈົບ: ຂໍ້ຄວາມ, ການເອີ້ນໃຊ້ເຄື່ອງມືແຕ່ລະຄັ້ງ ແລະ ສິ່ງທີ່ມັນສົ່ງກັບມາ, ໂທເຄັນ ແລະ ຄ່າໃຊ້ຈ່າຍຕໍ່ຂັ້ນຕອນ, ແລະ ຮາວກັນໃດເຮັດວຽກ ແລະ ມັນເຮັດຫຍັງ. ການເຮັດວຽກຕາມກຳນົດເວລາ, ການສົ່ງ webhook ແລະ ການສົ່ງຂໍ້ຄວາມຕິດຕາມ ແຕ່ລະອັນມີບັນທຶກຂອງຕົນເອງຢູ່ຄຽງຂ້າງ.

## ພ້ອມສ້າງ ຕົວແທນທຳອິດຂອງທ່ານແລ້ວບໍ?

ທຸກຄຸນສົມບັດຟຣີ ແລະ ບໍ່ຕ້ອງໃຊ້ບັດເຄຣດິດເພື່ອລົງທະບຽນ. ທ່ານຈ່າຍສະເພາະ AI ທີ່ທ່ານໃຊ້ແທ້ເທົ່ານັ້ນ.
