## ຈາກໄອເດຍ ສູ່ຕົວແທນທີ່ໃຊ້ໄດ້ຈິງ ໃນສາມຂັ້ນຕອນ

ແຕ້ມມັນ, ໃຫ້ອຸປະກອນມັນ, ວາງມັນໄວ້ບ່ອນທີ່ວຽກຢູ່.

1. **ແຕ້ມວຽກ** — ເລືອກ Simple ສຳລັບພຣອມດຽວ, ຫຼື Agentic ເພື່ອວາງວຽກເປັນໂໜດເທິງແຄນວາດ — ການດຶງຂໍ້ມູນ, ການຄິດ, ການກວດສອບ, ການແຍກທາງ — ຕໍ່ສາຍຈາກຊ້າຍໄປຂວາ.
2. **ໃຫ້ສິ່ງທີ່ມັນຕ້ອງການ** — ແນບເຄື່ອງມື, ທັກສະ, ຄວາມຮູ້ ແລະ ໜ່ວຍຄວາມຈຳ ໃຫ້ຕົວແທນ ຫຼື ໃຫ້ໂໜດດຽວ, ແລະ ຕັ້ງຮາວກັນທີ່ທຸກຂໍ້ຄວາມຕ້ອງຜ່ານ.
3. **ນຳໄປໃຊ້ງານ** — ທົດສອບເທິງແຄນວາດ, ແລ້ວເຊື່ອມມັນກັບຊ່ອງທາງກ່ອງຂໍ້ຄວາມ, ຕາຕະລາງເວລາ, ຕົວແທນອື່ນເປັນເຄື່ອງມື, ຫຼື MCP client.

## ຫຼາຍກວ່າພຣອມທີ່ມີເຄື່ອງມື

ແຄນວາດສຳລັບວຽກທີ່ພຣອມດຽວເຮັດເອງບໍ່ໄດ້.

### ແບບງ່າຍ ຫຼື agentic

ຕົວແທນແບບງ່າຍແມ່ນການເອີ້ນໂມເດວຄັ້ງດຽວດ້ວຍ system prompt ຂອງທ່ານ — ເໝາະກັບຄຳຖາມ, ການແປພາສາ ແລະ ການສະຫຼຸບ. ຕົວແທນ agentic ເປັນກຣາຟຂອງໂໜດ, ສຳລັບວຽກທີ່ຕ້ອງຫຼາຍຂັ້ນຕອນ ແລະ ການຕັດສິນໃຈລະຫວ່າງທາງ.

### ສິບຫົກປະເພດຂັ້ນຕອນ

Agent, Crew, Run Agent, Code, Knowledge ແລະ Skill Retrieval, Drive Action, Condition, Parallel, Loop, Evaluation, Human Review, Message, Send — ແຕ່ລະອັນເປັນກາດທີ່ລາກໃສ່ແຄນວາດ ແລະ ຕໍ່ສາຍໄປຂັ້ນຕໍ່ໄປ.

### ກວດວຽກຂອງຕົນເອງ

ໂໜດ Evaluation ໃຫ້ຄະແນນຄຳຕອບດ້ວຍກົດ ຫຼື LLM judge ແລ້ວແຍກທາງ: Pass ໄປຕໍ່, Retry ສົ່ງກັບໄປໃຫ້ຕົວແທນລອງໃໝ່ ຈົນເຖິງຈຳນວນຄັ້ງທີ່ທ່ານກຳນົດ.

### ຄົນຢູ່ບ່ອນທີ່ສຳຄັນ

ໂໜດ Human Review ຢຸດການຮັນຈົນກວ່າຄົນຈະອະນຸມັດ ຫຼື ປະຕິເສດ, ແລະ ໂໜດ Message ຖາມລູກຄ້າຫາລາຍລະອຽດຜ່ານຟອມ ຫຼື ປຸ່ມກ່ອນ workflow ຈະໄປຕໍ່.

### ເຄື່ອງມື, ທັກສະ ແລະ ຄວາມຮູ້

ຫົກສິບເຄື່ອງມືມີໃນຕົວ, HTTP API ແລະ Python ຂອງທ່ານເອງ, MCP server, ແລະ ຕົວແທນອື່ນເປັນເຄື່ອງມື. ທັກສະໃສ່ເຂົ້າທຸກພຣອມ, ຫຼື ສະເພາະເມື່ອຄຳຖາມກົງກັນ — ຄັງໃຫຍ່ຈຶ່ງບໍ່ກິນໂທເຄັນທຸກຄັ້ງທີ່ເອີ້ນ.

### ທົດສອບ, ຕິດຕາມ, ຖອຍກັບໄດ້

ຮັນ workflow ຈາກແຄນວາດ ແລະ ອ່ານຜົນລັບ, ໂທເຄັນ ແລະ ຄ່າໃຊ້ຈ່າຍຂອງແຕ່ລະໂໜດ. ບັນທຶກເວີຊັນຂອງແຄນວາດ, ແລ້ວກູ້ຄືນອັນທີ່ໃຊ້ໄດ້ດີ ເມື່ອການປ່ຽນແປງບໍ່ຖືກໃຈ.

## ມີຫຍັງເທິງແຄນວາດ

ທຸກໂໜດ, ແຄັດຕາລັອກໂມເດວ, ແລະ ທຸກບ່ອນທີ່ຕົວແທນຮັນໄດ້.

### ການຄິດ ແລະ ການລົງມື

- Agent — ໂມເດວ, ພຣອມ ແລະ ເຄື່ອງມືຂອງຕົນເອງ, ໃນວົງຈອນຄິດ-ແລ້ວ-ລົງມື
- Crew — ທີມ CrewAI ຂອງຕົວແທນ ແລະ ວຽກ
- Run Agent — ເອີ້ນຕົວແທນທີ່ທ່ານສ້າງໄວ້ແລ້ວ
- Code — Python ຫຼື Bash ໃນ sandbox, ບໍ່ມີຄ່າໃຊ້ຈ່າຍ LLM

### ການຄວບຄຸມການໄຫຼ

- Start — ຈຸດທີ່ຂໍ້ຄວາມເຂົ້າມາ
- Condition — ແຍກທາງຕາມກົດ, ບໍ່ມີຄ່າໃຊ້ຈ່າຍ LLM
- Parallel — ທຸກສາຂາຂາອອກພ້ອມກັນ
- Loop ແລະ Exit Loop — ວົນຕາມລາຍການ ຫຼື N ຄັ້ງ

### ການກວດສອບ ແລະ ຄົນ

- Evaluation — ກົດ ຫຼື LLM judge, ແລ້ວ Pass ຫຼື Retry
- Human Review — ຢຸດລໍຖ້າອະນຸມັດ ຫຼື ປະຕິເສດ
- Message — ຂໍ້ຄວາມແຊັດ, ຟອມ ຫຼື ປຸ່ມ
- Send — ສົ່ງຂໍ້ຄວາມຫາລູກຄ້າແລ້ວໄປຕໍ່

### ຄວາມຮູ້ ແລະ ຂໍ້ມູນ

- Knowledge Retrieval — ຄົ້ນຫາເຊິງຄວາມໝາຍ, ຄຳສຳຄັນ ຫຼື ປະສົມ
- Skill Retrieval — ຈັບຄູ່ທັກສະໂດຍບໍ່ໃຊ້ຂັ້ນຕອນ LLM
- Drive Action — ສ້າງ, ອ່ານ ຫຼື ອັບເດດເອກະສານ, ຕາຕະລາງ, ແຜນຜັງຄວາມຄິດ ແລະ storyboard
- ໜ່ວຍຄວາມຈຳທີ່ຄົງຢູ່ຂ້າມການສົນທະນາ, ແລະ ໜ່ວຍຄວາມຈຳສ່ວນກາງທີ່ທຸກຕົວແທນໃຊ້ຮ່ວມກັນ

### ໂມເດວ

- Anthropic, OpenAI, Google ແລະ DeepSeek
- Alibaba Qwen, Z.AI GLM, xAI ແລະ MiniMax
- ໜຶ່ງໂມເດວຕໍ່ໂໜດ Agent, ບໍ່ແມ່ນໜຶ່ງອັນຕໍ່ workflow
- ຄິດເງິນຈາກເຄຣດິດພື້ນທີ່ເຮັດວຽກ — ບໍ່ຕ້ອງຈັດການ key ຂອງຜູ້ໃຫ້ບໍລິການເອງ

### ບ່ອນທີ່ມັນຮັນ

- ຊ່ອງທາງກ່ອງຂໍ້ຄວາມ: Messenger, Telegram, Zalo ສ່ວນຕົວ, ແຊັດເວັບໄຊ
- Scheduler, ຕາມຕາຕະລາງເວລາທີ່ເຮັດຊ້ຳ
- ຕົວແທນອື່ນ, ເປີດເປັນເຄື່ອງມື
- MCP client ເຊັ່ນ Claude Code ແລະ Cursor
- Playground, ກ່ອນລູກຄ້າຄົນໃດຈະເຫັນມັນ

### ຕ້ອງຂຽນໂຄດເພື່ອສ້າງຕົວແທນບໍ່?

ບໍ່ຕ້ອງ. ຕົວແທນແບບງ່າຍແມ່ນຟອມ: ໂມເດວ, ພຣອມ, ເຄື່ອງມື. ຕົວແທນ agentic ແຕ້ມເທິງແຄນວາດດ້ວຍການລາກໂໜດແລ້ວຕໍ່ສາຍ. ໂຄດເປັນທາງເລືອກ — ໂໜດ Code ຮັນ Python ຫຼື Bash ເມື່ອທ່ານຢາກໃຫ້ຂັ້ນຕອນເຮັດວຽກໂດຍບໍ່ໃຊ້ໂມເດວ.

### ຕົວແທນແບບງ່າຍ ແລະ ແບບ agentic ຕ່າງກັນແນວໃດ?

ຕົວແທນແບບງ່າຍເອີ້ນໂມເດວຄັ້ງດຽວດ້ວຍ system prompt ຂອງທ່ານ ພ້ອມເຄື່ອງມື ແລະ ຄວາມຮູ້ທີ່ແນບໄວ້. ຕົວແທນ agentic ຮັນເປັນກຣາຟ: ແຕ່ລະໂໜດເຮັດວຽກດຽວ — ດຶງຂໍ້ມູນ, ຄິດ, ກວດສອບ, ແຍກທາງ, ວົນ, ຖາມຄົນ — ແລະ ເສັ້ນຕໍ່ສາຍຕັດສິນວ່າຈະໄປຫຍັງຕໍ່.

### ຕົວແທນໃຊ້ໂມເດວໃດໄດ້ແດ່?

ແຄັດຕາລັອກລວມ Anthropic, OpenAI, Google, DeepSeek, Alibaba (Qwen), Z.AI (GLM), xAI ແລະ MiniMax, ແລະ ໃນແຄນວາດ agentic ແຕ່ລະໂໜດ Agent ເລືອກໂມເດວຂອງຕົນເອງ. ການໃຊ້ງານຄິດເງິນຈາກເຄຣດິດພື້ນທີ່ເຮັດວຽກ, ຈຶ່ງບໍ່ຕ້ອງຈັດການ key ຂອງຜູ້ໃຫ້ບໍລິການ.

### ຈະທົດສອບຕົວແທນກ່ອນລູກຄ້າເຫັນແນວໃດ?

ຮັນມັນຈາກແຄນວາດ ຫຼື Playground. ທຸກຮອບຖືກບັນທຶກພ້ອມ input, output, ໂທເຄັນ, ຄ່າໃຊ້ຈ່າຍ ແລະ ການເອີ້ນໃຊ້ເຄື່ອງມືຂອງແຕ່ລະຂັ້ນຕອນ, ທ່ານຈຶ່ງເຫັນວ່າຄຳຕອບຜິດຢູ່ໃສ ແລະ ແກ້ໄຂໂໜດນັ້ນແທນທີ່ຈະແກ້ພຣອມທັງໝົດ.

### ຫຼາຍຄົນແກ້ໄຂຕົວແທນອັນດຽວກັນໄດ້ບໍ່?

ໄດ້. ແຄນວາດຊິງຄ໌ແບບເວລາຈິງ ແລະ ສະແດງວ່າໃຜກຳລັງເຂົ້າຢູ່, ແລະ ເວີຊັນຂອງແຄນວາດໃຫ້ທ່ານບັນທຶກສະຖານະທີ່ໃຊ້ໄດ້ດີ ແລ້ວກູ້ຄືນມັນພາຍຫຼັງໄດ້.

### ຕົວແທນຮັນຢູ່ໃສໄດ້ແດ່ ເມື່ອສ້າງແລ້ວ?

ຢູ່ຊ່ອງທາງກ່ອງຂໍ້ຄວາມ — Messenger, Telegram, Zalo ສ່ວນຕົວ ຫຼື ແຊັດເວັບໄຊຂອງທ່ານ — ຕາມຕາຕະລາງເວລາ, ເປັນເຄື່ອງມືໃຫ້ຕົວແທນອື່ນເອີ້ນ, ຫຼື ຈາກ MCP client ເຊັ່ນ Claude Code ຫຼື Cursor.
