## ເຊື່ອມຕໍ່ໃນສາມຂັ້ນຕອນ

Key ໜຶ່ງ, ຕົວຢ່າງໜຶ່ງ, ຄຳຂໍໜຶ່ງ.

1. **ສ້າງ API key** — ໄປທີ່ Settings › API Keys & MCP, ສ້າງ key ແລ້ວເລືອກສິ່ງທີ່ມັນເຮັດໄດ້. Key ບໍ່ສາມາດມີສິດຫຼາຍກວ່າຄົນທີ່ສ້າງມັນ.
2. **ວາງຕົວຢ່າງໂຄດ** — ກັອບປີ້ block server ສຳລັບ Claude Code ຫຼື Cursor — endpoint ແລະ key ຂອງທ່ານໃນ header X-API-Key — ໃສ່ໄຟລ໌ config ຂອງ client.
3. **ຂໍໃຫ້ມັນເຮັດວຽກ** — ບອກ client ວ່າທ່ານຢາກໄດ້ຫຍັງ. ມັນລິດເຄື່ອງມືຂອງພື້ນທີ່ເຮັດວຽກ, ອ່ານ playbook ຂອງວຽກນັ້ນ, ແລ້ວເອີ້ນໃຊ້ພວກມັນທີລະຂັ້ນຕອນ.

## ຄຳຖາມກ່ຽວກັບ MCP

ສິ່ງທີ່ຄົນຖາມ ກ່ອນເຊື່ອມ client.

### client ໃດເຮັດວຽກໄດ້?

client ໃດກໍໄດ້ທີ່ຮອງຮັບ MCP server ທາງໄກຜ່ານ Streamable HTTP. ໜ້າຕັ້ງຄ່າໃຫ້ຕົວຢ່າງໂຄດພ້ອມໃຊ້ສຳລັບ Claude Code ແລະ Cursor.

### client ເຮັດຫຍັງໄດ້ໃນພື້ນທີ່ເຮັດວຽກຂອງຂ້ອຍ?

ຫຍັງກໍໄດ້ທີ່ key ອະນຸຍາດ: ສ້າງ ແລະ ທົດສອບຕົວແທນ; ແກ້ໄຂເອກະສານ, ຕາຕະລາງ, ແຜນຜັງຄວາມຄິດ ແລະ storyboard ໃນ Drive; ສືບຄົ້ນຖານຂໍ້ມູນທີ່ເຊື່ອມໄວ້; ຈັດການບອດ, ແບຣນ, ປະຕິທິນເນື້ອຫາ ແລະ ການຕັ້ງຄ່າຊ່ອງທາງ. ລາຍການເຄື່ອງມືທີ່ client ເຫັນ ຖືກກັ່ນຕອງຕາມສິດນັ້ນແລ້ວ.

### ໃຫ້ key ກັບ AI client ປອດໄພບໍ່?

Key ເຮັດວຽກແທນສະມາຊິກທີ່ສ້າງມັນ ແລະ ບໍ່ສາມາດມີສິດທີ່ຄົນນັ້ນບໍ່ມີ. ບໍ່ມີການຖາມອະນຸມັດຜ່ານ MCP, ສິດຂອງ key ຈຶ່ງເປັນປະຕູດ່ານ: ໃຫ້ສິດອ່ານຢ່າງດຽວແກ່ client ທີ່ຄວນອ່ານຢ່າງດຽວ, ແລະ ຕັ້ງວັນໝົດອາຍຸໃຫ້ key ທີ່ຄວນຢຸດເຮັດວຽກ.

### ມັນໃຊ້ເຄຣດິດຂອງຂ້ອຍບໍ່?

ເຄື່ອງມືສ່ວນຫຼາຍແມ່ນການອ່ານ ແລະ ຂຽນທຳມະດາ. ເຄື່ອງມືທີ່ສ້າງບາງຢ່າງ — ໂຄງຮ່າງປະຕິທິນ, ຮູບພາບ, ການຮັນທົດສອບຂອງຕົວແທນ — ໃຊ້ເຄຣດິດພື້ນທີ່ເຮັດວຽກ ຄືກັບໃນແອັບ.
