## ວາງຕົວແທນໄວ້ໃນຕາຕະລາງເວລາ

ເລືອກຕົວແທນ, ຕັ້ງເວລາ, ອ່ານຜົນລັບ.

1. **ເລືອກຕົວແທນ ແລະ ວຽກ** — ເລືອກຕົວແທນ ແລະ ຂຽນສິ່ງທີ່ຄວນຖາມມັນ, ໜຶ່ງຂໍ້ຄວາມຕໍ່ໜຶ່ງແຖວ — ແຕ່ລະແຖວຖືກສົ່ງ ແລະ ຕອບເປັນລາຍການຂອງຕົນເອງ.
2. **ຕັ້ງເວລາຮັນ** — ຄັ້ງດຽວ, ລາຍວັນ, ລາຍອາທິດຕາມມື້ທີ່ທ່ານຕິກ, ລາຍເດືອນຕາມວັນທີ່, ຫຼື ຄຳສັ່ງ cron — ຕາມເຂດເວລາທີ່ທ່ານເລືອກ.
3. **ອ່ານສິ່ງທີ່ມັນເຮັດ** — ທຸກຮອບຢູ່ໃນປະຫວັດຂອງວຽກ ພ້ອມແຕ່ລະຄຳຕອບ, ໂທເຄັນ ແລະ ຄ່າໃຊ້ຈ່າຍ. ຮັນມັນທັນທີ, ພັກ ຫຼື ຍົກເລີກໄດ້ຈາກລາຍການ.

## ຕາຕະລາງເວລາທີ່ຮູ້ວ່າກຳລັງລັນຕົວແທນ

ບໍ່ແມ່ນ cron job ທີ່ຍິງ webhook — ແຕ່ເປັນການຮັນທີ່ມີການສົນທະນາ, ເຄື່ອງມື ແລະ ບັນທຶກ.

### ຫ້າແບບຕາຕະລາງເວລາ

ຄັ້ງດຽວຕາມວັນທີ່, ລາຍວັນຕາມເວລາ, ລາຍອາທິດຕາມມື້ທີ່ເລືອກ, ລາຍເດືອນຕາມວັນທີ່ໃນເດືອນ, ຫຼື ຄຳສັ່ງ cron ໃດກໍໄດ້. ທຸກຕາຕະລາງເວລາຮັກສາເຂດເວລາທີ່ທ່ານຕັ້ງ, ບໍ່ແມ່ນຂອງ server.

### ຜົນລັບໄປຫາບ່ອນທີ່ຕ້ອງການ

ຕົວແທນຮັນພ້ອມເຄື່ອງມືຂອງມັນ, ລາຍງານຈຶ່ງອອກໄປໄດ້ໃນຮູບແບບທີ່ຂຽນ: ຂໍ້ຄວາມ Telegram ໄປຫາກຸ່ມຂາຍ, ອີເມວ, ການແຈ້ງເຕືອນຜູ້ດຳເນີນງານ, ແຖວໃນຕາຕະລາງ Drive.

### ຄ່າໃຊ້ຈ່າຍເຄິ່ງໜຶ່ງ, ເມື່ອລໍຖ້າໄດ້

ສະຫຼັບຕົວແທນແບບງ່າຍໄປໂໝດ Batch API ແລ້ວການຮັນຂອງມັນຈະຜ່ານຄິວ batch ຂອງຜູ້ໃຫ້ບໍລິການ — ຖືກກວ່າປະມານ 50%, ແລ້ວສຳເລັດພາຍໃນ 24 ຊົ່ວໂມງ. ສຳລັບໂມເດວ Anthropic ແລະ OpenAI.

### ຄວາມຈຳຂ້າມຮອບ, ຖ້າທ່ານຕ້ອງການ

ເລີ່ມການສົນທະນາໃໝ່ທຸກຮອບ, ຫຼື ເພີ່ມເຂົ້າການສົນທະນາຫຼ້າສຸດເພື່ອໃຫ້ຕົວແທນຈື່ຄັ້ງກ່ອນ, ຫຼື ໂພສເຂົ້າການສົນທະນາສະເພາະອັນ.

### ມັນຢຸດເມື່ອທ່ານບອກ

ຕັ້ງວັນໝົດອາຍຸ ຫຼື ຈຳນວນຮັນສູງສຸດ, ແລະ ເລືອກຈຳນວນຂໍ້ຄວາມທີ່ຮັນຄຽງກັນ — ຈາກໜຶ່ງເຖິງສິບ.

### ທຸກຮອບຢູ່ໃນບັນທຶກ

ແຕ່ລະຮອບເກັບສະຖານະ, ເວລາເລີ່ມ ແລະ ຈົບ, ແລະ ຄຳຕອບ ຫຼື ຂໍ້ຜິດພາດຂອງແຕ່ລະຂໍ້ຄວາມ ພ້ອມໂທເຄັນ ແລະ ຄ່າໃຊ້ຈ່າຍ — ລວມຢູ່ໃນ Settings › Logs ນຳ.

## ຄຳຖາມກ່ຽວກັບ Scheduler

ສິ່ງທີ່ຄົນຖາມ ກ່ອນຕັ້ງລາຍງານອັດຕະໂນມັດອັນທຳອິດ.

### ຕັ້ງເວລາຫຍັງໄດ້ແດ່?

ຕົວແທນທີ່ໃຊ້ງານຢູ່ໃນພື້ນທີ່ເຮັດວຽກຂອງທ່ານ ອັນໃດກໍໄດ້. ທ່ານຂຽນຂໍ້ຄວາມທີ່ຄວນສົ່ງໃຫ້ມັນ, ໜຶ່ງຂໍ້ຄວາມຕໍ່ໜຶ່ງແຖວ, ແລະ ແຕ່ລະຮອບຈະສົ່ງພວກມັນ ແລະ ບັນທຶກຄຳຕອບ.

### ຜົນລັບຈະສົ່ງມາຫາຂ້ອຍແນວໃດ?

ຜ່ານເຄື່ອງມືຂອງຕົວແທນເອງ. ໃຫ້ມັນມີ Telegram Send Message, Gmail ຫຼື Notify Operators ແລ້ວບອກໃນຂໍ້ຄວາມວ່າຜົນລັບຄວນໄປໃສ. ທຸກຄຳຕອບຍັງຖືກເກັບໄວ້ໃນປະຫວັດການຮັນຂອງວຽກນຳ.

### ໂໝດ Batch API ແມ່ນຫຍັງ?

ມັນສົ່ງຂໍ້ຄວາມຂອງຮອບໜຶ່ງຜ່ານຄິວ batch ຂອງຜູ້ໃຫ້ບໍລິການໂມເດວ ແທນທີ່ຈະຕອບທັນທີ. ຄ່າໃຊ້ຈ່າຍປະມານເຄິ່ງໜຶ່ງ ແລະ ສຳເລັດພາຍໃນ 24 ຊົ່ວໂມງ. ໃຊ້ໄດ້ກັບຕົວແທນແບບງ່າຍເທິງໂມເດວ Anthropic ຫຼື OpenAI; workflow ແບບ agentic ຕ້ອງການການຮັນຫຼາຍຮອບ ຈຶ່ງຮັນທັນທີສະເໝີ.

### ໃຊ້ເຂດເວລາໃດ?

ອັນທີ່ທ່ານເລືອກໃນວຽກ — ຄ່າເລີ່ມຕົ້ນແມ່ນເຂດເວລາຂອງບຣາວເຊີທ່ານ. ເວລາລາຍວັນ, ລາຍອາທິດ ແລະ ລາຍເດືອນ ອ່ານຕາມເຂດເວລານັ້ນ.

### ຕັ້ງເວລາໃຫ້ຕົວແທນທີ່ມີຂັ້ນຕອນ Human Review ໄດ້ບໍ່?

ບໍ່ໄດ້. ການຮັນຕາມກຳນົດເວລາບໍ່ມີໃຜອະນຸມັດ, dialog ຈຶ່ງຈະບໍ່ຕັ້ງເວລາໃຫ້ຕົວແທນທີ່ workflow ຂອງມັນມີໂໜດ Human Review.

### ວຽກຢຸດຫຼັງຈາກຮັນຈຳນວນໜຶ່ງໄດ້ບໍ່?

ໄດ້. ຕັ້ງຈຳນວນຮັນສູງສຸດ, ວັນໝົດອາຍຸ, ຫຼື ທັງສອງຢ່າງ. ທ່ານຍັງພັກ, ດຳເນີນຕໍ່ ຫຼື ຍົກເລີກວຽກໄດ້ທຸກເວລານຳ.
