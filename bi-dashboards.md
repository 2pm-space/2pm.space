## From question to board in three steps

Ask it, pin it, share it.

1. **Ask, or write the SQL** — Ask Data answers in plain language with a chart. SQL Lab lets you write the query yourself, or have AI draft it from a description.
2. **Pin it to a board** — Pin the chart to a board and a tab — a new one or one you have. The tile keeps its query, not just the picture.
3. **Share it** — Share the board with the people who need it. The filters live in the URL, so a link opens on the view you are looking at.

## A board that stays honest

Every tile is a query against your data model, not a screenshot of one.

### One definition of revenue

Tiles query the same semantic model Ask Data does, so a measure defined once means the same thing on every chart and every board.

### Filters that reach every tile

Add a board filter on any dimension your model marks filterable — text, select, multi-select, date or date range — and every tile that uses it re-runs. A tile that can't honour it says so.

### This period against the last

Compare with the previous period, the same period last year or a range you pick, and re-bucket time by day, week, month, quarter or year.

### Nine ways to draw it

Bar, horizontal bar, stacked, 100% stacked, line, area, pie, scatter and a single-number card — with axis, legend, data-label and series colour settings per tile.

### SQL Lab for the precise ones

Write CubeQL against the model, read the native SQL it compiles to, save your queries, and turn a good one into a reusable derived cube.

### Agents can build boards too

The BI Board tool lets an agent create boards, add charts and read a tile's data — and the same actions are on our MCP server for Claude Code or Cursor.

## BI Dashboards questions

What people ask before they build their first board.

### Which databases can a board use?

Any connection Ask Data supports: PostgreSQL, MySQL, Redshift, ClickHouse, Snowflake and BigQuery. A board queries it through your semantic model.

### How do charts get onto a board?

From Ask Data or SQL Lab: once a chart looks right, choose Pin to board and pick the board and tab. The tile keeps the query, not just the picture.

### Do filters work on every tile?

A board filter applies to every tile whose query uses that dimension, and re-runs it. A tile that can't be filtered by it says so in its header, rather than quietly showing unfiltered numbers.

### Can I compare with last month or last year?

Yes. Turn on the comparison and choose the previous period, the same period last year or a custom range; tiles with a date window show both periods.

### Can agents use boards?

Yes. The BI Board tool lets an agent create a board, add charts and read a tile's data, and the same actions are available to Claude Code or Cursor through the MCP server.
